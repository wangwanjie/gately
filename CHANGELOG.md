# Changelog

Release notes are published in three places:

- Website announcements: [English](https://gately.cn/en/news/) and [简体中文](https://gately.cn/news/), with upgrade notes for each version.
- [GitHub Releases](https://github.com/wangwanjie/gately/releases): notes grouped by module, with the downloadable packages, checksums and signatures.
- Security fixes: [GitHub security advisories](https://github.com/wangwanjie/gately/security/advisories).

The release process and version numbering are described in the [Release policy](README.md#release-policy).

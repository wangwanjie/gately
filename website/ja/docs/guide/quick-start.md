# クイックスタート

5 分以内にデプロイ、ログイン、最初のルール作成まで完了できます。

## 1. 起動

```bash
docker run -d --name gately --network host --cap-add NET_ADMIN \
  -v ./gately-data:/etc/gately \
  ghcr.io/wangwanjie/gately:latest
```

Gately から Docker を管理する場合は、コマンドに `-v /var/run/docker.sock:/var/run/docker.sock` を追加してください。`--cap-add NET_ADMIN` は侵入防御がブロックをホストのファイアウォールに書き込むためのものです。ポート転送、STUN、Web サービスはホストのポートを待ち受ける必要があるため、`--network host` を推奨します。

GHCR へのアクセスが遅い場合は、Docker Hub の `vanjayak/gately:latest` を使えます。中身は同じイメージです。

::: tip fnOS ユーザーの方へ
代わりにネイティブアプリをインストールしてください。fnOS 統一ゲートウェイ経由でデスクトップのアイコンから開け、fnOS 管理者は fnOS のログイン状態でそのままログインできます。詳しくは [fnOS ネイティブアプリ](/ja/docs/guide/install#fnos) を参照してください。
:::

## 2. ログイン

ブラウザで `http://<デバイスのIP>:16680` を開き、ユーザー名 `admin`、デフォルトのパスワード `gately.cn` でログインします。デフォルトのパスワードは公開されているため、ログイン後にパスワード変更ダイアログが表示されます。10 文字以上の推測されにくい新しいパスワードに変更すると、使い続けられます。

新規インストールでパスワードを変更すると、最初に「Gately を何に使いますか？」と尋ねられます。「社内サービスをドメインで公開」「ポート転送 / ホールパンチ」「ダイナミック DNS」「拠点間ネットワーク」「ファイル共有」「VPS の入口」「すべての機能」から複数選択できます。選んだ用途に関連する機能モジュールだけを残し、残りは無効になり（設定は削除されません）、その後 1 回自動で再起動します。あとから「設定 → 機能モジュール」またはサイドバー下部の「機能を追加」でいつでも有効にできます。「スキップ」を選ぶとすべての機能が残ります。アップグレードしたインスタンスではこの手順は表示されません。概要の上部にある「はじめに」チェックリストは、選んだ用途に応じて次にやることを並べ、実際の設定に合わせて自動でチェックを付けます。折りたたんだり閉じたりできます。

## 3. 基本的なハードニング

ログイン後すぐに、「設定」で次の操作を行ってください。

1. 2 段階認証（TOTP）を有効にするか、Passkey を登録する
2. 必要に応じて、セキュアエントリー、LAN 内からのみ許可、管理画面の HTTPS を設定する
3. 「設定 → アカウントとセキュリティ」の上部にあるセキュリティスコアを確認し、案内に従って減点項目に対処する

詳しくは [ハードニングの推奨事項](/ja/docs/guide/hardening) を参照してください。

## 4. 最初のルールを追加

Web サービスページの「クイックサイト」で、3 ステップでサイトを公開できます。ドメインを入力し、バックエンドのアドレスを入力し（「接続テスト」が使えるほか、Home Assistant、Jellyfin、Emby、Vaultwarden、Nextcloud、Immich、Proxmox VE、Synology DSM、fnOS のテンプレートでポートと推奨オプションを事前入力できます）、HTTP か HTTPS を選びます。リスナーは自動で再利用または新規作成されます。詳しくは [Web サービス · クイックサイト](/ja/docs/modules/web#quick-site) を参照してください。

目的に合ったモジュールから始めましょう。

| 目的 | モジュール |
| --- | --- |
| 自宅の公開 IP が頻繁に変わるので、固定のドメイン名でアクセスしたい | [ダイナミック DNS](/ja/docs/modules/ddns) |
| 回線事業者から固定の公開ポートが割り当てられず、外出先から自宅のサービスにアクセスしたい | [STUN 穿孔](/ja/docs/modules/stun) |
| 1 つのポートを LAN 内の別のデバイスに転送したい | [ポート転送](/ja/docs/modules/portforward) |
| 1 つのドメイン名と HTTPS で複数の LAN 内サービスにアクセスしたい | [SSL 証明書](/ja/docs/modules/ssl) + [Web サービス](/ja/docs/modules/web) |
| 拠点間をつなぐネットワークを構築したい | [Tailscale / frp](/ja/docs/modules/tunnels) |

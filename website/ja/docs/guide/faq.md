# よくある質問

## プロジェクト側のサーバーへの接続は必要ですか？

接続は不要です。Gately はプロジェクト側のサーバーに接続せず、端末情報も送信しません。デフォルトでは GitHub のリリース一覧とセキュリティアドバイザリーを匿名で照会しますが、無効にできます。詳しくは[自動更新チェック](/ja/docs/guide/install#update-check)を参照してください。公開 IP の照会などの外部アドレスにはサードパーティの公開サービスが使われ、対応するタスクで変更できます。

## デフォルトのアカウントとパスワードは？

デフォルトのアカウントは `admin`、パスワードは `gately.cn` です。このパスワードは公開されているため、ログイン後すぐに「設定 → アカウントとセキュリティ」で変更してください。変更するまで管理画面の上部に警告が表示され続けます。デプロイ時に環境変数 `GATELY_INITIAL_PASSWORD` を設定した場合は、そのパスワードが使われます。

## 管理者パスワードを忘れた場合は？

サーバー上で `gately reset-password`（Docker では `docker exec -it gately gately reset-password`）を実行し、`yes` と入力して確認すると、パスワードがデフォルトの `gately.cn` にリセットされます。稼働中のインスタンスには数秒以内に反映されます。詳しくは [パスワードと 2 段階認証のリセット](/ja/docs/guide/install#reset) を参照してください。

## 2 段階認証アプリを紛失した場合は？

サーバー上で `gately reset-totp`（Docker では `docker exec -it gately gately reset-totp`）を実行して確認すると、2 段階認証が無効になります。パスワードでログインしてから、もう一度有効にしてください。

## fnOS に対応していますか？

対応しています。各リリースに fnOS 向けのオフラインパッケージ（`.fpk`）が含まれており、アプリセンターから手動でインストールできます。Gately は fnOS 統一ゲートウェイに統合されるため、デスクトップのアイコンから開け、fnOS のリモートドメインでも利用できます。「設定 → アクセス制御」で「fnOS のログイン状態で自動ログイン」を有効にすると、fnOS にログイン済みの管理者はパスワードや 2 段階認証コードなしでそのまま入れます。詳しくは [fnOS ネイティブアプリ](/ja/docs/guide/install#fnos) を参照してください。

## OpenWrt / iStoreOS に対応していますか？

対応しています。各リリースに OpenWrt 向けパッケージが含まれます。OpenWrt 24.10 以前（iStoreOS を含む）は `.ipk` を `opkg install` で、OpenWrt 25.12 以降は `.apk` を `apk add --allow-untrusted` でインストールします。インストール後に自動で起動し、設定は `/etc/gately` に保存されます。アップグレードは新しいパッケージをインストールするだけです。バイナリは約 32 MB なので、ストレージに余裕のあるソフトルーター向けです。詳しくは [OpenWrt](/ja/docs/guide/install#openwrt) を参照してください。

## なぜ `--network host` を推奨しているのですか？

ポート転送、STUN、Web サービスは、ホストのポートを直接待ち受ける必要があります。ブリッジネットワークを使う場合は、使用するポートを 1 つずつ自分でマッピングしてください。

## Tailscale、frp、cloudflared のプログラムはどこから入手しますか？

これらのモジュールは公式の外部プログラムを管理し、Gately 本体には内蔵していません。各モジュールページの「オンラインインストール」カードで最新版または指定バージョンをダウンロードでき、個別のダウンロードプロキシも設定できます。更新後に問題があれば旧バージョンにロールバックできます。プログラムのアンインストールやデフォルト設定に戻すこともできます。詳しくは [オンラインでのインストール・更新・ロールバック](/ja/docs/modules/tunnels#install) を参照してください。Tailscale のオンラインインストールは Linux のみ対応です。プログラムを自分で配置することもでき、配置場所は [設定と起動オプション](/ja/docs/guide/configuration) を参照してください。

## STUN ルールを有効にしても外部からアクセスできません

ルーターの WAN 側がキャリアグレード NAT（100.64.0.0/10）の配下にある場合、外部から穿孔したポートにアクセスできません。これはネットワーク環境自体の制約です。[Tailscale / frp / Cloudflare トンネル](/ja/docs/modules/tunnels) への切り替えを検討してください。

## 問題の報告や開発への参加はどうすればよいですか？

[GitHub Issues](https://github.com/wangwanjie/gately/issues) で報告してください。開発の決まりごとは [コントリビュート](/ja/docs/guide/contributing) を参照してください。

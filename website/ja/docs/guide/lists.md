# リストのグループ、並べ替え、一括操作と複製

項目の多いリストはグループ化、手動での並べ替え、検索、一括操作ができ、操作方法はどのページでも共通です。順序とグループは管理画面の表示にだけ影響し、変更しても実行中のインスタンスは再起動されず、接続も切断されません。

## 対応しているリスト

| ページ | リスト |
| --- | --- |
| ダイナミック DNS | タスク、タスク内の DNS レコード |
| STUN 穿孔 | ルール |
| ポート転送 | ルール |
| SSL 証明書 | 証明書 |
| Web サービス | リスナー内のサイト（リスナー自体は上下に移動可能） |
| WAF ファイアウォール | インスタンス |
| 侵入防御 | ログルール |
| frp | frpc インスタンス、frps インスタンス、プロキシ |
| Cloudflare トンネル | トンネル |
| File Browser | インスタンス |
| ストレージマウント | マウント |
| Wake-on-LAN | デバイス |
| スケジュールタスク | タスク |
| 通知センター | チャネル、ルール |
| Web ターミナル | 保存した接続 |
| API トークン | トークン |

これらのリストの多くは「カード表示」と「コンパクト表示」の両方に対応しており、リスト右上で切り替えます。幅の狭い画面ではカード表示に固定されます。

## グループ

編集ダイアログで「グループ」を入力します（最大 64 文字、既存のグループから選択可能）。空欄の場合はグループなしになります。1 つでもグループが設定された項目があると、リストはグループごとの折りたたみ可能なブロックで表示されます。グループは最初に現れた順に並び、グループなしの項目は最後に置かれ、各グループの折りたたみ状態はブラウザに保存されます。検索ボックスでは名前、グループ、備考などで項目を絞り込め、検索中はすべてのグループが展開されます。

グループ見出しにマウスを合わせて鉛筆ボタンをクリックすると、グループ名を変更できます。グループ内の項目はまとめて新しい名前になり、位置と順序は変わりません。既存のグループ名に変更した場合は、確認後に 2 つのグループが統合されます。

## 並べ替えモード

「並べ替え・一括」をクリックすると並べ替えモードになります。このモードではすべての項目が表示され、検索と絞り込みは一時的に無効になります。

- 矢印でグループ内の項目を上下に移動するか、グループ見出しの矢印でグループ全体を移動します。
- デスクトップでは項目を直接ドラッグできます。別のグループの項目やグループ見出しにドロップすると、そのグループに加わります。
- 複数の項目にチェックを入れて（グループ見出しのチェックボックスでグループ全体を選択できます）そのうちの 1 つをドラッグすると、選択したすべての項目が現在の順序のまま一緒に移動します。
- ツールバーの「グループへ移動」で選択した項目を指定のグループへまとめて移動できます。空欄にするとグループから外れます。

スマートフォンなど幅の狭い画面ではドラッグに対応しておらず、矢印とツールバーで同じ操作を行います。

## 一括操作

並べ替えモードで項目にチェックを入れると、ツールバーで次の操作もできます。

- **有効化 / 無効化**：チェックしたすべての項目を一度に保存します。すでに目的の状態になっている項目は再起動されません。
- **削除**：確認ダイアログに削除される項目が一覧表示されます。削除すると元に戻せません。削除できない項目が 1 つでもある場合（サイトから参照されている証明書など）は 1 つも削除せず、理由を表示します。

一括操作で一度に処理できるのは最大 500 項目です。すべての項目が検証を通過したときだけ保存され、1 つでも失敗すると何も変更されません。Wake-on-LAN のデバイスには有効化スイッチがないため、一括削除のみ使えます。API トークンは現在、一括の有効化・無効化・削除に対応していません。Web サービスにはドメインとオプションの一括変更もあります。[Web サービス](/ja/docs/modules/web#一括操作)を参照してください。サイトは別のリスナーへ移動することもできます。[サイトの移動](/ja/docs/modules/web#move-sites)を参照してください。

## 項目の複製

API トークンを除く上表の項目はすべて「複製」でき、購読 IP リスト、バックアップ先、Web ターミナルの認証プリセット、DDNS タスク内のレコード、Web サービスのリスナー内のサイトも複製できます。項目の「複製」をクリックすると、その項目をテンプレートとして追加ダイアログが開き、名前に「のコピー」が付きます。区別が必要な設定を変更して保存すると新しい項目が追加されます。元の項目は変更されず、コピーは元の項目のすぐ後ろに並びます。

- **秘密情報は元の項目から引き継ぎ**：保存済みのパスワード、トークン、秘密鍵はダイアログ上でマスクされたままです。変更しなければ元の項目の値を使い、平文はブラウザを経由しません。目のボタンで元の項目の平文を表示できます。Web ターミナルの接続と認証プリセットは、利用規約への同意と二段階認証を済ませてから秘密情報を引き継ぎます。
- **システムが管理する内容は複製しない**：ACME で取得した証明書やファイルから読み込む証明書は、コピーの設定で改めて発行・読み込みされます。アップロードした証明書は秘密鍵ごと複製されます。証明書のデプロイ記録は消去され、購読 IP リストは再ダウンロードされます。サイトの共有リンクはトークンで認証を回避できるため複製されません。
- **証明書のデプロイ先**：元の証明書と同じファイルに書き込まないよう、コピーではデプロイ先を無効にしています。ファイル名が重複しないことを確認してから有効にしてください。
- **Web サービス**：サイトの複製時に別のリスナーへ配置できます（HTTP リスナーから HTTPS リスナーへなど）。リスナーの複製時には、含まれるサイトも複製するかを選べます。
- コピーは元の項目の有効/無効状態を引き継ぎます。元の項目と競合しないよう、保存前にポート、ドメイン、レコードなど区別が必要な設定を変更してください。

## ページごとの補足

- **ダイナミック DNS**：タスクカードの「レコードの並べ替え」でダイアログが開き、そのタスク内の DNS レコードの順序とグループを調整できます。保存するとすぐに反映され、再同期は行われません。タスクの編集時にも「DNS レコード」タブから同じダイアログを開け、タスクと一緒に保存されます。レコードにグループが設定されている場合、カード内のレコードはグループごとに表示され、グループごとに折りたためます。
- **frp**：プロキシ一覧は frpc インスタンスで絞り込めます。並べ替えモードではすべてのプロキシが表示され、全体の順序を調整します。
- **API トークン**：手動で並べ替えるまでは作成日時の新しい順に表示されます。順序を調整した後は保存した順序で表示され、新しく作成したトークンは先頭に置かれます。
- **認証ユーザー**：「共有ユーザーを使うサイト」はリスナーごとに表示され、リスナー内のサイトはさらに Web サービスでのグループごとに分類されます。リスナーとグループはそれぞれ折りたためて、ツールバーからすべてを一括で折りたたみ・展開できます。

## API

汎用のリスト API はすべて、順序を変更する `PUT <リストのパス>-order`（リクエストボディ `{"keys": [...]}`、すべての項目を含める必要があります）と、グループを一括設定する `PUT <リストのパス>-group`（リクエストボディ `{"keys": [...], "group": "..."}`）、一括で有効化・無効化する `PUT <リストのパス>-enable`（リクエストボディ `{"keys": [...], "enable": true}`）、一括削除する `POST <リストのパス>-delete`（リクエストボディ `{"keys": [...]}`）を提供します。例：`PUT /api/stun/rules-group`、`POST /api/portforward/rules-delete`。DDNS タスク内のレコードは `PUT /api/ddns/tasks/{key}/records-layout`、API トークンは `PUT /api/tokens/order` と `PUT /api/tokens/group` を使います。詳しくは[エンドポイント一覧](/ja/docs/reference/api-reference)を参照してください。

項目の複製には `POST <リストのパス>/{key}/copy` を使います。リクエスト本文は新しい項目で、プレースホルダー `********` のままの秘密情報は項目 `{key}` の値を引き継ぎます（例：`POST /api/frp/clients/{key}/copy`）。

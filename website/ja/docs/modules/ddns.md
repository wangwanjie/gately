# ダイナミック DNS（DDNS）

家庭用ブロードバンドの公開 IP は変化します。DDNS は IP が変わると DNS レコードを自動で更新し、ドメイン名が常に現在のアドレスを指すようにします。

## 対応プロバイダー

Alibaba Cloud、Cloudflare、Tencent Cloud、DNSPod、Huawei Cloud、GoDaddy、Porkbun、dynv6、DuckDNS、Amazon Route 53、OVHcloud、Gandi、NS1、Bunny DNS、Namecheap、DynDNS2、およびカスタムコールバック（未対応のプロバイダーや自前の API 用）。

| プロバイダー | 認証情報 | 証明書の DNS 検証に利用 |
| --- | --- | --- |
| Amazon Route 53 | Access Key ID / Secret Access Key、任意でホストゾーン ID | 可 |
| OVHcloud | Application Key / Secret と Consumer Key、エンドポイント ovh-eu / ovh-ca / ovh-us | 可 |
| Gandi | Personal Access Token | 可 |
| NS1 | API Key | 可 |
| Bunny DNS | Account API Key | 可 |
| Namecheap | ドメインの Dynamic DNS パスワード（A レコードのみ） | 不可 |
| DynDNS2 | ユーザー名、パスワード、更新 URL。No-IP、Dynu など dyndns2 プロトコル互換のサービス向け | 不可 |

## IP の取得方法

- **URL**：公開 IP の照会アドレスにリクエストします（任意のサービスに置き換えたり、自前で用意したりできます）。
- **NIC**：指定したネットワークインターフェースのアドレスを直接読み取ります。公開 IP を持つデバイスに向いています。
- **コマンド**：コマンドを実行してその出力を使います。特殊なネットワーク環境向けです。

IPv4 と IPv6 に対応しています。

## レコード値の変数 {#record-vars}

レコード値には次の変数を使用でき、同期のたびに現在の値に置き換えられます。

- `{ipv4Addr}`、`{ipv6Addr}`：このタスクが取得した IPv4・IPv6 アドレス（A・AAAA レコードの値を空にした場合の既定値）
- `{STUN_ルール名_PORT}`、`{STUN_ルール名_IP}`、`{STUN_ルール名_ADDR}`：STUN ルールの現在のパブリックポート、IP、IP:ポート。ルール名にはアンダースコアを含められます。例：TXT レコードに `port={STUN_ssh_PORT}`、A レコードに `{STUN_ssh_IP}`

STUN ルールのパブリックアドレスが変わると、それを参照するタスクは次のチェック周期を待たずにすぐ同期します。ルールが無効、またはまだ貫通に成功していない場合、そのレコードはその回はスキップされ、レコードの状態に理由が表示されます。STUN 変数はタスクの Webhook でも使用できます。Webhook だけで参照している場合も、アドレスが変わると Webhook を 1 回呼び出します。ルール名の代わりにルールの key も使えます。

## 通知

IP の変化や同期の失敗時に Webhook を呼び出せます。

## 利用のヒント

- DNS プロバイダーでは、レコード編集権限だけを持つサブアカウントのキーを作成して使い、メインアカウントのキーは使わないでください。
- タスクを作成したら「強制同期」を押して、レコードが更新されたことを確認します。
- 不要になったレコードは、一覧でそのレコード右側の削除アイコンを押せば編集画面を開かずに削除できます。タスクから外すだけでプロバイダー側の既存レコードは残り、タスクには少なくとも 1 件のレコードが残ります。
- 公開 IP の照会アドレスはプロジェクト側のサービスに依存しないため、タスクでいつでも変更できます。

## グループと並べ替え

タスクには「グループ」（最大 64 文字）を設定できます。一覧はグループごとに折りたためるセクションで表示され、グループは最初に現れた順に並び、グループなしのタスクは最後になります。折りたたみ状態はブラウザに保存されます。ページ上部の検索ボックスでは名前・グループ・ドメイン・プロバイダで絞り込めます。

「並べ替え」で並べ替えモードに入ります。矢印でタスクを上下に移動したり、グループごと移動したりできます。複数のタスクにチェックを入れてそのどれかをドラッグするとまとめて移動し、別グループのタスクや見出しにドロップするとそのグループに入ります。ツールバーではチェックしたタスクを指定グループへ一括で移動でき、名前を空欄にするとグループから外します。順序とグループは一覧の表示にだけ影響し、変更してもタスクは再起動されません。

グループ見出しにマウスを合わせて鉛筆ボタンを押すと、グループ名を変更できます。グループ内の項目もまとめて新しい名前になり、位置と順序は変わりません。既存のグループと同じ名前にすると、確認のうえ 2 つのグループが統合されます。

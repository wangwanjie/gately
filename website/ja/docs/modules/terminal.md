# Web ターミナル

ブラウザから SSH や Telnet のサーバー、またはローカルシェルに接続します。セッションはサーバー側に永続的に保持され、切断後に再接続できます。入口はサイドバーの「Web ターミナル」です。

## 接続の種類

| 種類 | 説明 |
| --- | --- |
| SSH | パスワード認証と秘密鍵認証に対応（秘密鍵は貼り付けるか、サーバー上の `keyFile` パスを指定でき、秘密鍵のパスフレーズも使えます）。ログイン後に移動する `workDir`、`keepAlive`、接続タイムアウト（1〜120 秒、デフォルトは 15）、プロキシを設定できます |
| Telnet | デフォルトのポートは 23。`login:`、`username:`、`password:` などのプロンプトを検出すると、それぞれ 1 回ずつ自動入力します。プロキシも設定できます |
| ローカルシェル | Gately を実行しているデバイスで直接シェルを開きます。シェルのパス、作業ディレクトリ、追加の環境変数を指定できます |

各接続にはメモを書けます。接続一覧はドラッグ＆ドロップで並べ替えができ、「接続テスト」にも対応しています。SSH ではサーバーのバージョンとレイテンシーが返り、Telnet は TCP（プロキシ経由を含む）の到達性のみを検証し、ローカルシェルはテストできません。接続を編集するとき、パスワード、秘密鍵、秘密鍵のパスフレーズ、プロキシのパスワードはマスクして表示され、変更しなければ元の値が引き継がれます。

「設定」で「SSH 認証プリセット」（パスワードまたは秘密鍵。既定のユーザー名も指定可）を管理できます。SSH 接続の追加・編集時に認証プリセットを選ぶと再利用でき、1 つの資格情報を複数の接続で共有できます。プリセットを変更すると、各接続の次回接続時に反映されます。接続から参照されているプリセットは削除できません。

### プロキシ

SSH と Telnet の接続には、個別に外向きのプロキシを設定できます。種類は `socks5` または `http` で、プロキシのユーザー名とパスワードも入力できます。

### ホスト鍵の初回信頼

SSH 接続を初めて確立するときにサーバーのホストフィンガープリントを記録して信頼し、以降の接続のたびに照合します。サーバーを再インストールしたり鍵を交換したりした場合は、その接続で「ホストフィンガープリントをリセット」を実行すると、再び信頼されます。

## セッション

- セッションはサーバー側に永続的に保持されます。ブラウザを更新したり切断したりしても、セッション一覧から再接続でき、接続時にはまず出力バッファーを再生してから、リアルタイムの転送に切り替わります。
- 同じセッションに複数のクライアントが同時に接続でき、入力は共有され、出力はブロードキャストされます。
- セッションにはメモを追加できます。セッション一覧には、作成日時、最終アクティビティの日時、ウィンドウサイズ、送受信バイト数が表示されます。
- ページを更新しても、生きているセッションはタブとして自動的に復元され、分割レイアウトも一緒に復元されます。
- ターミナルには、検索（キーワードを入力し、Enter で次を検索、Shift+Enter で前を検索）、コピー、貼り付け、画面クリア、フォントサイズの調整、全画面表示、複数のカラーテーマ（既定では画面のテーマに従い、特定の配色に固定することもできます）が組み込まれています。

### 設定項目

ページ右上の「設定」で調整します。

| フィールド | デフォルト値 | 説明 |
| --- | --- | --- |
| `allowLocalShell` | オフ | ローカルシェルを開くことを許可するか |
| `maxSessions` | 20 | 同時セッション数の上限。最大 1000。超えると、新規セッションの作成は HTTP 429 を返します |
| `idleTimeout` | 0 | 入出力のない状態がこの分数を超えたセッションを自動で終了します。0 で無制限 |
| `bufferSize` | 256 | セッションごとに保持する再生バッファー（KB）。最大 16384 |
| `heartbeatInterval` | 30 | WebSocket のハートビート間隔（秒）。最大 600 |
| `sessionKeepAlive` | 0 | ブラウザ切断後もセッションを保持する分数。0 は切断と同時に終了。最大 10080 |

::: tip ヒント
切断後に再接続したい場合は、`sessionKeepAlive` を 0 より大きい値に設定してください。0 の場合、ブラウザを切断するとセッションはすぐに終了します。
:::

## SFTP ファイル管理

ターミナルのツールバーにあるフォルダーアイコンで、ファイル管理パネルを開きます。SSH 接続は SFTP でリモートのファイルを操作し、ローカルシェルの接続は Gately が動作しているデバイスのファイルシステムを直接操作します。Telnet 接続ではファイル管理は使えません。ローカルのファイル管理には、「ローカルシェルを許可」が有効になっている必要があります。

| 機能 | 説明 |
| --- | --- |
| 閲覧 | パンくずリストと上位ディレクトリへの移動。ディレクトリが先で、名前順に並び、並べ替え方法を切り替えられます。パーミッション、サイズ、更新日時、所有者を表示します |
| 新規作成 | フォルダーの新規作成、空ファイルの新規作成 |
| アップロード | 複数ファイルのアップロード。デスクトップではフォルダーごとのアップロードにも対応し（サブディレクトリの構造を保持）、同名のファイルは上書きされ、パネルにアップロードの進捗が表示されます |
| ダウンロード | ストリーミングダウンロード。レジューム（`Range`）に対応 |
| オンライン編集 | テキストファイルのプレビューと保存。1MB を超えるファイルやバイナリはプレビューできません |
| 名前変更、コピー、貼り付け | 同じディレクトリにコピーすると、`name コピー.ext`、`name コピー 2.ext` のように自動で名前が付けられます |
| 削除 | 複数選択による一括削除に対応。ディレクトリは再帰的に削除され、ルートディレクトリは保護されています |
| 圧縮と展開 | `zip` または `tar.gz` に圧縮します。展開は `zip`、`tar`、`tar.gz`、`tgz` に対応し、展開前にアーカイブの内容をプレビューできます（最大 10000 件）。圧縮と展開は Gately 自身が行うため、リモート側にコマンドをインストールする必要はありません |
| パーミッション変更 | 8 進数のパーミッション（0〜7777）。ディレクトリでは再帰を選べます |
| クイックアクセス | 接続ごとによく使うディレクトリを保存し、ワンクリックで移動できます |

展開時、`..` を含むエントリーがあるとアーカイブ全体を拒否してディレクトリトラバーサルを防ぎ、シンボリックリンクとハードリンクのエントリーはスキップされ、ファイルのパーミッションは rwx ビットのみ保持されます。モバイルのパネルには、複数選択モードと操作パネルが用意されています。

## クイックコマンド

「クイックコマンド」のドロップダウンには共通のクイックコマンドが一覧表示され、クリックすると現在のターミナルに送信されます。各クイックコマンドは `name`、`command`、`sendEnter`（送信後に自動で Enter を押すか）で構成されます。ドロップダウン下部の「クイックコマンドを管理」で追加、編集、削除ができます。

## 分割表示

ツールバーの「分割」メニューには、左右に分割、上下に分割、グリッドに分割があり、同時に最大 4 ペインまで表示できます。分割表示中に別の接続を開くと自動で分割に追加されます。他のタブをクリックして追加することもでき、ペインのタイトルバーからセッションを分割から外せます。分割レイアウトはサーバー側に保存され、ページを更新すると復元されます。画面が狭い場合は自動で分割が解除されますが、保存済みのレイアウトは削除されません。

## モバイル対応

- 画面が狭い場合は、接続一覧とターミナルが別々のビューに分かれ、ターミナルビューの左上の戻るボタンで一覧に戻れます。
- ターミナル領域はビューポートに追従し、ソフトウェアキーボードが表示されると自動で縮小されます。
- 仮想キーバーは横にスワイプできる 1 行のバーで、`Esc`、`Tab`、`Ctrl`、`Alt`（押したままにできます）、矢印キー（長押しで連打）、よく使う記号、クイックコマンドの入口が並び、右端にはキーボードの表示／非表示を切り替えるボタンが固定されています。キーバーは既定でソフトキーボードと一緒に表示・非表示になり、キーボードを閉じている間は右下のフローティングボタンからキーボードを呼び出せます。キーボードを出さずに矢印キーやページ送りを使いたい場合は、「その他」メニューで「キーバーを常に表示」をオンにします。

## セキュリティ

ターミナルは、対象ホストで任意のコマンドを実行できることと同じです。Gately はデフォルトで次の制限を設けています。

- **ローカルシェルはデフォルトで無効**で、設定で明示的に有効にする必要があります。
- **利用規約の確認**：ローカルシェルを初めて有効にするとき、セッションの新規作成、セッションへの接続、ファイル管理の利用の際に、利用規約が表示され、同意にチェックを入れると続行できます。
- **二段階認証（2FA）**：セキュリティ設定で QR コードをスキャンして TOTP 認証アプリを紐づけると、上記の操作で 6 桁のコードの入力が必要になります。検証に成功すると、現在のログイントークンは 30 分間再検証が不要になります。5 回連続で入力を間違えると、そのログイントークンは 1 分間ロックされます。
- 接続パスワード、秘密鍵、プロキシのパスワードは、API の出力でマスクされます。

::: warning 警告
ローカルシェルを有効にする前に、管理画面で 2 段階認証を有効にし、「LAN 内からのみ許可」または VPN と組み合わせてください。
:::

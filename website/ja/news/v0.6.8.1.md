# Gately v0.6.8.1 リリース

2026年11月17日

[ダウンロード v0.6.8.1](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.1)

## Web サービス

- **サイトの追加・編集に失敗する問題**：v0.6.8 では、Web サービスページでサイトの追加、編集、コピー、有効化・無効化を行うとき、および HTTPS リスナーを編集するときに、`siteCerts` の形式が正しくないというエラーで保存に失敗していました。原因は、v0.6.8 で追加されたサイトの証明書情報（サイト行に表示される証明書の残り日数）が画面から設定と一緒に送信され、保存 API がこのフィールドを認識しなかったことです。現在は画面が送信前にこれを取り除きます。保存 API も、一覧 API 自身が出力する読み取り専用フィールド（稼働状態、統計、証明書の一致情報など）を無視するため、アップグレード後も開いたままの古いページや、「取得した設定をそのまま丸ごと送信する」スクリプトでも保存できます。それ以外の未知のフィールドは従来どおり拒否されます。クイックサイトウィザードは影響を受けません。
- **接続の再利用時の「サイトが見つかりません」**：複数のドメインが同じ IP に解決され、証明書がすべてをカバーしている場合（例：`*.example.com` のワイルドカード証明書）、ブラウザは新しいドメインのリクエストをすでに開いている HTTP/2 接続に載せます。手前に SNI で振り分けるプロトコル振り分けがあり、一部のドメインを別の Gately に転送していると、その接続は実際には別の Gately につながっているため、アクセスすると「サイトが見つかりません」（または相手側のデフォルトサイト）が表示され、ブラウザを閉じて開き直すまで直りませんでした。現在は、HTTP/2・HTTP/3 のリクエストのドメインが TLS SNI と異なり、このリスナーにそのドメインのサイトがない場合、`421 Misdirected Request` を返し、ブラウザがそのドメイン用に新しい接続を作って自動的に再試行します。HTTP/1.1 と SNI のないリクエスト（IP でのアクセス）はこれまでどおり処理されます。

## ナビゲーションパネル（#100、#101）

- **リンクサイズ**：リンクは 1×1、1×2、2×2（行×列）に設定できます。カードスタイルの 2×2 は 2 行分の高さの大きなタイルで、アイコンが大きくなり、タイトルと説明が下に表示されます。アイコンスタイルの 1×1 はアイコンと名前、1×2 は左にアイコン、右に名前と説明を置いた横長のワイドタイル、2×2 は 2 倍サイズのアイコンです。サイズ未設定のリンクは従来どおりです（カードスタイルは 1×2、アイコンスタイルは 1×1）。アイコンスタイルではアイコン下の名前を非表示にできます。Sun-Panel 2.x からのインポートでは 1x2 と 2x2 のカードを引き継ぎます。
- **複数アドレスのリンクを直接開く**：「レイアウト」で、クリックすると現在のネットワークの既定アドレスを直接開き、右クリック、メニューキー、または長押し（スマートフォン）でアドレス選択を表示するように設定できます。既定は従来どおり、クリックでアドレス選択を表示します。
- **リンクアイコンの取得**：リンクの編集画面で「アイコンを取得」をクリックすると、リンクの LAN アドレス、外部アドレス、その他のアクセス方法の順にサイトが宣言しているアイコン（SVG と 128–256 px を優先）を読み取り、見つからなければ `/favicon.ico` を使います。取得したアイコンとアップロードした画像は適切なサイズに縮小され、2×2 でも鮮明です。
- **ページのスイッチ**：右上の言語メニュー、テーマボタン、ログイン時のみ表示リンクの鍵マークを、それぞれ個別にオン・オフできます。テーマボタンを隠すと、ページはパネルに設定したスキンとライト/ダークモードに固定されます。
- **背景のリアルタイムプレビュー**：背景設定のぼかしとオーバーレイのスライダーの下にリアルタイムプレビューを表示し、ドラッグ中に訪問者ページでの見え方を確認できます。
- **修正**：アイコンスタイルで 2×2 のリンクにマウスを重ねると行ったり来たりする問題、1×2 のワイドタイルがホバーで上に動き、ポインターが下端にあるとちらつく問題。

詳しくは [Web サービス](/ja/docs/modules/web) を参照してください。

## アップグレードの注意

- Docker は新しいイメージを pull してコンテナを再作成します。OpenWrt は新しい `.apk` / `.ipk` を上書きインストールします。fnOS はアプリセンターで新しい `.fpk` を手動インストールします。その他の環境では「システム設定」からオンラインでアップグレードできます。
- 「接続の再利用」の問題は、SNI で振り分ける両端をアップグレードして初めて完全に解消します。リクエストが届いた Gately が 421 を返す必要があるためです。
- ナビゲーションパネルの訪問者ページ右上の言語メニューは既定でオフになり、訪問者ページはブラウザーの言語で表示されます。以前に選択した言語（Cookie）も適用されなくなります。言語メニューが必要なパネルは、パネル編集の「ページ設定」タブで「言語切り替え」をオンにしてください。

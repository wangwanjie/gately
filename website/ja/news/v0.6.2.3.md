# Gately v0.6.2.3 リリース

2026年11月2日

v0.6.2 シリーズの改善アップデートです。設定ファイルの形式に変更はありません。

[ダウンロード v0.6.2.3](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.3)

## 独立したネットワークトポロジーページ

トポロジーは Web サービスページのタブから、サイドメニューの Web 配下にある「ネットワークトポロジー」ページに移りました。Web サービスページのボタンから開けます。統計と接続のダイアログはトポロジーページで開き、「編集」は Web サービスページに移ってサイトの編集画面を開きます。キャンバスは現在のスキンのライト / ダークに従います。

## 7 種類のレイアウト

レイアウトメニューにはツリー、縦ツリー、放射、サンキー、サンバースト、ツリーマップ、バブルがあり、それぞれアイコンと 1 行の説明が付きます。切り替えはフェードで行い、選択は記憶されます。各リスナーは先頭 8 サイト、各サイトは先頭 6 バックエンドを表示し、残りはトラフィックと処理中リクエストを合算した集約ノードにまとめられ、その場で展開できます。折りたたみボタンのないレイアウトでは詳細パネルからリスナーを折りたためます。

## ズーム、ウィンドウ全体表示、キャンバスの高さ

キャンバスはドラッグで移動できます。ホイールはページのスクロール、Ctrl / ⌘ + ホイール、トラックパッドのピンチ、2 本指のピンチで 15% から 250% の間で拡大縮小します。右下のコントロールで縮小、倍率表示（クリックで 100%）、拡大、キャンバスに合わせる、ウィンドウ全体表示（Esc で終了）を操作できます。キャンバス下のバーで高さを変更でき、デバイスごとに記憶されます。ダブルクリックまたは自動高さで元に戻ります。

## カテゴリ別マスク

マスクはカテゴリを選べます。訪問者の IP、バックエンドのアドレス、待ち受けアドレス、ドメインのうち、前の 3 つが既定で選ばれており、スクリーンショットやライブ配信で必要な情報を隠せます。

## スクリーンショットと紹介動画

公式サイトのトップと 10 言語の README は、対応する言語の画面のスクリーンショットを表示します。トポロジーのアニメーションを追加し、各 README の冒頭に 2 分間の音声なし紹介動画へのリンクを置きました。

## その他

- リスト / トポロジー切り替えの名残のコメントを削除しました。

## アップグレードの注意

- Docker は新しいイメージを pull してコンテナーを作り直してください。OpenWrt は新しい `.apk` / `.ipk` を上書きインストール、fnOS はアプリセンターで新しい `.fpk` をインストールしてください。その他の環境は「システム設定」からオンラインでアップグレードできます。

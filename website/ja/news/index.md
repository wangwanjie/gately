# 更新履歴

主要なバージョンのリリースのお知らせを以下に掲載します。各バージョンの変更点の全体とダウンロードファイルは [GitHub Releases](https://github.com/wangwanjie/gately/releases) を参照してください。

## [v0.6.2](/ja/news/v0.6.2)

2026年10月31日 · 新しい「プロトコル振り分け」モジュールで HTTPS、SSH、RDP、OpenVPN などが 1 つのポートを共有できます。長いリストはすべてグループ分けと並べ替えに対応し、ダイナミック DNS で STUN の公開アドレスを参照でき、STUN は多段 NAT に対応しました。セキュリティも複数の点で強化されています。

## [v0.6.1.1](/ja/news/v0.6.1.1)

2026年10月30日 · 侵入防御で Web パス探索をブロックできるようになりました。新しい「認証ユーザー」ページで共有ユーザーと OIDC をまとめて管理でき、共有ユーザーは自分でパスワードを変更でき、サイトは拒否時に接続を切断できます。Cloudflare のトークン方式トンネルのルートを Gately で編集でき、ログに「除外」フィルターが加わりました。

## [v0.6.1](/ja/news/v0.6.1)

2026年10月30日 · セキュリティ修正：読み取り専用アカウントと読み取り専用 API トークンからコンテナーの環境変数と起動コマンドの平文が読めなくなりました。証明書を IPv4 のみ・IPv6 のみで発行でき、Docker ページは Gately 自身のコンテナーをアップグレード・再作成しなくなり、通知とログは管理画面の言語に従います。

## [v0.6.0.4](/ja/news/v0.6.0.4)

2026年10月29日 · OpenWrt 向け LuCI アプリを追加し、LuCI で状態の確認、サービスの開始・停止、管理ポートの設定ができます。リダイレクトサイトで `{path}`、`{1}`、`{STUN_ルール名_PORT}` などの変数が使え、全体設定の共有ユーザーと OIDC クライアントは概要表示とダイアログ編集になりました。

## [v0.6.0.3](/ja/news/v0.6.0.3)

2026年10月28日 · 信頼する PROXY 送信元から平文転送を受ける LAN 側 Gately が訪問者の HTTPS 利用を認識できず、https 発行者の OIDC ログイン失敗、Cookie の Secure 欠落、平文リダイレクトのループが起きる問題を修正しました。

## [v0.6.0.2](/ja/news/v0.6.0.2)

2026年10月28日 · fnOS のデスクトップから開いたときに Web ターミナルが「接続中」のまま止まる問題、相対パスの設定ディレクトリで File Browser が起動しない問題、簡体字中国語以外の言語で API がユーザーの入力した中国語を部分的に翻訳する問題を修正しました。

## [v0.6.0.1](/ja/news/v0.6.0.1)

2026年10月27日 · ダイナミック DNS とポート転送がグループ分け・並べ替え・検索に対応。Web サービス、ダイナミック DNS、ポート転送でグループの一括設定、複数選択のドラッグ、グループ名の変更が可能になりました。

## [v0.6.0](/ja/news/v0.6.0)

2026年10月27日 · frpc と frps を複数インスタンスで実行可能に。Web サービスはサインインユーザーごとに別のバックエンドへ振り分け、サイトのグループ化・並べ替え・検索、Gately サインイン Cookie の転送に対応。証明書は委任されたサブドメインの DNS ゾーンを自動検出。保存済みのパスワードと鍵を必要に応じて表示可能に。

## [v0.5.9.1](/ja/news/v0.5.9.1)

2026年10月26日 · Web サービスの HTTPS リスナーが同一ポートで HTTP を受け付け可能に（リダイレクトまたはそのまま提供）。File Browser インスタンスにアクセス URL を設定可能に。File Browser インスタンスと Cloudflare トンネルの編集後に保存できない問題を修正。

## [v0.5.9](/ja/news/v0.5.9)

2026年10月26日 · File Browser をホスト。IP アドレス証明書と短期証明書を発行可能に。frp、cloudflared、Tailscale、File Browser をオンラインでインストール、更新、ロールバック、アンインストール可能に。ファイルサービスの共有ユーザーを専用ページに移動。

## [v0.5.8.1](/ja/news/v0.5.8.1)

2026年10月26日 · WebDAV・FTP・SMB で共有ユーザーを共用。Web サービスに「接続を切断」サイトを追加し、アクセスログに Referer と User-Agent を記録。frps の待ち受けアドレスを指定可能に。HTTP でもコピーボタンが使えます。

## [v0.5.8](/ja/news/v0.5.8)

2026年10月25日 · OIDC ID プロバイダーを内蔵し、共有ユーザーで Gitea、Grafana などのアプリにログインできます。SMB サービスを追加し、すべてのログを絞り込めるようになり、WAF のルールグループを並べ替えられ、サイトのリクエストヘッダーをよく使う項目から選べます。

## [v0.5.7](/ja/news/v0.5.7)

2026年10月24日 · ストレージマウントが SMB 共有に対応しました。テーマはライトとダークを備えた 15 のパレットになり、アクセントと角丸を変更できます。管理画面は圧縮して転送し、プログラムは約 11% 小さくなりました。

## [v0.5.6.4](/ja/news/v0.5.6.4)

2026年10月23日 · 証明書の自動デプロイで複数のローカルディレクトリへのコピー、ディレクトリごとのコマンド、証明書と秘密鍵のファイル名指定に対応しました。

## [v0.5.6.3](/ja/news/v0.5.6.3)

2026年10月23日 · OpenWrt で概要に br-lan が表示されない問題と、タイムゾーンを設定できず時刻が UTC になる問題を修正しました。

## [v0.5.6.2](/ja/news/v0.5.6.2)

2026年10月23日 · Web サービスのログイン画面とエラーページを刷新し、2 段階認証をポップアップに変更。Docker 29 で Docker モジュールに接続できない問題、ログイン前に概要画面が一瞬表示される問題、Lucky から移行した Cloudflare 認証情報と名前を変えた DDNS レコードが同期されない問題を修正しました。

## [v0.5.6.1](/ja/news/v0.5.6.1)

2026年10月22日 · Docker イメージが書き込んだファイアウォールルールでホストの古い nft がクラッシュする問題を修正しました。

## [v0.5.6](/ja/news/v0.5.6)

2026年10月22日 · 侵入防御を追加：fail2ban 風のログルール、おとりポート、ポートスキャン検出。ブロックは nftables に同期します。

## [v0.5.5.2](/ja/news/v0.5.5.2)

2026年10月22日 · fnOS などのファイルシステムで、設定ディレクトリ内の機密ファイルを同じマシンの他のユーザーが読めてしまう問題を修正しました。

## [v0.5.5.1](/ja/news/v0.5.5.1)

2026年10月21日 · 実行ログをディスクに書き込み、再起動やアップグレード後も確認できるようになりました。

## [v0.5.5](/ja/news/v0.5.5)

2026年10月21日 · nginx 設定のインポート、他のホストやコンテナへの証明書の自動デプロイ、WAF の大容量アップロードと WebDAV への対応、購読 IP リストを追加し、自己診断に証明書の有無と frp の競合の確認が加わりました。

## [v0.5.4](/ja/news/v0.5.4)

2026年10月21日 · Linux バイナリ導入でオンラインアップグレードに対応し、PVE の LXC コンテナを作り直す必要がなくなりました。OpenWrt パッケージ（.ipk / .apk）を追加しました。

## [v0.5.3](/ja/news/v0.5.3)

2026年10月21日 · fnOS ネイティブアプリ：fnOS 統一ゲートウェイに対応し、fnOS 管理者は fnOS のログイン状態でそのままログインできます。機能モジュールを個別に有効化・無効化できるようになりました。

## [v0.5.2](/ja/news/v0.5.2)

2026年10月20日 · SNI 振り分けで複数のサービスが 443 番ポートを共用でき、Web サービスで nginx を置き換えられます。共有ユーザーは TOTP とシングルサインオンに対応しました。haproxy + nginx との性能比較も掲載しています。

2026年10月19日 · 監査ログ、設定履歴とロールバック、Passkey、読み取り専用アカウント、ACME HTTP-01、HTTP/3、PROXY プロトコル、全体の Prometheus メトリクス、ネットワーク自己診断、署名付きリリース。

# 更新履歴

主要なバージョンのリリースのお知らせを以下に掲載します。各バージョンの変更点の全体とダウンロードファイルは [GitHub Releases](https://github.com/wangwanjie/gately/releases) を参照してください。

## [v0.6.5.3](/ja/news/v0.6.5.3)

2026年11月10日 · セキュリティ修正（レスポンスキャッシュ）、ナビゲーションパネル、訪問者監査、ネットワークトポロジーの再生、パスごとのキャッシュルール、Web ターミナルでキーの種類ごとにホストのフィンガープリントを照合、ログパネルの高さ調整。

## [v0.6.5.2](/ja/news/v0.6.5.2)

2026年11月8日 · Synology DSM など nf_tables のないカーネルで侵入防御とファイアウォールの自動許可に対応、サイトの先頭ラベル内ワイルドカード、フォワード認証の 401 リダイレクト、HTTP/2 リクエストでの終了を修正。

## [v0.6.5.1](/ja/news/v0.6.5.1)

2026年11月7日 · gately service による自動起動、長いリストのページ表示、DDNS レコードの一括追加、crash.log、macOS バイナリの署名と公証。

## [v0.6.5](/ja/news/v0.6.5)

2026年11月6日 · リバースプロキシのバックエンドと訪問者のタイムアウト、自動再試行、バックエンドへの ID 情報の受け渡し、リスナーと転送ルールのファイアウォール自動開放、アクセスログの日ごとのアーカイブとエクスポート、侵入防御の IPv6 厳格モード、管理対象プロセスのリソース表示。

## [v0.6.4.1](/ja/news/v0.6.4.1)

2026年11月4日 · Tailscale と NetBird が複数インスタンスに対応、通知にサーバー名、プロトコル振り分けのルートを一時無効化、DNSPod の同期・証明書検証の失敗と ipw.cn 停止による公開 IP 取得の失敗を修正。

## [v0.6.4](/ja/news/v0.6.4)

2026年11月3日 · カスタムビルド：build.gately.cn で必要なモジュールと UI 言語だけを選び、より小さなパッケージと Docker イメージをオンラインで生成。管理画面は未認可アクセスに対する特徴を隠せるように。Web サイトは 10 種類のエラーページスタイルまたはカスタムページを選べ、バックエンドのエラーページも置き換え可能。

## [v0.6.3.5](/ja/news/v0.6.3.5)

2026年11月3日 · NetBird によるネットワーク接続を追加。新しいバージョンとセキュリティアドバイザリを自動で確認して通知し、すべてのリストの項目をコピーでき、Web サイトを別のリスナーへ移動できます。ページヘッダーとリストのツールバーはスクロール中も表示され、通知、Webhook、IP リストはプロキシ経由にでき、Docker のバックグラウンドタスクは中断できます。セキュリティ修正を含むため、アップグレードをおすすめします。

## [v0.6.3](/ja/news/v0.6.3)

2026年11月2日 · パフォーマンス監視を追加（推移、最初のバイトまでの時間、しきい値アラート）。WAF は自前の SafeLine 検知エンジンに接続でき、リストと Web サービスのサイトは一括操作に対応。STUN ルールはこのマシンのファイアウォールのポートを自動で開放でき、ワイルドカード CNAME による DNS-01 発行失敗を修正。Web サービスのログでは禁止された送信元と管理画面自身のリクエストを隠せます。

## [v0.6.2.3](/ja/news/v0.6.2.3)

2026年11月2日 · ネットワークトポロジーが独立したページになり、7 種類のレイアウト、ズームとウィンドウ全体表示、カテゴリを選べるマスクを追加しました。公式サイトのトップと README のスクリーンショットは言語別になり、2 分間の紹介動画も付きます。

## [v0.6.2.2](/ja/news/v0.6.2.2)

2026年11月1日 · Web サービスにトポロジービューが加わり、信頼済みプロキシから訪問者の実 IP を取得でき、サイトごとのリアルタイム接続を表示して切断やブロックができます。ポート転送、プロトコル振り分け、STUN、frps は送信元 IP の許可リスト / ブラックリストに対応しました。ダイナミック DNS は備考をプロバイダーに書き込み、プロバイダー側のレコードも削除できます。Docker ページから Gately 自身のコンテナーをアップグレードでき、スマートフォンの Web ターミナルは長押しで選択できます。

## [v0.6.2](/ja/news/v0.6.2)

2026年10月31日 · 新しい「プロトコル振り分け」モジュールで HTTPS、SSH、RDP、OpenVPN などが 1 つのポートを共有できます。長いリストはすべてグループ分けと並べ替えに対応し、ダイナミック DNS で STUN の公開アドレスを参照でき、STUN は多段 NAT に対応しました。セキュリティも複数の点で強化されています。

## [v0.6.1.1](/ja/news/v0.6.1.1)

2026年10月30日 · 侵入防御で Web パス探索をブロックできるようになりました。新しい「認証ユーザー」ページで共有ユーザーと OIDC をまとめて管理でき、共有ユーザーは自分でパスワードを変更でき、サイトは拒否時に接続を切断できます。Cloudflare のトークン方式トンネルのルートを Gately で編集でき、ログに「除外」フィルターが加わりました。

## [v0.6.1](/ja/news/v0.6.1)

2026年10月30日 · セキュリティ修正：読み取り専用アカウントと読み取り専用 API トークンからコンテナーの環境変数と起動コマンドの平文が読めなくなりました。証明書を IPv4 のみ・IPv6 のみで発行でき、Docker ページは Gately 自身のコンテナーをアップグレード・再作成しなくなり、通知とログは管理画面の言語に従います。

## [v0.6.0.4](/ja/news/v0.6.0.4)

2026年10月29日 · OpenWrt 向け LuCI アプリを追加し、LuCI で状態の確認、サービスの開始・停止、管理ポートの設定ができます。リダイレクトサイトで `{path}`、`{1}`、`{STUN_ルール名_PORT}` などの変数が使え、全体設定の共有ユーザーと OIDC クライアントは概要表示とダイアログ編集になりました。

## [v0.6.0.3](/ja/news/v0.6.0.3)

2026年10月28日 · 信頼する PROXY 送信元から平文転送を受ける LAN 側 Gately が訪問者の HTTPS 利用を認識できず、https 発行者の OIDC ログイン失敗、Cookie の Secure 欠落、平文リダイレクトのループが起きる問題を修正しました。

## [v0.6.0.2](/ja/news/v0.6.0.2)

## [v0.6.0.1](/ja/news/v0.6.0.1)

## [v0.6.0](/ja/news/v0.6.0)

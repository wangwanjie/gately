# Gately v0.6.5.4 リリース

2026年11月11日

[ダウンロード v0.6.5.4](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.4)

## Wake-on-LAN：リモートシャットダウン

デバイスに Web ターミナルの SSH 接続を選び、シャットダウンコマンドを入力すると、デバイスカードに「シャットダウン」ボタンが表示されます（API `POST /api/wol/devices/{key}/shutdown`）。

- フォームには Linux（`shutdown -h now`）、Windows（`shutdown /s /t 0`、OpenSSH サーバーの有効化が必要）、macOS（`sudo -n shutdown -h now`）のよく使うコマンドがあります；
- その接続は Web ターミナルで一度接続してホスト鍵を記録済みである必要があり、無人の操作で未知のホストを信頼することはありません；
- シャットダウンのたびに新しい SSH 接続を作り、終了後に閉じるため、デバイス再起動前の無効な接続は使われません。コマンドは最長 30 秒、同じデバイスでは同時に 1 つだけ実行します。終了コードが返る前に接続が切れた場合はシャットダウン開始とみなします；
- API トークンでデバイスの追加・編集・複製やシャットダウンを行うには `wol:write` に加えて `webterminal:write` が、選択可能な SSH 接続の一覧には `webterminal:read` が必要です。

## Wake-on-LAN：Bemfa 音声操作

[Bemfa](https://cloud.bemfa.com) と連携すると、Xiao AI、Xiaodu、Google Assistant などの音声アシスタントでデバイスをオン・オフできます。Bemfa コンソールで `001`（コンセント）または `006`（スイッチ）で終わるトピックを作成し、デバイスに同じトピックを入力、「Wake-on-LAN → Bemfa」でユーザー秘密鍵を入力して有効にし、Mi Home や Xiaodu などのアプリで Bemfa アカウントを連携します。

「オン」でデバイスを起動、「オフ」でリモートシャットダウンし、成功するとオン・オフ状態を Bemfa に書き戻します。画面や API からの起動・シャットダウンも同様に書き戻します。Gately は MQTT 3.1.1 over TLS で `bemfa.com:9503` に接続して証明書を検証し、秘密鍵は API でマスク表示します。購読時にサーバーが再送する前回の状態は実行せず、10 秒以内に繰り返された同じ指示は 1 回だけ実行します。同じ秘密鍵でオンラインにできるクライアントは 1 つだけです。

## Web サービス：リスナーに HTTP ポートを追加

リスナーには平文 HTTP ポートを追加できます（例：443 の HTTPS リスナーに 80 を追加）。メインポートとすべてのサイト・設定を共有するため、HTTP 用に同じサイトを登録したリスナーを別に作る必要はありません。HTTPS 有効時は「HTTPS へリダイレクト」（既定。ドメイン・パス・クエリ文字列を保ち、ポートをアクセスアドレスのポートに切り替え、GET/HEAD は 301、その他のメソッドは 308）か「そのまま提供」を選べます。

- ACME HTTP-01 の検証、PROXY プロトコル、ファイアウォール自動開放もこのポートに適用されます。ポートが使用中でもメインポートは動作を続け、リスナーの状態に理由が表示されます；
- 対応するサイトのないドメインはリダイレクトせず、未知のドメインとして 404 を返すかデフォルトサイトに渡します（デフォルトサイトが「接続を切断」なら切断）。HTTPS と同じ扱いで、同一ポート HTTP のリダイレクトもこの動作になりました；
- 保存時に HTTP ポートが他のリスナーのポートと競合しないか確認します。プロトコル振り分けやポート転送経由でアクセスされるリスナーにアクセスポートが未入力の場合、編集画面で入口ポートの入力を促します。

## ナビゲーションパネル：テーマ切り替え

ナビゲーションパネルは管理画面と同じテーマ配色（Gately オリジナルとクラシック）を使い、パネルの編集時に既定のスキンを選べます。訪問者はページ右上のパレットボタンでテーマを切り替えられ、操作は管理画面と同じです：ライト・ダーク・システムに合わせる、ホバーで配色をプレビューし、クリックするとその位置から新しい配色が広がる、メインカラーと角丸のカスタマイズ。スマートフォンでは下から開きます。選択は訪問者のブラウザに保存され、パネルと管理画面が同じドメインにある場合は両方で選択が共有されます。詳しくは [Web サービス · ナビゲーションパネル](/ja/docs/modules/web#nav-panel) を参照してください。

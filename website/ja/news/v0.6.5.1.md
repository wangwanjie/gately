# Gately v0.6.5.1 リリース

2026年11月7日

[ダウンロード v0.6.5.1](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.1)

## 自動起動：gately service

バイナリで導入した場合、Gately をそのままシステムサービスとして登録できます：`sudo ./gately service install`（Windows では管理者ターミナルで `.\gately.exe service install`）。Linux では systemd サービス、macOS では launchd デーモン（`-user` で sudo なしのログイン項目）、Windows ではシステムサービスとして登録され、すぐに起動し、異常終了後は自動的に再起動されます。以後は `gately service uninstall|start|stop|restart|status` で管理し、アンインストールしても設定ディレクトリは残ります。

- Windows の既定の設定ディレクトリ `%ProgramData%\Gately` には SYSTEM と管理者だけがアクセスできます。
- プログラムや設定ディレクトリを root 以外のユーザーが変更できる場合（プログラムがまだ「ダウンロード」にあるなど）、インストール時に警告します。

[自動起動](/ja/docs/guide/install#service) を参照してください。

## 長いリストのページ表示

侵入防御のブロック一覧、Web サービスのグローバル設定にある管理画面のブロック、ストレージマウントと Docker コンテナのファイル一覧、Web ターミナルの SFTP ファイル管理がページ表示になり、1 ページ 20 / 50 / 100 / 200 件をリストごとに記憶します。4000 件のブロックがあるページの描画は約 2.6 秒から 0.23 秒になりました。検索は絞り込んでからページ分けし、定期更新とブロック解除では現在のページを保ちます。SFTP の見出しのチェックボックスは現在のページだけに作用し、見えていないファイルを誤って削除しません。

## DDNS レコードの一括追加

タスク編集の「レコード」タブに「一括追加」が加わりました。1 行に 1 ドメインで、完全なドメインかホストだけを書き、続けてタイプと値も書けます（例：`cdn.example.com CNAME target.example.net`）。追加前に、追加するレコード、スキップする重複、無効な行をプレビューし、無効な行は修正してから追加します。国際化ドメイン名は punycode に変換されます。[レコードの一括追加](/ja/docs/modules/ddns#batch) を参照してください。

## クラッシュ記録 crash.log

Gately は Go ランタイムのクラッシュ（panic、fatal error）の内容とスタックを設定ディレクトリの `crash.log` に書き込み、プロセスが強制終了された場合（メモリ不足による OOM など）は最後に生存していた時刻を記録します。次回起動時にシステムログで知らせ、診断パッケージにはマスキングして含めます。Docker、LXC、fnOS などで再起動後に標準エラー出力が残らない場合の調査に役立ちます。[診断パッケージ](/ja/docs/reference/diagnostics) を参照してください。

## その他の改善

- macOS バイナリは Developer ID 証明書で署名され Apple の公証を受けているため、ダウンロード後そのまま実行できます。確認方法は [リリース成果物の検証](/ja/docs/guide/verify) を参照してください。
- 機能リクエストのテンプレートでバージョンとシステム・アーキテクチャの記入が必須になりました。

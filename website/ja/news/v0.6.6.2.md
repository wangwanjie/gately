# Gately v0.6.6.2 リリース

2026年11月14日

[ダウンロード v0.6.6.2](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.6.2)

## EasyTier ネットワーク

「ネットワークとトンネル」に EasyTier を追加しました。`easytier-core` プロセスを管理し、このマシンを EasyTier ネットワークに参加させます。まず P2P のホールパンチングで直接接続し、つながらない場合はパブリックノードまたは自前のノード経由で中継します。

- 複数のインスタンスに対応します。各インスタンスは独立したプロセスで、同じマシンを別々のネットワークに参加させられます。
- オンラインでのインストール、更新、ロールバックに対応します。Windows のパッケージには wintun.dll などの依存ファイルが含まれます。
- ネットワークシークレットは環境変数でプロセスに渡され、コマンドラインには現れず、ログではマスクされます。ローカルサブネットの共有や出口ノードとして動作させる場合はシークレットが必須です。
- インスタンスのカードに仮想 IP、リッスンアドレス、ノード一覧（直接 / 中継、遅延、接続プロトコル）を表示します。TUN デバイスを作成できない場合やプロセスが起動直後に終了した場合は、その理由を表示します。
- 有効なインスタンスが同じポートをリッスンする場合、ポートフォワードが同じローカルポートにバインドされる場合、デバイス名が重複する場合は保存を拒否します。

詳しくは [Tailscale / NetBird / EasyTier / frp / cloudflared](/ja/docs/modules/tunnels) を参照してください。

## 侵入防御

- **TLS ハンドシェイク失敗ルール（#90）**：ログルールにソース「TLS ハンドシェイク失敗」を追加しました。Web サービスの HTTPS リスナーでのハンドシェイク失敗を、失敗の種類・リスナー・回数でカウントしてブロックします。ハンドシェイク途中で切断（EOF）、接続リセット、ハンドシェイクタイムアウト、TLS 以外またはプロトコルエラー、パラメータをネゴシエートできない、未知のドメイン、クライアントが中止などの種類を個別に選べます。「TLS 異常ハンドシェイク」（1 分間に 5 回で 1 日ブロック）と「TLS ハンドシェイク中断」（1 分間に 20 回）の 2 つのテンプレートを内蔵し、ルール編集画面では失敗理由を貼り付けて分類を確認できます。送信元が Web サービスの「信頼プロキシ」にあるアドレス（CDN のオリジン取得ノード）の場合は数えません。
- **ポートスキャン検出がモジュールのポートを認識**：Gately の各モジュールはリッスンに成功するとすぐにポートを開放として登録し、300 ミリ秒以内に反映されます。frps のバインド、vhost、外部公開 dashboard、allowPorts の範囲、frpc がログイン後に申請するリモートポート、EasyTier のリッスンとポートフォワード、Tailscale と NetBird の外部向け SOCKS5 ポートが登録されます。リッスンを止めたポートも 10 分間は開放として扱うため、frpc の再接続中やプログラムの再起動中の通常の訪問者がポートスキャンとしてブロックされることはありません。

詳しくは [侵入防御](/ja/docs/modules/guard) を参照してください。

## 通知：新しいアドレスからのログイン（#92）

通知イベント「管理画面：新しいアドレスからのログイン」（`login.newip`、警告レベル）を追加しました。管理画面へのログインに成功し、その送信元アドレスがこれまでログインに成功したことのないものであるときに発行されます。「セキュリティとログイン」テンプレートに含まれています。パスワード、Passkey、サードパーティログイン、fnOS 統合ゲートウェイログインのすべてを確認します。初回のログインは基準の記録のみ行い、IPv6 は /64 単位でまとめ、最大 200 件の送信元を記録します。詳しくは [通知センター](/ja/docs/modules/notify) を参照してください。

## その他の改善

- 読み取り専用アカウントと読み取り専用 API トークンで管理対象プログラムの設定を表示すると、環境変数は名前のみ表示され、追加引数は全体が非表示になります。
- ログイン画面でユーザー名またはパスワードが空の場合、リクエストを送らずにその場で通知します。
- 一覧カードの操作ボタンをカード下部に固定し、高さの異なるカードでもボタンが揃うようにしました。幅の狭いカードではフィールドを 2 列で表示します。

## アップグレードの注意

- Docker は新しいイメージを pull してコンテナを再作成します。OpenWrt は新しい `.apk` / `.ipk` を上書きインストールします。fnOS はアプリセンターで新しい `.fpk` を手動インストールします。その他の環境では「システム設定」からオンラインでアップグレードできます。
- 既存の侵入防御ルールと通知ルールは影響を受けません。新しいアドレスからのログイン通知を使うには、通知センターで `login.newip` のルールを追加するか、「セキュリティとログイン」テンプレートをもう一度適用してください。

# Gately v0.6.2.1 リリース

2026年11月1日

[v0.6.2.1 をダウンロード](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.1)

## 信頼済みプロキシの背後での訪問者の実 IP（#50）

Web サービスの「全体設定」に「訪問者の実 IP」が加わりました。CDN や WAF など信頼済みプロキシのオリジン向けアドレスまたは範囲を入力し、実 IP ヘッダーを順番に選びます（`CF-Connecting-IP`、`X-Forwarded-For`、`X-Real-IP`、`True-Client-IP` またはカスタム名）。これらのヘッダーは直接の接続元が信頼済みプロキシのときだけ読み取り、直接接続してきた訪問者が送ったヘッダーは無視します。`X-Forwarded-For` は右から左へ読み、信頼済みプロキシを飛ばします。得られたアドレスはアクセスログ、IP リスト、LAN 限定アクセス、国フィルター、ブロック、統計、バックエンドへ送るヘッダーに使われます。Cloudflare では `CF-Connecting-IP` を推奨します。詳しくは [Web サービス](/ja/docs/modules/web) を参照してください。

## サイトごとのリアルタイム接続（#51）

サイト一覧の各ドメイン行に処理中のリクエスト数が表示され、「接続」ウィンドウは 2 秒ごとに更新されます。

- リアルタイム一覧には送信元アドレス、プロトコル（h1 / h2 / h3、WebSocket は個別に表示）、メソッドとパス（クエリ文字列を除く）、経過時間、上り下りの通信量が表示され、IP で検索できます。
- 履歴には、1 秒以上続いたリクエストと手動で切断したリクエストをサイトごとに最新 200 件保持します（メモリ上のみ）。
- 1 件のリクエストを切断できます（HTTP/2 と HTTP/3 ではそのストリームだけをリセット）。切断と同時に送信元アドレスをブロックすることもでき、その場合はすべてのサイト上のそのアドレスのリクエストも切断します。自分が現在使っているアドレス、ループバックアドレス、信頼済みプロキシはブロックできません。

## 送信元 IP アクセス制御（#49）

ポート転送、プロトコル振り分け、STUN の内蔵転送、frps インスタンスで、それぞれ許可リストまたはブラックリストを使えます。リストは手入力の IP / サブネットと Web サービスの購読 IP リストで構成し、購読リストが更新されるとルールを再起動せずにすぐ反映されます。

- 侵入防御のブロックを最初に確認し、その後にリストを確認します。
- ルールカードにはアクセスモードと拒否回数が表示され、IP リストのページにはそのリストを参照しているルールが表示されます。参照中のリストは削除できません。
- frps のリストは frpc のログイン時に確認され、バインドポートを保護します。
- Lucky からポート転送と STUN のルールをインポートすると、安全モードは送信元 IP アクセス制御に変換されます（同じインポートで `lucky_ipfilter.lkcf` をアップロードしてください）。

詳しくは [ポート転送](/ja/docs/modules/portforward) と [Tailscale / frp / cloudflared](/ja/docs/modules/tunnels) を参照してください。

## サイトのリンク（#52）

サイト一覧の具体的なドメインはそれぞれ新しいタブで開け、横のボタンでスキームとポートを含む完全な URL をコピーできます。訪問者がプロトコル振り分け、ポートマッピング、frp、CDN を経由してくる場合は、リスナーに公開アクセスアドレスを設定できます。frpc の http / https プロキシ、File Browser のアクセス URL、Cloudflare クイックトンネルのアドレス、Tailscale のログインリンクも同じように開いてコピーできます。ドメインはブラウザーが送る形式（小文字、国際化ドメインは punycode）で保存され、ポートやパスを含むなど決して一致しない値は拒否されます。

## ダイナミック DNS

- レコードの備考（空欄ならタスクの備考）を Alibaba Cloud、Cloudflare、Tencent Cloud、DNSPod、Huawei Cloud に書き込みます。
- レコードやタスクを削除するとき「DNS プロバイダーからも削除」を選べます（14 のプロバイダーが対応）。削除するのは、値が Gately の最後の同期結果と一致するレコードだけです。値が不明な場合、コンソールで変更された場合、レコードセットにほかの値がある場合は削除せず、理由を表示します。
- モジュールのスイッチは「全体設定」に移り、そこで削除チェックボックスの既定値も設定できます。

## その他の改善

- Docker ページから Gately 自身が動いているコンテナーをアップグレードできます。まず新しいイメージを pull し、新しいバージョンがある場合だけ一時的な補助コンテナーがコンテナーを作り直し、新しいコンテナーの起動に失敗したら古いコンテナーを復元します。Web ターミナルのローカルシェルが Gately のコンテナー内で動いているときは、この操作を案内します。
- スマートフォンで Web ターミナルを約 0.5 秒長押しすると選択モードになり、システムの選択ハンドルとコピーメニューを使えます。折り返された行はコピー時に 1 行に戻ります。キーバーに貼り付けキーが加わり、HTTP 接続では貼り付けパネルが開き、このタブで最近コピーまたは入力した 10 件のテキストを再送信できます。リモートのプログラムがブラケットペーストを有効にしていないときに複数行を貼り付けると、先に確認します。
- 認証ユーザーページで、共有ユーザーだけで認証しているサイトを解除できます。それらのサイトの認証をオフにする前に確認します。
- プロトコル振り分けのルールを編集しても、プロトコル、ドメイン、ALPN が変わらないルートはヒット数を保持します。
- ネットワーク診断の速度テストは 1 リクエストあたり 50 MB を要求するようになり、Cloudflare の HTTP 403 を解消しました。Vultr、Hetzner、OVH のテストノードを追加し、タスク名には現在のツールの対象だけを表示します。
- リスト外の訪問者の接続を切断するデフォルトサイトでの拒否は、Web パス探索で 444 として数えます（#53）。
- セキュアエントリーを設定していても、iOS のホーム画面アイコンが文字のプレースホルダーになりません。

## 修正と強化

- Web ターミナルは貼り付けたテキストから制御文字を取り除くため、埋め込まれたブラケットペースト終了シーケンスで複数行の確認を回避できません。システムのクリップボードから直接読み取ったテキストはクリップボード履歴に追加せず、履歴はサインアウト時やセッションの期限切れ時に消去します。
- リクエストが終わる瞬間に切断しても、同じ接続上の次のリクエストに影響しません。
- Gately 自身のアップグレード中に始めた 2 回目のアップグレードは拒否します。アップグレード用の補助コンテナーは匿名ボリュームとともに削除し、1 台の Docker ホスト上の複数の Gately はそれぞれ自分の補助コンテナーだけを扱います。
- ダイナミック DNS のタスク編集で「DNS プロバイダーからも削除」をオンにしてレコードを削除する場合、保存する設定を先に検証し、検証に失敗したらプロバイダー側では何も削除しません。Tencent Cloud の同期はホストレコードを完全一致で照合します。
- ページを離れると接続ウィンドウと統計ウィンドウはポーリングを止めます。ブロックに失敗してもブロックのダイアログは閉じません。frp のサブドメインは IPv6 アドレスを拒否します。ブラックリストモードの Lucky ルールをインポートしてリストが見つからないときは警告します。

## アップグレードの注意

- Docker は新しいイメージを pull してコンテナーを作り直してください。Docker ソケットをマウントしている場合は、Gately の Docker ページから Gately 自身をアップグレードすることもできます。OpenWrt は新しい `.apk` / `.ipk` を上書きインストールしてください。fnOS はアプリセンターで新しい `.fpk` を手動でインストールしてください。その他の環境は「システム設定」からオンラインでアップグレードできます。

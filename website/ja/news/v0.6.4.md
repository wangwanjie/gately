# Gately v0.6.4 リリース

2026年11月3日

[v0.6.4 をダウンロード](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.4) · [オンラインでカスタムビルド](https://build.gately.cn)

## カスタムビルド

ポート転送、Web サービス、SSL 証明書の 3 つのコアモジュールを除く 22 個のモジュールはコンパイル時に外せます。UI 言語も簡体字中国語のみ、または簡体字中国語・繁体字中国語・英語の 3 言語に絞れます。

- [build.gately.cn](https://build.gately.cn) を開いてモジュールと言語を選ぶと（「Core only」「Router」「NAS」のプリセットから始めることもできます）、ページがサイズをリアルタイムに見積もり、Linux / Windows / macOS / FreeBSD のバイナリ、OpenWrt と fnOS のパッケージ、または amd64・arm64・arm/v7 のマルチアーキテクチャ Docker イメージをオンラインで生成します。同じ選択の成果物は再利用され、改めてビルドする必要はありません。
- linux/arm64 の例：フル版は 33.6 MB、コアのみは約 19.9 MB、Router プリセットと簡体字中国語の組み合わせは約 21.2 MB です。Router プリセットと簡体字中国語の Docker イメージは pull サイズ約 18.7 MB（フルイメージは 51.9 MB）で、Docker 管理と侵入防御を含まないイメージには docker-cli、compose、nftables も入りません。
- コンパイルに含めなかったモジュールの設定ファイルはそのまま残り、設定のスイッチと API トークンの権限も引き続き有効です。その API は 404 を返してこのビルドに含まれていないことを伝え、UI は該当するページと項目を隠します。フル版に戻すと元どおりになります。
- 「バージョン情報」ページには、このビルドで外したモジュールの一覧と、同じ選択でビルダーを開くリンクが表示されます。カスタムビルドはオンラインアップグレードに対応しません（オンラインアップグレードはフル版をダウンロードするため）。新しいバージョンが出たら同じ選択で生成し直し、アップグレードパッケージをアップロードしてください。
- 自分でコンパイルする場合は、`no_<モジュール>` と `lang_zh` / `lang_cjken` の build tag、フロントエンドの `GATELY_LOCALES`、または Dockerfile の `GATELY_TAGS` などのビルド引数を使います。`tools/custombuild` は選択内容をこれらのパラメーターに変換します。

詳しくは [モジュール一覧 · カスタムビルド](/ja/docs/modules/#custom-build) と [ソースからビルド](/ja/download#custom-build) を参照してください。

## 管理ポートを隠す

「設定 → アクセス制御」に「未認可アクセスへの応答」を追加しました。ブロック中の送信元、LAN 限定アクセスを有効にしているときの外部からのアクセス、セキュアエントリーを通っていないリクエストに適用されます。

- 既定の案内ページ、通常の 404、空白ページ、接続を切断、タイムアウトまで応答しない、またはカスタム HTML ページ（ステータスコードを指定可能）から選べます。
- 切断と無応答は接続の確立時に送信元で判定するため、HTTPS は証明書も送りません。信頼できるプロキシ経由のリクエストは自動的に通常の 404 に切り替わり、前段のプロキシがエラーページを表示するのを防ぎます。保留中の接続には時間と数の上限があります。
- 隠す方式では、管理画面に固有のセキュリティ応答ヘッダーを付けなくなり、カスタムページはスクリプトと外部リソースを禁止したサンドボックス内で表示されます。

ポート自体はスキャンで見つかるため、完全に隠すにはファイアウォールとの併用が必要です。詳しくは [ハードニングの推奨事項](/ja/docs/guide/hardening) を参照してください。

## サイトのエラーページ

- Web サービスのサイトの「エラーページ」タブで、Gately が生成する 404 と 5xx のページに、標準スタイル、10 種類の組み込みスタイル（ミニマル、ターミナル、ネオン、星空、新聞、ブルータリスト、オーロラ、ピクセル、設計図、ステータスチェーン）、またはページライブラリのカスタムページを選べます。各スタイルにはサムネイルとデスクトップ / モバイルのプレビューがあります。
- ページライブラリには HTML をアップロード・貼り付けするか、サーバー上の `.html` ファイルを参照できます。保存時にスクリプト、イベント属性、フォームなどを検査して取り除き、`{code}`、`{title}`、`{host}`、`{path}` などのプレースホルダーに対応し、出力にはスクリプトと外部リソースを禁止する CSP を付けます。
- リバースプロキシのサイトでは、バックエンドの特定のステータスコード（`404, 500-599` など）をインターセプトし、ブラウザーがページを開くリクエストだけを置き換えます。API リクエストはそのまま返します。
- デフォルトサイトの設定は、どのサイトにも一致しないリクエストにも使われます。「並べ替え・一括」でエラーページのスタイルを一括設定できます。

詳しくは [Web サービス · エラーページ](/ja/docs/modules/web#error-pages) を参照してください。

## その他の改善

- ダイナミック DNS の検索をレコード単位で絞り込むようにしました。タスクの名前、グループ、備考、プロバイダーが一致する場合はすべてのレコードを、それ以外は一致したレコードだけを表示し、検索中は折りたたまれたタスクとグループを自動で展開します。Web サービスの検索では折りたたまれたリスナーを自動で展開します。
- 設定ページの長いラベルは自動で折り返し、ドイツ語やロシア語などで入力欄と重ならなくなりました。
- 管理画面のリクエストが JSON 以外の応答を受け取った場合（セッション期限切れ後にセキュアエントリーでブロックされたときなど）、再読み込みまたはセキュアエントリーを開き直すよう案内します。
- 既定のエラーページの「再読み込み」を通常のリンクにし、スクリプトを禁止する CSP でも使えるようにしました。
- 診断パッケージと `GET /api/status`、`GET /api/system/info` にビルド情報（カスタムビルドかどうか、含まれるモジュールと言語）を加えました。
- CI にプリセットの build tag の組み合わせのチェックを追加しました。

## アップグレードの注意

- Docker は新しいイメージを pull してコンテナを再作成します。Docker ソケットをマウントしている場合は、Gately の Docker ページから Gately 自身をアップグレードすることもできます。OpenWrt は新しい `.apk` / `.ipk` を上書きインストールします。fnOS はアプリセンターで新しい `.fpk` を手動でインストールします。その他のデプロイ方法では「バージョン情報」ページからオンラインでアップグレードできます。
- フル版を使っている場合は何もする必要はなく、設定形式にも変更はありません。

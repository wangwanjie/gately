# Tutorials

Each tutorial starts from a concrete goal and walks you through the admin UI step by step, with ways to check the result and common problems. If Gately isn't installed yet, start with [Installation](/en/docs/guide/install). To look around first, open the [online demo](https://demo.gately.cn) and use the one-click read-only demo account (data resets every hour).

Screenshots come from a demo instance; domains and addresses are example values (`example.com`, `192.0.2.x`, `203.0.113.x`). Replace them with your own.

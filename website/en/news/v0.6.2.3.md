# Gately v0.6.2.3 released

November 2, 2026

This is an improvement update in the v0.6.2 series. The configuration format is unchanged.

[Download v0.6.2.3](/en/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.3)

## Network topology on its own page

The topology moves from a tab on the Web Services page to a Network topology page under Web in the side menu, with a button on the Web Services page that opens it. The statistics and connections dialogs open on the topology page, and Edit goes to the Web Services page and opens the site editor. The canvas follows the light or dark mode of the current skin.

## Seven layouts

The layout menu offers Tree, Vertical, Radial, Sankey, Sunburst, Treemap and Bubbles, each with an icon and a one-line description; switching fades and the choice is remembered. Each listener shows its first 8 sites and each site its first 6 backends, and the rest merge into a summary node with their combined traffic and requests in flight that expands in place. In layouts without fold buttons, listeners can be folded from the details panel.

## Zoom, full-window mode and canvas height

Drag the canvas to pan. Scroll moves the page; Ctrl / ⌘ + wheel, trackpad pinch or two-finger pinch zooms between 15% and 250%. The controls at the bottom right zoom out, show the zoom level (click for 100%), zoom in, fit to canvas and toggle the full-window mode, which closes with Esc. A bar under the canvas resizes its height, remembered per device; double click it or choose Auto height to restore.

## Mask by category

Masking lets you choose categories: visitor IPs, backend addresses, listen addresses and domains. The first three are selected by default, so screenshots and live streams hide what you need.

## Screenshots and tour video

The home page and the READMEs in all 10 languages show screenshots of the interface in the matching language, a topology animation is added, and the top of each README links to a 2 minute silent tour video.

## Other

- Removed a leftover comment from the old List / Topology switch.

## Upgrading

- Docker: pull the new image and recreate the container. OpenWrt: install the new `.apk` / `.ipk` over the old one. fnOS: install the new `.fpk` in the App Center. Other installs can upgrade online in Settings.

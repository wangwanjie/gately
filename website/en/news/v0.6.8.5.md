# Gately v0.6.8.5 released

November 23, 2026

[Download v0.6.8.5](/en/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.5)

## IP location (#107)

- Wherever the admin UI lists IP addresses it now shows their location from the imported GeoIP database: visitor audit, top source IPs in site statistics, live connections, the ban lists of the Web service and intrusion protection, module logs, active IPs in the network topology (hidden while masking is on), the operation audit and addresses allowed by port knocking. Site statistics show country names.
- The GeoIP database can be uploaded or downloaded as a `.mmdb.gz` (as DB-IP publishes it) or the `.tar.gz` MaxMind provides; the decompressed size limit is raised to 256 MB (the DB-IP city database is about 127 MB).

## Several single sign-on domains (#108)

- For an instance that serves sites under more than one parent domain, several single sign-on domains can be configured. Each domain and its subdomains share the sign-in and Passkeys within that domain; domains cannot contain one another.
- SSO sessions record their domain and are accepted only on sites in it; sessions from earlier versions keep working. The single `ssoDomain` of older configs is merged into the list. The users page takes a comma or space separated list.

## Sign-in page styles

- The sign-in, password change and Passkey pages (including the OIDC issuer's sign-in page) can change appearance. Besides the default style there are 9 built-in styles: Lock screen, Split, Minimal, Terminal, Letter, Brutalist, Aurora, Pixel and Blueprint.
- Default, Split, Minimal and Letter follow the visitor's light or dark mode, Brutalist is light only and the rest are dark only.

## Fixes

- **fnOS gateway**: saving settings and other state-changing requests work again when Gately is opened over a plain HTTP address (fnOS port 5000/5666, or the fnOS app with HTTPS turned off); they were rejected with "cross-origin request refused".
- **Docker**: the floating task panel no longer covers the last container's action buttons; a spacer as tall as the panel is added at the end of the page (#110).

## Upgrade notes

- Docker: pull the new image and recreate the container; OpenWrt: install the new `.apk` / `.ipk` over the old one; fnOS: install the new `.fpk` manually in the App Center; other deployments can upgrade online from System settings.

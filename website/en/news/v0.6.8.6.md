# Gately v0.6.8.6 released

November 23, 2026

[Download v0.6.8.6](/en/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.6)

## Topology upload rate and averaging period (#113)

- Sites, backends and listener actions now report an upload rate next to the download rate: for sites the bytes visitors send (request bodies, and data visitors send after a WebSocket or other upgrade), for backends the request body bytes forwarded to them.
- In the details panel the "60 s average" card is replaced by Up, next to Down, and a new "Averaging period" select switches QPS, Up and Down between the last 1, 5, 10, 30 and 60 seconds (default 10, remembered per device). Replay always uses the recorded 10 seconds.
- The toolbar shows both directions and wraps on narrow screens; the per-second traffic chart draws upload and download as two lines.
- `GET /api/webservice/topology` accepts `window=1..60`, node rates include `upBps`, and `qps60` is still returned.

## SMTP certificate verification (#115)

- SMTP notification channels have a "Skip certificate verification" option for STARTTLS and SSL/TLS, for self-hosted mail servers whose certificate is self-signed or does not match the server address (such as a default certificate valid only for localhost). It is off by default.

## Windows overview

- On Windows the overview shows CPU model and usage, memory and page file, disk, uptime, Windows edition and build, network traffic and rates, and the memory, CPU and threads of Gately and its managed processes. Windows has no load average, so that field stays empty.

## Fixes

- **Overview**: a running container whose health check fails is counted as running and listed under its own "Unhealthy" count on the Docker row; "Abnormal" only counts restarting, dead and non-zero exited containers (#114).
- **Docker**: containers whose health check fails show an "Unhealthy" warning badge on their card, in the detail header and on the overview tab, and the container list has a "Problem" filter (#114).
- **Network topology**: the fold button on listener cards points where the children go when clicked: left/right in the tree layout, up/down in the vertical layout, minus/plus in the radial layout (#113).

## Upgrade notes

- Docker: pull the new image and recreate the container; OpenWrt: install the new `.apk` / `.ipk` over the old one; fnOS: install the new `.fpk` manually in the App Center; other deployments can upgrade online from System settings.

# 목록 그룹, 정렬, 일괄 작업과 복제

항목이 많은 목록은 그룹화, 수동 정렬, 검색, 일괄 작업을 할 수 있으며 조작 방법은 모든 페이지에서 같습니다. 순서와 그룹은 관리 화면의 표시에만 영향을 주며, 변경해도 실행 중인 인스턴스가 재시작되거나 연결이 끊기지 않습니다.

## 지원하는 목록

| 페이지 | 목록 |
| --- | --- |
| 동적 DNS | 작업, 작업 안의 DNS 레코드 |
| STUN 홀 펀칭 | 규칙 |
| 포트 포워딩 | 규칙 |
| SSL 인증서 | 인증서 |
| Web 서비스 | 리스너 안의 사이트(리스너 자체는 위아래로 이동 가능) |
| WAF 방화벽 | 인스턴스 |
| 침입 방지 | 로그 규칙 |
| frp | frpc 인스턴스, frps 인스턴스, 프록시 |
| Cloudflare 터널 | 터널 |
| File Browser | 인스턴스 |
| 스토리지 마운트 | 마운트 |
| Wake-on-LAN | 기기 |
| 예약 작업 | 작업 |
| 알림 센터 | 채널, 규칙 |

이 목록들은 대부분 '카드 보기'와 '간결히 보기'를 함께 제공하며 목록 오른쪽 위에서 전환합니다. 좁은 화면에서는 카드 보기로 고정됩니다.

## 그룹

편집 대화 상자에서 '그룹'을 입력합니다(최대 64자, 기존 그룹에서 선택 가능). 비워 두면 그룹 없음이 됩니다. 그룹이 설정된 항목이 하나라도 있으면 목록은 그룹별로 접을 수 있는 구역으로 표시됩니다. 그룹은 처음 나타난 순서대로 정렬되고, 그룹 없는 항목은 맨 뒤에 놓이며, 각 그룹의 접힘 상태는 브라우저에 저장됩니다. 검색창에서는 이름, 그룹, 메모 등으로 항목을 걸러 낼 수 있고, 검색하는 동안에는 모든 그룹이 펼쳐집니다.

그룹 제목에 마우스를 올리고 연필 버튼을 누르면 그룹 이름을 바꿀 수 있습니다. 그룹 안의 항목이 함께 새 이름으로 바뀌고 위치와 순서는 그대로 유지됩니다. 기존 그룹의 이름으로 바꾸면 확인 후 두 그룹이 합쳐집니다.

## 정렬 모드

'정렬 및 일괄'을 누르면 정렬 모드로 들어갑니다. 이때는 모든 항목이 표시되고 검색과 필터는 잠시 적용되지 않습니다.

- 화살표로 그룹 안에서 항목을 위아래로 옮기거나, 그룹 제목에서 그룹 전체를 옮깁니다.
- 데스크톱에서는 항목을 바로 끌어 놓을 수 있으며, 다른 그룹의 항목이나 그룹 제목 위에 놓으면 그 그룹에 들어갑니다.
- 여러 항목을 선택한 뒤(그룹 제목의 체크박스로 그룹 전체를 선택할 수 있음) 그중 하나를 끌면, 선택한 모든 항목이 현재 순서대로 함께 이동합니다.
- 도구 모음의 '그룹으로 이동'으로 선택한 항목을 지정한 그룹에 한꺼번에 옮길 수 있으며, 비워 두면 그룹에서 빠집니다.

휴대폰 등 좁은 화면에서는 끌어 놓기를 지원하지 않으므로 화살표와 도구 모음으로 같은 작업을 합니다.

## 일괄 작업

정렬 모드에서 항목을 선택하면 도구 모음에서 다음 작업도 할 수 있습니다.

- **사용 / 사용 안 함**: 선택한 모든 항목을 한 번에 저장하며, 이미 목표 상태인 항목은 재시작하지 않습니다.
- **삭제**: 확인 대화 상자에 삭제할 항목이 나열되며, 삭제하면 되돌릴 수 없습니다. 삭제할 수 없는 항목이 하나라도 있으면(예: 사이트가 아직 사용하는 인증서) 아무것도 삭제하지 않고 이유를 알려 줍니다.

일괄 작업은 한 번에 최대 500개 항목을 처리합니다. 모든 항목이 검증을 통과해야 저장되며, 하나라도 실패하면 아무것도 바뀌지 않습니다. Wake-on-LAN 기기에는 사용 스위치가 없어 일괄 삭제만 제공합니다. API 토큰은 아직 일괄 사용·사용 안 함·삭제를 제공하지 않습니다. Web 서비스에는 도메인과 옵션 일괄 변경도 있으며, [Web 서비스](/ko/docs/modules/web#일괄-작업)를 참고하세요. 사이트를 다른 리스너로 옮길 수도 있습니다. [사이트 이동](/ko/docs/modules/web#move-sites)을 참고하세요.

## 항목 복제

API 토큰을 제외한 위 표의 항목은 모두 "복제"할 수 있으며, 구독 IP 목록, 백업 대상, Web 터미널 인증 프리셋, DDNS 작업 안의 레코드, Web 서비스 리스너 안의 사이트도 복제할 수 있습니다. 항목의 "복제"를 누르면 해당 항목을 템플릿으로 추가 대화상자가 열리고 이름에 "사본"이 붙습니다. 구분해야 하는 설정을 바꾼 뒤 저장하면 새 항목이 추가되며, 원래 항목은 바뀌지 않고 사본은 원래 항목 바로 뒤에 놓입니다.

- **비밀 값은 원래 항목에서 가져옴**: 저장된 비밀번호, 토큰, 개인 키는 대화상자에서 가려진 채로 표시됩니다. 바꾸지 않으면 원래 항목의 값을 사용하며 평문은 브라우저를 거치지 않습니다. 눈 버튼으로 원래 항목의 평문을 볼 수 있습니다. Web 터미널 연결과 인증 프리셋은 사용자 약관 동의와 2단계 인증을 거쳐야 비밀 값을 이어받습니다.
- **시스템이 관리하는 내용은 복제하지 않음**: ACME로 발급받거나 파일에서 읽는 인증서는 사본의 설정으로 다시 발급하거나 읽어 오며, 업로드한 인증서는 개인 키와 함께 복제됩니다. 인증서 배포 기록은 지워지고, 구독 IP 목록은 다시 내려받습니다. 사이트의 공유 링크는 토큰으로 인증을 우회할 수 있으므로 복제하지 않습니다.
- **인증서 배포 대상**: 원본 인증서와 같은 파일에 쓰지 않도록 사본에서는 배포 대상을 비활성화합니다. 파일 이름이 겹치지 않는지 확인한 뒤 활성화하세요.
- **Web 서비스**: 사이트를 복제할 때 다른 리스너 아래에 둘 수 있습니다(예: HTTP 리스너에서 HTTPS 리스너로). 리스너를 복제할 때는 안의 사이트도 함께 복제할지 고를 수 있습니다.
- 사본은 원래 항목의 활성화 상태를 그대로 가집니다. 원래 항목과 충돌하지 않도록 저장하기 전에 포트, 도메인, 레코드 등 구분해야 하는 설정을 바꾸세요.

## 페이지별 보충 설명

- **동적 DNS**: 작업 카드의 '레코드 정렬'을 누르면 대화 상자가 열리며 해당 작업 안의 DNS 레코드 순서와 그룹을 조정합니다. 저장하면 바로 적용되고 다시 동기화하지 않습니다. 작업을 편집할 때도 'DNS 레코드' 탭에서 같은 대화 상자를 열 수 있으며 작업과 함께 저장됩니다. 레코드에 그룹이 설정되어 있으면 카드의 레코드가 그룹별로 표시되고 그룹마다 따로 접을 수 있습니다.
- **frp**: 프록시 목록은 frpc 인스턴스로 걸러 낼 수 있습니다. 정렬 모드에서는 모든 프록시가 표시되며 전체 순서를 조정합니다.
- **API 토큰**: 수동으로 정렬하기 전에는 생성 시간 기준 최신순으로 표시됩니다. 순서를 조정한 뒤에는 저장된 순서대로 표시되며 새로 만든 토큰은 맨 앞에 놓입니다.
- **인증 사용자**: '공유 사용자를 쓰는 사이트'는 리스너별로 표시되고, 리스너 안의 사이트는 다시 Web 서비스의 그룹별로 분류됩니다. 리스너와 그룹은 각각 따로 접을 수 있으며, 도구 모음에서 한 번에 모두 접거나 펼칠 수 있습니다.

## API

일반 목록 API는 모두 순서를 바꾸는 `PUT <목록 경로>-order`(요청 본문 `{"keys": [...]}`, 모든 항목을 포함해야 함)와 그룹을 일괄 설정하는 `PUT <목록 경로>-group`(요청 본문 `{"keys": [...], "group": "..."}`), 일괄 사용·사용 안 함을 위한 `PUT <목록 경로>-enable`(요청 본문 `{"keys": [...], "enable": true}`), 일괄 삭제를 위한 `POST <목록 경로>-delete`(요청 본문 `{"keys": [...]}`)를 제공합니다. 예: `PUT /api/stun/rules-group`, `POST /api/portforward/rules-delete`. DDNS 작업 안의 레코드는 `PUT /api/ddns/tasks/{key}/records-layout`을, API 토큰은 `PUT /api/tokens/order`와 `PUT /api/tokens/group`을 사용합니다. 자세한 내용은 [API 레퍼런스](/ko/docs/reference/api-reference)를 참고하세요.

항목 복제는 `POST <목록 경로>/{key}/copy`를 사용합니다. 요청 본문은 새 항목이며, 자리표시자 `********`로 남아 있는 비밀 값은 `{key}` 항목의 값을 이어받습니다(예: `POST /api/frp/clients/{key}/copy`).

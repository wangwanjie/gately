# 목록 그룹과 정렬

항목이 많은 목록은 그룹화, 수동 정렬, 검색을 할 수 있으며 조작 방법은 모든 페이지에서 같습니다. 순서와 그룹은 관리 화면의 표시에만 영향을 주며, 변경해도 실행 중인 인스턴스가 재시작되거나 연결이 끊기지 않습니다.

## 지원하는 목록

| 페이지 | 목록 |
| --- | --- |
| 동적 DNS | 작업, 작업 안의 DNS 레코드 |
| STUN 홀 펀칭 | 규칙 |
| 포트 포워딩 | 규칙 |
| SSL 인증서 | 인증서 |
| Web 서비스 | 리스너 안의 사이트(리스너 자체는 위아래로 이동 가능) |
| WAF 방화벽 | 인스턴스 |
| 침입 방지 | 로그 규칙 |
| frp | frpc 인스턴스, frps 인스턴스, 프록시 |
| Cloudflare 터널 | 터널 |
| File Browser | 인스턴스 |
| 스토리지 마운트 | 마운트 |
| Wake-on-LAN | 기기 |
| 예약 작업 | 작업 |
| 알림 센터 | 채널, 규칙 |
| Web 터미널 | 저장된 연결 |
| API 토큰 | 토큰 |

이 목록들은 대부분 '카드 보기'와 '간결히 보기'를 함께 제공하며 목록 오른쪽 위에서 전환합니다. 좁은 화면에서는 카드 보기로 고정됩니다.

## 그룹

편집 대화 상자에서 '그룹'을 입력합니다(최대 64자, 기존 그룹에서 선택 가능). 비워 두면 그룹 없음이 됩니다. 그룹이 설정된 항목이 하나라도 있으면 목록은 그룹별로 접을 수 있는 구역으로 표시됩니다. 그룹은 처음 나타난 순서대로 정렬되고, 그룹 없는 항목은 맨 뒤에 놓이며, 각 그룹의 접힘 상태는 브라우저에 저장됩니다. 검색창에서는 이름, 그룹, 메모 등으로 항목을 걸러 낼 수 있고, 검색하는 동안에는 모든 그룹이 펼쳐집니다.

그룹 제목에 마우스를 올리고 연필 버튼을 누르면 그룹 이름을 바꿀 수 있습니다. 그룹 안의 항목이 함께 새 이름으로 바뀌고 위치와 순서는 그대로 유지됩니다. 기존 그룹의 이름으로 바꾸면 확인 후 두 그룹이 합쳐집니다.

## 정렬 모드

'정렬'을 누르면 정렬 모드로 들어갑니다. 이때는 모든 항목이 표시되고 검색과 필터는 잠시 적용되지 않습니다.

- 화살표로 그룹 안에서 항목을 위아래로 옮기거나, 그룹 제목에서 그룹 전체를 옮깁니다.
- 데스크톱에서는 항목을 바로 끌어 놓을 수 있으며, 다른 그룹의 항목이나 그룹 제목 위에 놓으면 그 그룹에 들어갑니다.
- 여러 항목을 선택한 뒤(그룹 제목의 체크박스로 그룹 전체를 선택할 수 있음) 그중 하나를 끌면, 선택한 모든 항목이 현재 순서대로 함께 이동합니다.
- 도구 모음의 '그룹으로 이동'으로 선택한 항목을 지정한 그룹에 한꺼번에 옮길 수 있으며, 비워 두면 그룹에서 빠집니다.

휴대폰 등 좁은 화면에서는 끌어 놓기를 지원하지 않으므로 화살표와 도구 모음으로 같은 작업을 합니다.

## 페이지별 보충 설명

- **동적 DNS**: 작업 카드의 '레코드 정렬'을 누르면 대화 상자가 열리며 해당 작업 안의 DNS 레코드 순서와 그룹을 조정합니다. 저장하면 바로 적용되고 다시 동기화하지 않습니다. 작업을 편집할 때도 'DNS 레코드' 탭에서 같은 대화 상자를 열 수 있으며 작업과 함께 저장됩니다. 레코드에 그룹이 설정되어 있으면 카드의 레코드가 그룹별로 표시되고 그룹마다 따로 접을 수 있습니다.
- **frp**: 프록시 목록은 frpc 인스턴스로 걸러 낼 수 있습니다. 정렬 모드에서는 모든 프록시가 표시되며 전체 순서를 조정합니다.
- **API 토큰**: 수동으로 정렬하기 전에는 생성 시간 기준 최신순으로 표시됩니다. 순서를 조정한 뒤에는 저장된 순서대로 표시되며 새로 만든 토큰은 맨 앞에 놓입니다.
- **인증 사용자**: '공유 사용자를 쓰는 사이트'는 리스너별로 표시되고, 리스너 안의 사이트는 다시 Web 서비스의 그룹별로 분류됩니다. 리스너와 그룹은 각각 따로 접을 수 있으며, 도구 모음에서 한 번에 모두 접거나 펼칠 수 있습니다.

## API

일반 목록 API는 모두 순서를 바꾸는 `PUT <목록 경로>-order`(요청 본문 `{"keys": [...]}`, 모든 항목을 포함해야 함)와 그룹을 일괄 설정하는 `PUT <목록 경로>-group`(요청 본문 `{"keys": [...], "group": "..."}`)을 제공합니다. 예: `PUT /api/stun/rules-group`. DDNS 작업 안의 레코드는 `PUT /api/ddns/tasks/{key}/records-layout`을, API 토큰은 `PUT /api/tokens/order`와 `PUT /api/tokens/group`을 사용합니다. 자세한 내용은 [API 레퍼런스](/ko/docs/reference/api-reference)를 참고하세요.

# 포트 포워딩

이 호스트에서 수신하는 포트를 다른 장치나 서비스로 전달합니다.

## 기능

- TCP와 UDP
- IPv4와 IPv6, v4 / v6 간 상호 포워딩
- 포트 범위와 다중 포트
- 다중 대상과 장애 조치
- 연결 수 제한
- 트래픽 통계와 실행 로그
- 대상에 PROXY 프로토콜(v1 / v2)을 보내 실제 클라이언트 주소를 하위 단계에 전달
- 출발지 IP 접근 제어(허용 목록 / 차단 목록), Web 서비스의 구독 IP 목록 참조 가능;
- 여러 서비스가 도메인이나 프로토콜에 따라 443 같은 포트 하나를 함께 쓰려면 [프로토콜 라우팅](/ko/docs/modules/protoroute)을 사용하세요

## PROXY 프로토콜

포트 포워딩은 TCP 중계만 하므로 하위 서비스에는 기본적으로 Gately 자신의 주소만 보입니다. 규칙에서 「PROXY 프로토콜」을 v1 또는 v2로 설정하면 Gately가 대상에 연결한 뒤 PROXY 헤더를 먼저 보내므로, 하위 서비스가 실제 클라이언트 주소를 얻어 로그, 속도 제한, 접근 제어에 활용할 수 있습니다.

대상에서 해당 수신 옵션을 켜야 하며, 그렇지 않으면 연결이 거부됩니다. 예:

- haproxy: `bind 192.168.1.8:4434 accept-proxy`
- nginx: `listen 4435 ssl proxy_protocol;`
- Gately 웹 서비스: 리스너에서 「PROXY 프로토콜 수신」을 켜고 출처를 신뢰할 PROXY 출처에 추가합니다.

이 옵션은 TCP에만 적용되며 UDP 포워딩에는 영향을 주지 않습니다.

## 출발지 IP 접근 제어

각 규칙에 허용 목록 또는 차단 목록을 설정해 출발지 IP로 전달 여부를 결정할 수 있습니다. 목록은 직접 입력한 IP / 서브넷과 Web 서비스의 구독 IP 목록으로 구성되며, 하나라도 일치하면 목록에 있는 것으로 봅니다. 구독 목록은 Web 서비스 모듈이 주기적으로 내려받고 갱신 즉시 적용되며, 첫 다운로드에 성공하기 전에는 빈 목록으로 처리합니다.

- 대상에 연결하기 전에 판단합니다. 조건을 만족하지 않는 TCP 연결은 바로 닫고, UDP는 패킷마다 판단해 만족하지 않는 패킷을 버립니다. 목록이 바뀌면 기존 세션의 상향 패킷에도 즉시 적용됩니다.
- 침입 방지의 차단이 목록보다 우선합니다. 차단된 주소는 허용 목록 서브넷 안에 있어도 거부됩니다.
- 목록을 수정해도 수신 대기는 중단되지 않으며, 이미 맺어진 TCP 연결에는 영향이 없습니다.
- 규칙 카드에 Gately 시작 이후 거부 횟수(TCP는 연결, UDP는 패킷 기준)를 표시하고, 실행 로그의 디버그 수준에 거부마다 기록합니다.
- 규칙 앞에 리버스 프록시나 다른 전달이 있으면 Gately가 보는 출발지는 그 주소입니다.

Lucky에서 가져올 때 규칙의 안전 모드도 함께 변환합니다. 허용 목록 모드는 Lucky IP 필터의 「화이트리스트」 IP / 서브넷을, 차단 목록 모드는 「블랙리스트」와 「전역 블랙리스트」를 사용합니다. 같은 가져오기에서 `lucky_ipfilter.lkcf`(또는 전체 백업)를 함께 올리세요. IP 데이터베이스·자동 기록·주소 범위 항목은 가져올 수 없으며 결과에 안내가 표시됩니다. 안전 모드가 꺼져 있으면 목록을 설정하지 않습니다. 직접 만든 IP 필터 규칙을 선택했다면 규칙 동작에 따라 허용은 허용 목록, 거부는 차단 목록(전역 블랙리스트도 합침)으로 가져옵니다.

## 대표 사용 사례

- NAS의 서비스 포트를 하나의 진입점으로 노출
- IPv6와 IPv4 사이의 상호 연결 포워딩
- 서비스 하나에 주/예비 백엔드 두 개 구성

## 배포 팁

포트 포워딩은 호스트 포트를 직접 수신하므로 Docker 배포에서는 `--network host`를 권장합니다.

## 그룹과 정렬

규칙에 "그룹"(최대 64자)을 지정할 수 있습니다. 목록은 그룹별로 접을 수 있는 구역으로 표시되며, 그룹은 처음 나타난 순서대로, 그룹이 없는 규칙은 맨 뒤에 놓입니다. 접힘 상태는 브라우저에 저장됩니다. 페이지 상단의 검색 상자로 이름, 그룹, 수신 포트 또는 대상을 기준으로 거를 수 있습니다.

"정렬"을 눌러 정렬 모드로 들어갑니다. 화살표로 규칙을 위아래로 옮기거나 그룹 전체를 옮길 수 있습니다. 여러 규칙을 선택한 뒤 그중 하나를 끌면 함께 이동하고, 다른 그룹의 규칙이나 그룹 제목에 놓으면 그 그룹으로 들어갑니다. 도구 모음에서 선택한 규칙을 지정한 그룹으로 한 번에 옮길 수 있고, 이름을 비우면 그룹에서 뺍니다. 순서와 그룹은 목록 표시에만 영향을 주며, 바꿔도 전달은 다시 시작되지 않고 열린 연결도 유지됩니다.

그룹 제목에 마우스를 올리고 연필 버튼을 누르면 그룹 이름을 바꿀 수 있습니다. 그룹의 항목도 함께 새 이름으로 바뀌며 위치와 순서는 그대로입니다. 이미 있는 그룹 이름을 고르면 확인 후 두 그룹이 합쳐집니다.

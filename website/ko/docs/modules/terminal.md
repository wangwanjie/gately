# 웹 터미널

브라우저에서 SSH, Telnet 서버나 로컬 셸에 연결합니다. 세션은 서버에 영구 보관되어 연결이 끊어져도 다시 접속할 수 있습니다. 진입점은 사이드바 「웹 터미널」입니다.

## 연결 유형

| 유형 | 설명 |
| --- | --- |
| SSH | 비밀번호와 개인 키 인증을 지원합니다(개인 키를 붙여 넣거나 서버 로컬의 `keyFile` 경로를 지정할 수 있으며 개인 키 암호도 지원). 로그인 후 이동할 `workDir`, `keepAlive`, 연결 타임아웃(1~120초, 기본 15), 프록시를 설정할 수 있습니다 |
| Telnet | 기본 포트 23. `login:`, `username:`, `password:` 등의 프롬프트를 감지하면 각각 한 번씩 자동 입력하며 프록시를 설정할 수 있습니다 |
| 로컬 셸 | Gately가 실행 중인 장치에서 셸을 바로 엽니다. 셸 경로, 작업 디렉터리, 추가 환경 변수를 지정할 수 있습니다 |

연결마다 메모를 남길 수 있습니다. 연결 목록은 드래그로 순서를 바꿀 수 있고 「연결 테스트」를 지원합니다. SSH는 서버 버전과 지연 시간을 반환하고, Telnet은 TCP(프록시 포함) 도달 여부만 확인하며, 로컬 셸은 테스트를 지원하지 않습니다. 연결을 편집할 때 비밀번호, 개인 키, 개인 키 암호, 프록시 비밀번호는 마스킹되어 표시되며 바꾸지 않으면 기존 값이 유지됩니다.

「설정」에서 「SSH 인증 프리셋」(비밀번호 또는 개인 키, 기본 사용자 이름 선택 가능)을 관리할 수 있습니다. SSH 연결을 추가하거나 편집할 때 인증 프리셋을 선택하면 재사용할 수 있고, 하나의 자격 증명을 여러 연결이 공유합니다. 프리셋을 수정하면 해당 연결이 다음에 접속할 때 반영됩니다. 연결에서 참조 중인 프리셋은 삭제할 수 없습니다.

### 프록시

SSH와 Telnet 연결에는 각각 송신 프록시를 설정할 수 있습니다. 유형은 `socks5` 또는 `http`이며 프록시 사용자 이름과 비밀번호를 입력할 수 있습니다.

### 호스트 키 최초 신뢰

SSH 연결을 처음 맺을 때 서버의 호스트 지문을 기록하고 신뢰하며, 이후 연결할 때마다 지문을 대조합니다. 서버를 재설치하거나 키를 바꾼 뒤에는 연결에서 「호스트 지문 초기화」를 실행하면 다시 신뢰할 수 있습니다.

## 세션

- 세션은 서버에 영구 보관되므로 브라우저를 새로고침하거나 연결이 끊어져도 세션 목록에서 다시 연결(attach)할 수 있으며, 연결할 때 출력 버퍼를 먼저 재생한 뒤 실시간으로 전달합니다.
- 한 세션에 여러 클라이언트가 동시에 연결할 수 있으며 입력은 공유되고 출력은 브로드캐스트됩니다.
- 세션에 메모를 남길 수 있으며 세션 목록에는 생성 시간, 마지막 활동 시간, 창 크기, 송수신 바이트 수가 표시됩니다.
- 페이지를 새로고침하면 살아 있는 세션이 탭으로 자동 복원되며 분할 레이아웃도 함께 복원됩니다.
- 터미널에는 검색(키워드를 입력하고 Enter로 다음, Shift+Enter로 이전 찾기), 복사, 붙여넣기, 화면 지우기, 글꼴 크기 조절, 전체 화면, 여러 터미널 색상 테마(기본값은 인터페이스 테마 따라가기, 특정 색상 테마로 고정 가능)가 내장되어 있습니다.

### 설정 항목

페이지 오른쪽 위의 「설정」에서 조정합니다.

| 필드 | 기본값 | 설명 |
| --- | --- | --- |
| `allowLocalShell` | 꺼짐 | 로컬 셸을 열 수 있게 할지 여부 |
| `maxSessions` | 20 | 최대 동시 세션 수이며 상한은 1000입니다. 초과하면 새 세션 생성이 HTTP 429를 반환합니다 |
| `idleTimeout` | 0 | 세션에 입출력이 없는 시간이 이 분 수를 넘으면 자동 종료하며 0은 제한 없음입니다 |
| `bufferSize` | 256 | 세션마다 보관하는 재생 버퍼(KB), 상한 16384 |
| `heartbeatInterval` | 30 | WebSocket 하트비트 간격(초), 상한 600 |
| `sessionKeepAlive` | 0 | 브라우저 연결이 끊어진 뒤 세션을 계속 유지하는 분 수이며 0이면 끊기는 즉시 종료합니다. 상한 10080 |

::: tip 팁
연결이 끊어져도 다시 접속하려면 `sessionKeepAlive`를 0보다 큰 값으로 설정하세요. 0으로 두면 브라우저 연결이 끊어지는 즉시 세션이 종료됩니다.
:::

## SFTP 파일 관리

터미널 도구 모음의 폴더 아이콘으로 파일 관리 패널을 엽니다. SSH 연결은 SFTP로 원격 파일을 다루고, 로컬 셸 연결은 Gately가 실행 중인 장치의 파일 시스템을 직접 다룹니다. Telnet 연결은 파일 관리를 제공하지 않습니다. 로컬 파일 관리를 쓰려면 「로컬 셸 허용」이 켜져 있어야 합니다.

| 기능 | 설명 |
| --- | --- |
| 탐색 | 이동 경로(breadcrumb)와 상위 디렉터리 이동, 디렉터리가 먼저 오고 이름순 정렬이며 정렬 방식을 바꿀 수 있습니다. 권한, 크기, 수정 시간, 소유자를 표시합니다 |
| 새로 만들기 | 새 폴더, 빈 파일 생성 |
| 업로드 | 여러 파일 업로드. 데스크톱에서는 폴더 전체 업로드(하위 디렉터리 구조 유지)를 지원하며 같은 이름의 파일은 덮어쓰고 패널에 업로드 진행률이 표시됩니다 |
| 다운로드 | 스트리밍 다운로드, 이어받기(`Range`) 지원 |
| 온라인 편집 | 텍스트 파일 미리보기와 저장. 파일이 1MB를 넘거나 바이너리이면 미리볼 수 없습니다 |
| 이름 변경, 복사, 붙여넣기 | 같은 디렉터리로 복사하면 `name copy.ext`, `name copy 2.ext`처럼 이름이 자동으로 바뀝니다 |
| 삭제 | 여러 개 선택해 일괄 삭제할 수 있고 디렉터리는 재귀적으로 삭제하며 루트 디렉터리는 보호됩니다 |
| 압축과 해제 | `zip` 또는 `tar.gz`로 압축하고, `zip`, `tar`, `tar.gz`, `tgz` 해제를 지원합니다. 해제 전에 압축 파일 내용(최대 10000개)을 미리 볼 수 있으며 압축과 해제는 Gately가 직접 처리하므로 원격에 별도 명령을 설치할 필요가 없습니다 |
| 권한 변경 | 8진수 권한(0~7777), 디렉터리는 재귀 적용 선택 가능 |
| 빠른 접근 | 연결마다 자주 쓰는 디렉터리를 저장해 한 번에 이동 |

해제할 때 `..`가 포함된 항목이 있으면 디렉터리 순회를 막기 위해 전체를 거부하고, 심볼릭 링크와 하드 링크 항목은 건너뛰며, 파일 권한은 rwx 비트만 유지합니다. 모바일 패널은 다중 선택 모드와 작업 패널을 제공합니다.

## 빠른 명령

「빠른 명령」 드롭다운에는 전역 빠른 명령이 나열되며 누르면 현재 터미널로 전송됩니다. 각 빠른 명령은 `name`, `command`, `sendEnter`(전송 후 자동으로 Enter를 보낼지 여부)로 구성됩니다. 드롭다운 아래쪽의 「빠른 명령 관리」에서 추가, 삭제, 수정합니다.

## 화면 분할

도구 모음의 「분할」 메뉴는 좌우 분할, 상하 분할, 그리드 분할을 제공하며 최대 4개의 창을 동시에 표시할 수 있습니다. 분할 모드에 들어간 뒤 연결을 열면 자동으로 분할에 추가되며 다른 탭을 눌러 추가할 수도 있고, 창 제목 표시줄에서 세션을 분할에서 뺄 수 있습니다. 분할 레이아웃은 서버에 저장되어 페이지를 새로고침하면 복원됩니다. 좁은 화면에서는 분할이 자동으로 해제되며 저장된 레이아웃은 삭제되지 않습니다.

## 모바일 대응

- 좁은 화면에서는 연결 목록과 터미널이 두 개의 화면으로 나뉘며 터미널 화면 왼쪽 위의 뒤로 가기 버튼으로 목록에 돌아갑니다.
- 터미널 영역은 보이는 뷰포트를 따르며 소프트 키보드가 올라오면 자동으로 줄어듭니다.
- 가상 키 막대는 좌우로 밀 수 있는 한 줄 막대로, `Esc`, `Tab`, `Ctrl`, `Alt`(고정 가능), 방향키(길게 누르면 반복), 자주 쓰는 기호, 빠른 명령 진입점을 제공하며 오른쪽에는 키보드를 열거나 닫는 버튼이 고정되어 있습니다. 기본적으로 키 막대는 화면 키보드와 함께 나타나고 사라지며, 키보드가 닫혀 있을 때는 오른쪽 아래의 플로팅 버튼으로 키보드를 다시 열 수 있습니다. 키보드 없이 방향키나 페이지 이동 키를 쓰려면 「더보기」 메뉴에서 「키 바 항상 표시」를 켜세요.

## 보안

터미널은 대상 호스트에서 임의의 명령을 실행하는 것과 같으므로 Gately는 기본적으로 다음 제한을 둡니다.

- **로컬 셸은 기본적으로 꺼져 있으며** 설정에서 명시적으로 켜야 합니다.
- **약관 확인**: 로컬 셸을 처음 켜거나 세션을 새로 만들거나 세션에 연결하거나 파일 관리를 사용할 때 사용자 약관이 표시되며 동의에 체크해야 계속할 수 있습니다.
- **2차 인증(2FA)**: 보안 설정에서 QR 코드를 스캔해 TOTP 인증기를 연결하면 위 작업에 6자리 인증 코드를 입력해야 합니다. 인증을 통과하면 현재 로그인 토큰으로 30분 동안 다시 인증하지 않아도 되며, 5번 연속 틀리면 해당 로그인 토큰이 1분간 잠깁니다.
- 연결 비밀번호, 개인 키, 프록시 비밀번호는 API 출력에서 마스킹됩니다.

::: warning 주의
로컬 셸을 켜기 전에 먼저 관리 UI에 2단계 인증을 켜고 「내부망 전용 접근」이나 VPN과 함께 사용하세요.
:::

# Gately v0.6.5.4 출시

2026년 11월 11일

[v0.6.5.4 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.4)

## Wake-on-LAN: 원격 종료

장치에 Web 터미널의 SSH 연결을 고르고 종료 명령을 입력하면 장치 카드에 "종료" 버튼이 나타납니다(API `POST /api/wol/devices/{key}/shutdown`).

- 폼에서 Linux(`shutdown -h now`), Windows(`shutdown /s /t 0`, OpenSSH 서버를 켜야 함), macOS(`sudo -n shutdown -h now`)의 일반적인 명령을 고를 수 있습니다;
- 해당 연결은 Web 터미널에서 한 번 연결해 호스트 키를 기록해 두어야 하며, 무인 상태에서 알 수 없는 호스트를 신뢰하지 않습니다;
- 종료할 때마다 새 SSH 연결을 만들고 끝나면 닫으므로 장치가 재부팅되기 전의 끊긴 연결을 쓰지 않습니다. 명령은 최대 30초, 같은 장치에서는 한 번에 하나만 실행하며, 종료 코드가 돌아오기 전에 연결이 끊기면 종료가 시작된 것으로 봅니다;
- API 토큰으로 장치를 추가·수정·복사하거나 종료를 실행하려면 `wol:write` 외에 `webterminal:write`가, 선택 가능한 SSH 연결 목록에는 `webterminal:read`가 필요합니다.

## Wake-on-LAN: Bemfa 음성 제어

[Bemfa](https://cloud.bemfa.com)를 연동하면 Xiao AI, Xiaodu, Google Assistant 같은 음성 비서로 장치를 켜고 끌 수 있습니다. Bemfa 콘솔에서 `001`(콘센트) 또는 `006`(스위치)으로 끝나는 토픽을 만들고, 장치에 같은 토픽을 입력한 뒤 "Wake-on-LAN → Bemfa"에서 사용자 개인 키를 입력해 켜고, Mi Home, Xiaodu 등의 앱에서 Bemfa 계정을 연결합니다.

"켜기"는 장치를 깨우고 "끄기"는 원격 종료하며, 성공하면 켜짐/꺼짐 상태를 Bemfa에 다시 기록합니다. 화면이나 API에서 깨우거나 종료해도 똑같이 기록합니다. Gately는 MQTT 3.1.1 over TLS로 `bemfa.com:9503`에 연결하고 인증서를 검증하며, 개인 키는 API에서 가려서 표시합니다. 구독 시 서버가 다시 보내는 이전 상태는 실행하지 않고, 10초 안에 반복된 같은 명령은 한 번만 실행합니다. 같은 개인 키로는 클라이언트 하나만 온라인일 수 있습니다.

## Web 서비스: 리스너에 HTTP 포트 추가

리스너에 평문 HTTP 포트를 하나 더 지정할 수 있습니다(예: 443 HTTPS 리스너에 80 추가). 메인 포트와 모든 사이트·설정을 공유하므로 같은 사이트를 다시 입력한 HTTP용 리스너를 따로 만들 필요가 없습니다. HTTPS를 켠 경우 "HTTPS로 리디렉션"(기본값. 도메인·경로·쿼리 문자열을 유지하고 포트를 접속 주소의 포트로 바꾸며 GET/HEAD는 301, 그 밖의 메서드는 308) 또는 "그대로 제공"을 고릅니다.

- ACME HTTP-01 검증, PROXY 프로토콜, 방화벽 자동 허용도 이 포트에 적용됩니다. 포트가 사용 중이면 메인 포트는 계속 동작하고 리스너 상태에 이유가 표시됩니다;
- 대응하는 사이트가 없는 도메인은 리디렉션하지 않고, 알 수 없는 도메인으로 404를 반환하거나 기본 사이트로 넘깁니다(기본 사이트가 "연결 끊기"이면 연결을 끊음). HTTPS와 같은 처리이며 같은 포트 HTTP 리디렉션도 이렇게 바뀌었습니다;
- 저장할 때 HTTP 포트가 다른 리스너의 포트와 충돌하는지 확인합니다. 프로토콜 라우팅이나 포트 포워딩을 거쳐 접속하는 리스너에 접속 포트가 비어 있으면 편집 창에서 입구 포트를 입력하라고 알려 줍니다.

## 내비게이션 패널: 테마 변경

내비게이션 패널은 관리 화면과 같은 테마 색상(Gately 오리지널과 클래식)을 쓰며, 패널을 편집할 때 기본 스킨을 고를 수 있습니다. 방문자는 페이지 오른쪽 위 팔레트 버튼으로 테마를 바꿀 수 있고 조작은 관리 화면과 같습니다: 라이트·다크·시스템 설정, 마우스를 올리면 색 구성을 미리 보고 클릭하면 그 위치에서 새 색이 퍼짐, 강조 색과 모서리 사용자 지정. 휴대폰에서는 아래에서 열립니다. 선택은 방문자의 브라우저에 저장되며, 패널과 관리 화면이 같은 도메인에 있으면 양쪽의 선택이 공유됩니다. 자세한 내용은 [웹 서비스 · 내비게이션 패널](/ko/docs/modules/web#nav-panel)을 참고하세요.

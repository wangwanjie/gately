# 변경 내역

주요 버전의 릴리스 공지는 아래와 같습니다. 모든 버전의 전체 변경 사항과 다운로드 파일은 [GitHub Releases](https://github.com/wangwanjie/gately/releases)에서 확인하세요.

## [v0.6.8.6](/ko/news/v0.6.8.6)

2026년 11월 23일 · 네트워크 토폴로지에서 업로드 속도를 표시하고 집계 기간을 선택할 수 있습니다. SMTP 알림에서 인증서 검증을 건너뛸 수 있고, Windows 개요에 전체 리소스 정보를 표시하며, 상태 검사에 실패한 컨테이너의 개요 집계와 토폴로지 접기 화살표 방향을 수정했습니다.

## [v0.6.8.5](/ko/news/v0.6.8.5)

2026년 11월 23일 · 방문자 IP 위치 표시, GeoIP 데이터베이스 .mmdb.gz / .tar.gz 지원, 여러 단일 로그인 도메인, 웹 인증 로그인 페이지 내장 스타일 9종, fnOS HTTP 접속에서 설정 저장이 거부되던 문제와 Docker 작업 패널이 버튼을 가리던 문제 수정.

## [v0.6.8.4](/ko/news/v0.6.8.4)

2026년 11월 19일 · 보안 수정: 알림 채널 키가 전송 오류에 나타날 수 있었습니다. 포트 포워딩, 프로토콜 라우팅, Web 서비스, 전역 설정을 바꾸면 새 연결로 확인되어야 적용이 유지되고, 확인되지 않으면 자동으로 롤백됩니다. 알림은 실패 시 재시도하고 채널이 복구되면 재전송합니다. 인증서는 fnOS 시스템 인증서를 사용할 수 있습니다. 시스템 설정에 저장소 사용량이 표시됩니다. 침입 방지의 미끼 포트가 관리 포트를 차지해 재시작 때 종료되던 문제를 수정했습니다.

## [v0.6.8.2](/ko/news/v0.6.8.2)

2026년 11월 18일 · 포트 노킹에서 사람마다 키를 따로 쓸 수 있습니다. 포트 포워딩과 프로토콜 라우팅에서 출처별 한도를 적용하지 않을 출처를 지정할 수 있습니다. 다른 Gately로 리버스 프록시할 때 백엔드 자신의 로그인 쿠키와 보안 진입 쿠키를 더 이상 제거하지 않으며, 리버스 프록시 뒤에서 v0.6.8.1이 일으키던 421도 고쳤습니다. 내비게이션 패널은 드래그 정렬과 패널 그룹을 지원하고, 리버스 프록시가 백엔드 연결 풀을 공유해 사이트 1000개일 때 메모리가 절반으로 줄어듭니다.

## [v0.6.8.1](/ko/news/v0.6.8.1)

2026년 11월 17일 · v0.6.8에서 사이트를 추가하거나 편집할 때 siteCerts 형식 오류가 표시되던 문제를 수정했습니다. 와일드카드 인증서의 여러 도메인이 프로토콜 라우팅으로 서로 다른 Gately에 전달될 때 브라우저의 연결 재사용으로 나타나던 '사이트를 찾을 수 없음'은 421을 반환해 브라우저가 다시 연결하도록 합니다. 내비게이션 패널에 1×1 / 1×2 / 2×2 링크 크기, 다중 주소 링크 바로 열기, 링크 아이콘 가져오기와 페이지 스위치를 추가했습니다.

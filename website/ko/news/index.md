# 변경 내역

주요 버전의 릴리스 공지는 아래와 같습니다. 모든 버전의 전체 변경 사항과 다운로드 파일은 [GitHub Releases](https://github.com/wangwanjie/gately/releases)에서 확인하세요.

## [v0.6.2](/ko/news/v0.6.2)

2026년 10월 31일 · 새 「프로토콜 라우팅」 모듈로 HTTPS, SSH, RDP, OpenVPN 등이 하나의 포트를 함께 씁니다. 모든 긴 목록을 그룹으로 묶고 정렬할 수 있고, 동적 DNS에서 STUN 공인 주소를 참조할 수 있으며, STUN이 다중 NAT를 지원합니다. 여러 보안 강화도 포함됩니다.

## [v0.6.1.1](/ko/news/v0.6.1.1)

2026년 10월 30일 · 침입 방지가 웹 경로 탐색을 차단합니다. 새 「인증 사용자」 페이지에서 공유 사용자와 OIDC를 관리하고, 공유 사용자는 비밀번호를 직접 바꿀 수 있으며, 사이트는 거부 시 연결을 끊을 수 있습니다. Cloudflare 토큰 터널의 라우팅 규칙을 Gately에서 편집할 수 있고, 로그에 「제외」 필터가 추가되었습니다.

## [v0.6.1](/ko/news/v0.6.1)

2026년 10월 30일 · 보안 수정: 읽기 전용 계정과 읽기 전용 API 토큰으로 더 이상 컨테이너 환경 변수와 시작 명령을 평문으로 읽을 수 없습니다. 인증서를 IPv4 전용 또는 IPv6 전용으로 발급할 수 있고, Docker 페이지는 Gately 자신의 컨테이너를 업그레이드하거나 다시 만들지 않으며, 알림과 로그는 관리 화면 언어를 따릅니다.

## [v0.6.0.4](/ko/news/v0.6.0.4)

2026년 10월 29일 · OpenWrt용 LuCI 앱을 추가해 LuCI에서 상태 확인, 서비스 시작·중지, 관리 포트 설정을 할 수 있습니다. 리디렉션 사이트에서 `{path}`, `{1}`, `{STUN_규칙이름_PORT}` 등의 변수를 쓸 수 있고, 전역 설정의 공유 사용자와 OIDC 클라이언트는 요약으로 표시되고 대화상자에서 편집합니다.

## [v0.6.0.3](/ko/news/v0.6.0.3)

2026년 10월 28일 · 신뢰할 PROXY 출처로 평문 전달을 받는 내부망 Gately가 방문자의 HTTPS 사용을 인식하지 못해 https 발급자의 OIDC 로그인 실패, 쿠키 Secure 누락, 평문 리디렉션 반복이 생기던 문제를 수정했습니다.

## [v0.6.0.2](/ko/news/v0.6.0.2)

2026년 10월 28일 · fnOS 데스크톱에서 열 때 웹 터미널이 "연결 중"에서 멈추는 문제, 상대 경로 설정 디렉터리에서 File Browser가 시작되지 않는 문제, 중국어 간체 이외의 언어에서 API가 사용자가 입력한 중국어를 일부 번역하는 문제를 수정했습니다.

## [v0.6.0.1](/ko/news/v0.6.0.1)

2026년 10월 27일 · 동적 도메인과 포트 포워딩이 그룹, 정렬, 검색을 지원합니다. Web 서비스, 동적 도메인, 포트 포워딩에서 그룹 일괄 설정, 여러 항목 함께 끌기, 그룹 이름 변경이 가능합니다.

## [v0.6.0](/ko/news/v0.6.0)

2026년 10월 27일 · frpc와 frps를 여러 인스턴스로 실행할 수 있습니다. Web 서비스는 로그인한 사용자별로 다른 백엔드로 보내고, 사이트를 그룹으로 묶어 정렬·검색하며, Gately 로그인 쿠키를 전달할 수 있습니다. 인증서는 위임된 하위 도메인의 DNS 영역을 자동으로 찾고, 저장된 비밀번호와 키는 필요할 때 표시할 수 있습니다.

## [v0.5.9.1](/ko/news/v0.5.9.1)

2026년 10월 26일 · Web 서비스의 HTTPS 리스너가 같은 포트에서 HTTP를 받을 수 있습니다(리디렉션 또는 그대로 제공). File Browser 인스턴스에 접속 주소를 지정할 수 있고, File Browser 인스턴스와 Cloudflare 터널을 편집한 뒤 저장되지 않던 문제를 고쳤습니다.

## [v0.5.9](/ko/news/v0.5.9)

2026년 10월 26일 · File Browser를 호스팅합니다. IP 주소 인증서와 단기 인증서를 발급할 수 있고, frp, cloudflared, Tailscale, File Browser를 온라인으로 설치, 업데이트, 롤백, 제거할 수 있으며, 파일 서비스 공유 사용자가 별도 페이지로 옮겨졌습니다.

## [v0.5.8.1](/ko/news/v0.5.8.1)

2026년 10월 26일 · WebDAV, FTP, SMB가 공유 사용자 목록을 함께 씁니다. 웹 서비스에 연결 끊기 사이트 유형이 추가되고 접근 로그에 Referer와 User-Agent가 기록되며, frps 수신 대기 주소를 지정할 수 있고, HTTP에서도 복사 버튼이 동작합니다.

## [v0.5.8](/ko/news/v0.5.8)

2026년 10월 25일 · OIDC ID 공급자를 내장해 공유 사용자로 Gitea, Grafana 등의 앱에 로그인할 수 있습니다. SMB 서비스가 추가되었고, 모든 로그를 필터링할 수 있으며, WAF 규칙 그룹의 순서를 바꿀 수 있고, 사이트 요청 헤더를 자주 쓰는 항목에서 고를 수 있습니다.

## [v0.5.7](/ko/news/v0.5.7)

2026년 10월 24일 · 스토리지 마운트가 SMB 공유에 연결되고, 테마는 라이트와 다크를 갖춘 15개 팔레트에 강조색과 모서리를 설정할 수 있으며, 관리 화면은 압축 전송되고 프로그램은 약 11% 작아졌습니다.

## [v0.5.6.4](/ko/news/v0.5.6.4)

2026년 10월 23일 · 인증서 자동 배포가 여러 로컬 디렉터리 복사, 디렉터리별 명령, 인증서와 개인 키 파일 이름 지정을 지원합니다.

## [v0.5.6.3](/ko/news/v0.5.6.3)

2026년 10월 23일 · OpenWrt에서 개요에 br-lan 인터페이스가 보이지 않던 문제와, 시간대를 설정할 수 없고 시간이 UTC로 계산되던 문제를 수정했습니다.

## [v0.5.6.2](/ko/news/v0.5.6.2)

2026년 10월 23일 · Web 서비스 로그인 화면과 오류 페이지를 새로 디자인하고 2단계 인증을 팝업으로 변경했습니다. Docker 29에서 Docker 모듈이 연결되지 않던 문제, 로그인 전에 개요 화면이 잠깐 보이던 문제, Lucky에서 가져온 Cloudflare 자격 증명과 이름을 바꾼 DDNS 레코드가 동기화되지 않던 문제를 수정했습니다.

## [v0.5.6.1](/ko/news/v0.5.6.1)

2026년 10월 22일 · Docker 이미지가 기록한 방화벽 규칙 때문에 호스트의 구버전 nft가 충돌하던 문제를 수정했습니다.

## [v0.5.6](/ko/news/v0.5.6)

2026년 10월 22일 · 침입 방지 추가: fail2ban 방식 로그 규칙, 미끼 포트, 포트 스캔 탐지와 nftables 차단 동기화.

## [v0.5.5.2](/ko/news/v0.5.5.2)

2026년 10월 22일 · fnOS 등의 파일 시스템에서 설정 디렉터리의 민감한 파일을 같은 기기의 다른 사용자가 읽을 수 있던 문제를 수정했습니다.

## [v0.5.5.1](/ko/news/v0.5.5.1)

2026년 10월 21일 · 실행 로그를 디스크에 기록해 재시작과 업그레이드 후에도 볼 수 있습니다.

## [v0.5.5](/ko/news/v0.5.5)

2026년 10월 21일 · nginx 설정 가져오기, 다른 호스트와 컨테이너로 인증서 자동 배포, WAF의 대용량 업로드와 WebDAV 지원, 구독 IP 목록이 추가되었고, 자가 점검에 인증서 적용 여부와 frp 충돌 검사가 추가되었습니다.

## [v0.5.4](/ko/news/v0.5.4)

## [v0.5.3](/ko/news/v0.5.3)

2026년 10월 21일 · fnOS 통합 게이트웨이에 연결되고 fnOS 관리자의 로그인 상태로 바로 로그인하는 fnOS 네이티브 앱. 기능 모듈을 필요에 따라 켜고 끌 수 있습니다.

## [v0.5.2](/ko/news/v0.5.2)

2026년 10월 20일 · SNI 라우팅으로 여러 서비스가 443 포트를 함께 쓰고, 웹 서비스가 nginx를 대체하며, 공유 사용자가 TOTP와 통합 로그인을 지원합니다. haproxy + nginx와의 성능 비교도 함께 실었습니다.

## [v0.5.0](/ko/news/v0.5.0)

2026년 10월 19일 · 감사 로그, 설정 기록과 되돌리기, 패스키, 읽기 전용 계정, ACME HTTP-01, HTTP/3, PROXY 프로토콜, 전역 Prometheus 지표, 네트워크 자가 점검, 서명된 릴리스.

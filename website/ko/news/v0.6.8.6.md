# Gately v0.6.8.6 출시

2026년 11월 23일

[v0.6.8.6 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.6)

## 토폴로지 업로드 속도와 집계 기간(#113)

- 사이트, 백엔드, 리스너 동작에 다운로드 속도와 함께 업로드 속도를 표시합니다. 사이트는 방문자가 보낸 바이트(요청 본문과 WebSocket 등으로 업그레이드된 뒤 방문자가 보내는 데이터), 백엔드는 해당 백엔드로 전달한 요청 본문 바이트입니다.
- 상세 패널에서 "60 s 평균" 카드가 "업로드"로 바뀌어 "다운로드" 옆에 표시되고, 새 "집계 기간" 선택으로 QPS, 업로드, 다운로드를 최근 1, 5, 10, 30, 60초 평균으로 전환할 수 있습니다(기본값 10, 기기별로 기억). 리플레이는 기록 당시의 10초를 그대로 사용합니다.
- 도구 모음에 두 방향이 모두 표시되고 좁은 화면에서는 줄바꿈되며, 초당 트래픽 차트는 업로드와 다운로드를 두 개의 선으로 그립니다.
- `GET /api/webservice/topology`는 `window=1..60`을 지원하고, 노드 속도에 `upBps`가 포함되며 `qps60`도 계속 반환됩니다.

## SMTP 인증서 검증(#115)

- SMTP 알림 채널에 STARTTLS와 SSL/TLS용 "인증서 검증 건너뛰기" 옵션이 추가되었습니다. 인증서가 자체 서명이거나 서버 주소와 맞지 않는 자체 구축 메일 서버(예: localhost에만 유효한 기본 인증서)를 위한 옵션이며, 기본값은 꺼짐입니다.

## Windows 개요

- Windows에서 개요에 CPU 모델과 사용률, 메모리와 페이지 파일, 디스크, 가동 시간, Windows 에디션과 빌드, 네트워크 트래픽과 속도, Gately 및 관리 대상 프로세스의 메모리·CPU·스레드 수를 표시합니다. Windows에는 로드 평균이 없어 해당 항목은 비어 있습니다.

## 수정

- **개요**: 상태 검사에 실패한 실행 중 컨테이너는 실행 중으로 집계하고 Docker 행에 "상태 검사 실패"로 따로 표시합니다. "이상"은 재시작 중, dead, 0이 아닌 코드로 종료된 컨테이너만 집계합니다(#114).
- **Docker**: 상태 검사에 실패한 컨테이너는 카드, 상세 헤더, 개요 탭에 "상태 검사 실패" 경고 배지를 표시하며, 컨테이너 목록에 "이상" 필터가 추가되었습니다(#114).
- **네트워크 토폴로지**: 리스너 카드의 접기 버튼이 클릭 시 하위 노드가 향하는 방향을 가리킵니다. 트리 레이아웃은 좌/우, 세로 레이아웃은 위/아래, 방사형 레이아웃은 빼기/더하기입니다(#113).

## 업그레이드 안내

- Docker는 새 이미지를 받아 컨테이너를 다시 만들고, OpenWrt는 새 `.apk` / `.ipk`를 덮어 설치하고, fnOS는 앱 센터에서 새 `.fpk`를 수동 설치하며, 그 밖의 환경은 "시스템 설정"에서 온라인으로 업그레이드할 수 있습니다.

# Gately v0.6.2.3 릴리스

2026년 11월 2일

v0.6.2 시리즈의 개선 업데이트입니다. 설정 형식은 바뀌지 않았습니다.

[다운로드 v0.6.2.3](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.3)

## 별도 페이지의 네트워크 토폴로지

토폴로지가 웹 서비스 페이지의 탭에서 사이드 메뉴 Web 아래의 "네트워크 토폴로지" 페이지로 옮겨졌고, 웹 서비스 페이지의 버튼으로 열 수 있습니다. 통계와 연결 창은 토폴로지 페이지에서 바로 열리며, "편집"은 웹 서비스 페이지로 이동해 사이트 편집기를 엽니다. 캔버스는 현재 스킨의 라이트 / 다크 모드를 따릅니다.

## 7가지 레이아웃

레이아웃 메뉴에는 트리, 세로 트리, 방사형, 생키, 선버스트, 트리맵, 버블이 있으며 각각 아이콘과 한 줄 설명이 붙습니다. 전환은 페이드로 이루어지고 선택은 기억됩니다. 각 리스너는 처음 8개 사이트, 각 사이트는 처음 6개 백엔드를 표시하고 나머지는 트래픽과 처리 중 요청을 합친 요약 노드로 묶여 그 자리에서 펼칠 수 있습니다. 접기 버튼이 없는 레이아웃에서는 상세 패널에서 리스너를 접을 수 있습니다.

## 확대/축소, 창 전체 화면, 캔버스 높이

캔버스는 드래그로 이동합니다. 휠은 페이지를 스크롤하고, Ctrl / ⌘ + 휠, 트랙패드 핀치, 두 손가락 핀치로 15%에서 250% 사이로 확대/축소합니다. 오른쪽 아래 컨트롤로 축소, 배율 표시(클릭하면 100%), 확대, 캔버스에 맞춤, 창 전체 화면(Esc로 종료)을 조작합니다. 캔버스 아래 막대로 높이를 조절하며 기기별로 기억되고, 더블 클릭하거나 자동 높이를 선택하면 복원됩니다.

## 범주별 마스킹

마스킹은 범주를 선택할 수 있습니다. 방문자 IP, 백엔드 주소, 수신 주소, 도메인 중 앞의 세 가지가 기본 선택되어 스크린샷과 라이브 방송에서 필요한 정보를 가릴 수 있습니다.

## 스크린샷과 소개 영상

홈페이지와 10개 언어 README는 해당 언어의 화면 스크린샷을 보여 주고, 토폴로지 애니메이션이 추가되었으며, 각 README 상단에서 2분짜리 무음 소개 영상으로 연결됩니다.

## 기타

- 목록 / 토폴로지 전환의 흔적이던 주석을 제거했습니다.

## 업그레이드 안내

- Docker는 새 이미지를 받은 뒤 컨테이너를 다시 만드세요. OpenWrt는 새 `.apk` / `.ipk`를 덮어 설치하고, fnOS는 앱 센터에서 새 `.fpk`를 설치하세요. 그 밖의 설치 방식은 "시스템 설정"에서 온라인 업그레이드할 수 있습니다.

# Gately v0.6.8.5 출시

2026년 11월 23일

[v0.6.8.5 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.5)

## IP 위치 표시(#107)

- 관리 화면에서 IP를 나열하는 모든 곳에 가져온 GeoIP 데이터베이스의 위치가 표시됩니다: 방문자 감사, 사이트 통계의 소스 IP, 실시간 연결, 웹 서비스와 침입 방지의 차단 목록, 모듈 로그, 네트워크 토폴로지의 활성 IP(마스킹 켜짐 시 숨김), 작업 감사, 포트 노킹 허용 주소. 사이트 통계는 국가 이름으로 표시됩니다.
- GeoIP 데이터베이스는 `.mmdb.gz`(DB-IP 배포 형식)와 MaxMind의 `.tar.gz`를 업로드/다운로드할 수 있으며, 압축 해제 후 크기 한도가 256 MB로 늘었습니다(DB-IP 도시 데이터베이스는 약 127 MB).

## 여러 단일 로그인 도메인(#108)

- 여러 상위 도메인 아래에서 사이트를 운영하는 인스턴스는 여러 단일 로그인 도메인을 설정할 수 있습니다. 각 도메인과 하위 도메인은 해당 도메인 안에서 로그인과 Passkey를 공유하며, 도메인끼리 서로 포함할 수 없습니다.
- SSO 세션은 소속 도메인을 기록하고 해당 도메인의 사이트에서만 유효합니다. 이전 버전의 세션은 계속 동작합니다. 이전 설정의 단일 `ssoDomain`은 목록에 병합됩니다. 사용자 페이지에서는 쉼표 또는 공백으로 구분해 입력합니다.

## 로그인 페이지 스타일

- 로그인, 비밀번호 변경, Passkey 페이지(OIDC 발급자 로그인 페이지 포함)의 모양을 바꿀 수 있습니다. 기본 스타일 외에 잠금 화면, 분할, 미니멀, 터미널, 편지, 브루탈리즘, 오로라, 픽셀, 블루프린트 9종이 내장되어 있습니다.
- 기본, 분할, 미니멀, 편지는 방문자의 라이트/다크 모드를 따르고, 브루탈리즘은 라이트 전용, 나머지는 다크 전용입니다.

## 수정

- **fnOS 게이트웨이**: HTTP 주소(fnOS 포트 5000/5666 또는 HTTPS를 끈 fnOS 앱)로 Gately를 열었을 때 설정 저장 등의 쓰기 요청이 "교차 출처 요청 거부"로 막히던 문제를 수정했습니다.
- **Docker**: 떠 있는 작업 패널이 마지막 컨테이너의 작업 버튼을 가리지 않습니다. 페이지 끝에 패널과 같은 높이의 여백을 추가했습니다(#110).

## 업그레이드 안내

- Docker는 새 이미지를 받아 컨테이너를 다시 만들고, OpenWrt는 새 `.apk` / `.ipk`를 덮어 설치하며, fnOS는 앱 센터에서 새 `.fpk`를 수동 설치하고, 그 밖의 환경은 "시스템 설정"에서 온라인 업그레이드할 수 있습니다.

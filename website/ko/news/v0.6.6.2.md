# Gately v0.6.6.2 출시

2026년 11월 14일

[다운로드 v0.6.6.2](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.6.2)

## EasyTier 네트워크

「네트워크 및 터널」에 EasyTier를 추가했습니다. `easytier-core` 프로세스를 관리하여 이 기기를 EasyTier 네트워크에 참여시키며, P2P 홀 펀칭으로 직접 연결을 우선 시도하고 연결되지 않으면 공용 노드나 직접 구축한 노드를 거쳐 중계합니다.

- 여러 인스턴스를 지원합니다. 인스턴스마다 독립된 프로세스이므로 한 기기를 서로 다른 네트워크에 각각 참여시킬 수 있습니다.
- 온라인 설치, 업데이트, 롤백을 지원하며 Windows 설치 패키지에는 wintun.dll 등 의존 파일이 포함됩니다.
- 네트워크 시크릿은 환경 변수로 프로세스에 전달되어 명령줄에 나타나지 않고 로그에서는 마스킹됩니다. 로컬 서브넷을 공유하거나 출구 노드로 동작하려면 시크릿이 필요합니다.
- 인스턴스 카드에 가상 IP, 수신 주소, 노드 목록(직접 / 중계, 지연, 연결 프로토콜)이 표시됩니다. TUN 장치를 만들 수 없거나 프로세스가 시작 직후 종료되면 원인이 표시됩니다.
- 활성화된 인스턴스가 같은 포트에서 수신하거나, 포트 포워딩이 같은 로컬 포트에 바인딩되거나, 장치 이름이 같으면 저장이 거부됩니다.

자세한 내용은 [Tailscale / NetBird / EasyTier / frp / cloudflared](/ko/docs/modules/tunnels)를 참고하세요.

## 침입 방지

- **TLS 핸드셰이크 실패 규칙(#90)**: 로그 규칙에 소스 「TLS 핸드셰이크 실패」가 추가되었습니다. 웹 서비스 HTTPS 리스너의 핸드셰이크 실패를 실패 유형, 리스너, 횟수별로 집계해 차단합니다. 핸드셰이크 중 끊김(EOF), 연결 재설정, 핸드셰이크 시간 초과, TLS 아님 또는 프로토콜 오류, 매개변수 협상 불가, 알 수 없는 도메인, 클라이언트 중단 등의 유형을 각각 선택할 수 있습니다. 「TLS 비정상 핸드셰이크」(1분 내 5회, 1일 차단)와 「TLS 핸드셰이크 중단」(1분 내 20회) 두 템플릿이 내장되어 있으며, 규칙 편집 화면에서 실패 원인을 붙여 넣어 어느 유형에 속하는지 확인할 수 있습니다. 출처가 웹 서비스의 「신뢰 프록시」에 있는 주소(CDN 원본 요청 노드)이면 집계하지 않습니다.
- **포트 스캔 탐지가 모듈 포트를 인식**: Gately의 각 모듈은 수신에 성공하면 즉시 해당 포트를 열린 포트로 등록하며 300밀리초 안에 반영됩니다. frps의 바인드, vhost, 외부 공개 dashboard, allowPorts 범위, frpc가 로그인 후 요청하는 원격 포트, EasyTier의 수신과 포트 포워딩, Tailscale과 NetBird의 외부용 SOCKS5 포트가 등록됩니다. 수신을 멈춘 포트도 10분 동안은 열린 것으로 취급하므로 frpc 재연결이나 프로그램 재시작 중의 정상 방문자가 포트 스캔으로 차단되지 않습니다.

자세한 내용은 [침입 방지](/ko/docs/modules/guard)를 참고하세요.

## 알림: 새 주소 로그인(#92)

알림 이벤트 「관리 콘솔: 새 주소 로그인」(`login.newip`, 경고 수준)이 추가되었습니다. 관리 콘솔 로그인에 성공했고 그 출처 주소가 이전에 로그인에 성공한 적이 없을 때 발생하며, 「보안 및 로그인」 템플릿에 포함되어 있습니다. 비밀번호, Passkey, 서드파티 로그인, fnOS 통합 게이트웨이 로그인을 모두 확인합니다. 첫 로그인은 기준만 기록하고, IPv6는 /64 대역으로 묶으며, 출처는 최대 200개까지 기록합니다. 자세한 내용은 [알림 센터](/ko/docs/modules/notify)를 참고하세요.

## 기타 개선

- 읽기 전용 계정과 읽기 전용 API 토큰이 관리 프로그램 설정을 볼 때 환경 변수는 이름만 표시되고 추가 인수는 전체가 숨겨집니다.
- 로그인 화면에서 사용자 이름이나 비밀번호가 비어 있으면 요청을 보내지 않고 바로 안내합니다.
- 목록 카드의 작업 버튼이 카드 하단에 고정되어 높이가 다른 카드에서도 버튼이 정렬됩니다. 폭이 좁은 카드는 필드를 두 열로 표시합니다.

## 업그레이드 안내

- Docker는 새 이미지를 받은 뒤 컨테이너를 다시 만드세요. OpenWrt는 새 `.apk` / `.ipk`를 덮어 설치하고, fnOS는 앱 센터에서 새 `.fpk`를 수동으로 설치하며, 그 밖의 배포 방식은 「시스템 설정」에서 온라인으로 업그레이드할 수 있습니다.
- 기존 침입 방지 규칙과 알림 규칙은 영향을 받지 않습니다. 새 주소 로그인 알림을 쓰려면 알림 센터에서 `login.newip` 규칙을 추가하거나 「보안 및 로그인」 템플릿을 다시 적용하세요.

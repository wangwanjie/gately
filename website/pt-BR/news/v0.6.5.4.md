# Gately v0.6.5.4 lançado

11 de novembro de 2026

[Baixar v0.6.5.4](/pt-BR/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.4)

## Wake-on-LAN: desligamento remoto

Escolha para um dispositivo uma conexão SSH do terminal Web e informe um comando de desligamento, e o cartão do dispositivo ganha o botão "Desligar" (API `POST /api/wol/devices/{key}/shutdown`).

- O formulário oferece comandos comuns para Linux (`shutdown -h now`), Windows (`shutdown /s /t 0`, com o servidor OpenSSH ativado) e macOS (`sudo -n shutdown -h now`);
- A conexão precisa ter sido aberta uma vez no terminal Web para registrar a chave do host; hosts desconhecidos nunca são aceitos sem supervisão;
- Cada desligamento abre uma nova conexão SSH e a fecha ao terminar, então uma conexão antiga de antes da reinicialização do dispositivo nunca é usada; o comando dura no máximo 30 segundos, um por vez por dispositivo; uma conexão que cai antes de o código de saída voltar conta como desligamento iniciado;
- Tokens de API precisam de `webterminal:write` além de `wol:write` para criar, editar ou copiar dispositivos ou acionar um desligamento, e de `webterminal:read` para listar as conexões SSH disponíveis.

## Wake-on-LAN: controle por voz Bemfa

Com o [Bemfa](https://cloud.bemfa.com) conectado, assistentes de voz como Xiao AI, Xiaodu e Google Assistant ligam e desligam dispositivos: crie no console do Bemfa um tópico terminado em `001` (tomada) ou `006` (interruptor), informe o mesmo tópico no dispositivo, informe a chave privada de usuário em "Wake-on-LAN → Bemfa" e ative, depois vincule sua conta Bemfa em apps como Mi Home ou Xiaodu.

"Ligar" acorda o dispositivo e "desligar" o desliga remotamente; após o sucesso o estado é gravado de volta no Bemfa, e acordar ou desligar pela interface ou API também o grava. O Gately conecta a `bemfa.com:9503` com MQTT 3.1.1 sobre TLS e verifica o certificado, e a chave privada aparece mascarada na API; o estado anterior que o servidor reenvia ao assinar não é executado, e o mesmo comando repetido em 10 segundos é executado uma vez. Só um cliente pode ficar online por chave privada.

## Serviço Web: porta HTTP adicional no listener

Um listener pode ganhar uma porta HTTP sem criptografia (por exemplo 80 ao lado de um listener HTTPS na 443) que compartilha todos os sites e configurações com a porta principal, de modo que o HTTP usa o mesmo listener sem cadastrar os sites de novo. Com HTTPS ativado, escolha "Redirecionar para HTTPS" (padrão; mantém o domínio, o caminho e a query string, troca a porta pela do endereço de acesso e usa 301 para GET/HEAD e 308 para os demais métodos) ou "Servir".

- Validações ACME HTTP-01, o protocolo PROXY e a liberação automática do firewall também valem para esta porta; se a porta estiver ocupada, a principal continua funcionando e o estado do listener mostra o motivo;
- Domínios sem site correspondente ficam sem redirecionamento: recebem o 404 de domínio desconhecido ou vão para o site padrão (um site padrão "fechar conexão" a fecha), como no HTTPS; o redirecionamento HTTP na mesma porta agora segue a mesma regra;
- Ao salvar, verifica-se se a porta HTTP conflita com portas de outros listeners; quando um listener é acessado por Roteamento por protocolo ou Redirecionamento de portas sem porta de acesso preenchida, o editor lembra de informar a porta de entrada.

## Painéis de navegação: temas

Os painéis de navegação usam as mesmas paletas da interface de administração (originais do Gately e paletas clássicas), e o editor do painel define o tema padrão. Os visitantes trocam o tema pelo botão de paleta no canto superior direito, que funciona como na interface de administração: modo claro, escuro ou do sistema, paletas com prévia ao passar o mouse que se espalham a partir do ponto do clique ao serem escolhidas, e cor de destaque e arredondamento personalizados; no celular o seletor abre de baixo. A escolha fica salva no navegador do visitante e é compartilhada entre o painel e a interface de administração quando ambos estão no mesmo domínio. Veja [Serviço Web · Painéis de navegação](/pt-BR/docs/modules/web#nav-panel).

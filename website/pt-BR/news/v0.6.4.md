# Gately v0.6.4 lançado

3 de novembro de 2026

[Baixar v0.6.4](/pt-BR/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.4) · [Build personalizado online](https://build.gately.cn)

## Build personalizado

Além dos três módulos principais (Redirecionamento de portas, Serviços Web e Certificados SSL), os outros 22 módulos podem ser removidos na compilação, e os idiomas da interface podem ficar só em chinês simplificado, ou em chinês simplificado, chinês tradicional e inglês:

- Abra o [build.gately.cn](https://build.gately.cn) e marque os módulos e idiomas (ou comece pelos presets "Core only", "Router" ou "NAS"); a página estima o tamanho em tempo real e gera online binários para Linux / Windows / macOS / FreeBSD, pacotes para OpenWrt e fnOS, ou uma imagem Docker multiarquitetura para amd64, arm64 e arm/v7; artefatos com as mesmas opções são reaproveitados, sem compilar de novo;
- Em linux/arm64, por exemplo: a edição completa tem 33,6 MB, só o núcleo cerca de 19,9 MB e o preset Router com chinês simplificado cerca de 21,2 MB; a imagem Docker do preset Router com chinês simplificado baixa cerca de 18,7 MB (imagem completa: 51,9 MB), e uma imagem sem o gerenciamento de Docker não inclui docker-cli nem compose, e uma sem a Prevenção de intrusão e o STUN não inclui nftables;
- Para os módulos não compilados, os arquivos de configuração ficam intactos, os interruptores em Configurações e as permissões dos tokens de API continuam valendo, as APIs respondem 404 informando que o módulo não está incluído neste build, e a interface oculta as páginas e opções correspondentes; ao voltar para a edição completa, tudo reaparece;
- A página Sobre lista os módulos removidos deste build, com um link que abre o construtor com as mesmas opções. Builds personalizados não oferecem atualização online (ela baixa a edição completa); quando sair uma nova versão, gere-a de novo com as mesmas opções e use "Enviar pacote de atualização";
- Para compilar por conta própria, use as build tags `no_<módulo>` e `lang_zh` / `lang_cjken`, `GATELY_LOCALES` no frontend ou argumentos de build do Dockerfile como `GATELY_TAGS`; o `tools/custombuild` converte uma seleção nesses parâmetros.

Veja [Visão geral dos módulos · Builds personalizados](/pt-BR/docs/modules/#custom-build) e [Compilar a partir do código-fonte](/pt-BR/download#custom-build).

## Ocultar a porta de administração

"Configurações → Controle de acesso" ganhou "Resposta não autorizada", que vale para origens banidas, para acessos pela internet com o acesso somente pela rede local ativado e para solicitações que não passaram pela entrada segura:

- É possível escolher a página de aviso padrão, uma página 404 simples, uma página em branco, fechar a conexão, não responder até esgotar o tempo ou uma página HTML personalizada (com o código de status que quiser);
- Fechar e não responder são decididos pela origem no momento em que a conexão é estabelecida, então o HTTPS não envia certificado; solicitações encaminhadas por um proxy confiável recebem automaticamente uma 404 simples, para que o proxy da frente não mostre a própria página de erro; conexões retidas têm limite de duração e de quantidade;
- Nos modos de ocultação, as respostas deixam de levar os cabeçalhos de segurança próprios do console de administração, e as páginas personalizadas são exibidas em um sandbox que bloqueia scripts e recursos externos.

A porta em si ainda pode ser encontrada por varredura; para ocultá-la por completo é preciso um firewall. Veja o [Guia de reforço de segurança](/pt-BR/docs/guide/hardening).

## Páginas de erro dos sites

- A aba "Páginas de erro" de um site dos Serviços Web permite escolher, para as páginas 404 e 5xx geradas pelo Gately, o estilo padrão, um dos 10 estilos embutidos (Minimalista, Terminal, Neon, Céu estrelado, Jornal, Brutalista, Aurora, Pixel, Planta, Cadeia de status) ou uma página personalizada da biblioteca de páginas; cada estilo tem miniatura e pré-visualização para desktop / celular;
- A biblioteca de páginas aceita HTML enviado ou colado, ou a referência a um arquivo `.html` no servidor; ao salvar, scripts, atributos de evento, formulários e conteúdos semelhantes são verificados e removidos, marcadores como `{code}`, `{title}`, `{host}` e `{path}` são suportados, e as páginas são servidas com uma CSP que bloqueia scripts e recursos externos;
- Sites de proxy reverso podem interceptar códigos de status específicos do backend (como `404, 500-599`) e substituir apenas as solicitações de navegadores que abrem uma página, deixando as solicitações de API como estão;
- As configurações do site padrão também valem para solicitações que não correspondem a nenhum site, e "Ordenar e lote" permite definir o estilo de página de erro de vários sites de uma vez.

Veja [Serviços Web · Páginas de erro](/pt-BR/docs/modules/web#error-pages).

## Outras melhorias

- A busca do DNS dinâmico filtra por registro: quando o nome, grupo, observação ou provedor da tarefa corresponde, todos os registros dela aparecem; caso contrário, só os registros correspondentes são listados, e tarefas e grupos recolhidos se expandem durante a busca; a busca dos Serviços Web expande automaticamente os listeners recolhidos;
- Rótulos longos da página Configurações quebram linha automaticamente e não se sobrepõem mais aos campos em idiomas como alemão e russo;
- Quando uma solicitação do console recebe uma resposta que não é JSON (por exemplo, bloqueada pela entrada segura depois que a sessão expira), o console pede para recarregar ou reabrir a entrada segura;
- "Recarregar" na página de erro padrão agora é um link comum, que também funciona sob uma CSP que bloqueia scripts;
- Pacotes de diagnóstico, `GET /api/status` e `GET /api/system/info` trazem as informações do build (se é personalizado e quais módulos e idiomas inclui);
- A CI verifica as combinações de build tags dos presets.

## Notas de atualização

- Docker: baixe a nova imagem e recrie o contêiner; com o socket do Docker montado, o Gately também pode se atualizar pela própria página Docker. OpenWrt: instale o novo `.apk` / `.ipk` por cima do anterior. fnOS: instale o novo `.fpk` manualmente na Central de Aplicativos. Outras implantações podem atualizar online na página Sobre.
- Quem usa a edição completa não precisa fazer nada; o formato de configuração não mudou.

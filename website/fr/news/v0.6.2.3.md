# Gately v0.6.2.3 publié

2 novembre 2026

Il s’agit d’une mise à jour d’amélioration de la série v0.6.2. Le format de configuration est inchangé.

[Télécharger v0.6.2.3](/fr/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.3)

## Topologie réseau sur sa propre page

La topologie quitte l’onglet de la page Services web pour la page Topologie réseau, sous Web dans le menu latéral, avec un bouton sur la page Services web qui l’ouvre. Les fenêtres de statistiques et de connexions s’ouvrent sur la page de topologie, et Modifier renvoie à Services web et ouvre l’éditeur du site. Le canevas suit le mode clair ou sombre du thème actuel.

## Sept dispositions

Le menu des dispositions propose Arbre, Vertical, Radial, Sankey, Sunburst, Treemap et Bulles, chacune avec une icône et une description d’une ligne ; le changement se fait en fondu et le choix est mémorisé. Chaque écoute affiche ses 8 premiers sites et chaque site ses 6 premiers backends ; le reste est regroupé dans un nœud de synthèse avec leur trafic et leurs requêtes en cours cumulés, qui se déplie sur place. Dans les dispositions sans boutons de repli, les écoutes se replient depuis le panneau de détails.

## Zoom, plein écran de fenêtre et hauteur du canevas

Faites glisser le canevas pour le déplacer. La molette fait défiler la page ; Ctrl / ⌘ + molette, pincement du trackpad ou pincement à deux doigts zoome entre 15 % et 250 %. Les commandes en bas à droite réduisent, affichent le niveau (clic pour 100 %), agrandissent, ajustent au canevas et activent le plein écran de fenêtre, quitté avec Échap. Une barre sous le canevas règle sa hauteur, mémorisée par appareil ; double-clic ou Hauteur automatique la rétablit.

## Masquage par catégorie

Le masquage permet de choisir des catégories : IP des visiteurs, adresses des backends, adresses d’écoute et domaines. Les trois premières sont cochées par défaut, pour que captures et directs masquent le nécessaire.

## Captures et vidéo de visite

La page d’accueil et les README dans les 10 langues affichent des captures de l’interface dans la langue correspondante, une animation de la topologie s’ajoute et le haut de chaque README renvoie vers une vidéo de visite muette de 2 minutes.

## Divers

- Suppression d’un commentaire résiduel de l’ancien sélecteur Liste / Topologie.

## Notes de mise à niveau

- Docker : récupérez la nouvelle image et recréez le conteneur. OpenWrt : installez le nouveau `.apk` / `.ipk` par-dessus l’ancien. fnOS : installez le nouveau `.fpk` dans le Centre d’applications. Les autres installations peuvent être mises à niveau en ligne dans les Paramètres.

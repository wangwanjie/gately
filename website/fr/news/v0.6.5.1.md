# Gately v0.6.5.1 publié

7 novembre 2026

[Télécharger v0.6.5.1](/fr/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.1)

## Démarrage automatique : gately service

Les installations à partir du binaire peuvent enregistrer Gately directement comme service système : `sudo ./gately service install` (sous Windows, `.\gately.exe service install` dans un terminal administrateur). Linux reçoit une unité systemd, macOS un démon launchd (`-user` enregistre un élément d’ouverture de session sans sudo) et Windows un service système ; Gately démarre aussitôt et est relancé après un plantage. Gérez-le ensuite avec `gately service uninstall|start|stop|restart|status` ; la désinstallation conserve le répertoire de configuration.

- Sous Windows, le répertoire de configuration par défaut `%ProgramData%\Gately` n’est accessible qu’à SYSTEM et aux administrateurs ;
- l’installation avertit quand le binaire ou le répertoire de configuration peuvent être modifiés par d’autres utilisateurs que root, par exemple un binaire encore dans Téléchargements.

Voir [Démarrage automatique](/fr/docs/guide/install#service).

## Longues listes paginées

La liste des blocages de la prévention d’intrusion, les blocages de l’interface dans les paramètres globaux des services Web, les listes de fichiers des montages de stockage et des conteneurs Docker et le gestionnaire de fichiers SFTP du terminal Web sont désormais paginés, avec 20 / 50 / 100 / 200 lignes par page mémorisées pour chaque liste. Une page de 4000 blocages s’affiche en 0,23 s au lieu d’environ 2,6 s ; la recherche filtre avant la pagination, et l’actualisation périodique et le déblocage conservent la page courante. La case à cocher de l’en-tête SFTP n’agit que sur la page courante, pour ne pas supprimer par erreur des fichiers invisibles.

## Ajout en lot d’enregistrements DDNS

L’onglet Enregistrements de l’éditeur de tâche gagne **Ajout en lot** : un domaine par ligne, complet ou seulement l’hôte, suivi éventuellement d’un type et d’une valeur (comme `cdn.example.com CNAME target.example.net`). Avant l’ajout, un aperçu montre les enregistrements à ajouter, les doublons ignorés et les lignes invalides, à corriger d’abord ; les noms de domaine internationalisés sont convertis en punycode. Voir [Ajout en lot](/fr/docs/modules/ddns#batch).

## crash.log

Gately écrit les plantages du runtime Go (panic, fatal error) avec leurs piles dans `crash.log`, dans le répertoire de configuration, et note le dernier moment où le processus était vivant quand il est tué, par exemple par l’OOM killer. Le démarrage suivant le signale dans le journal système, et le paquet de diagnostic l’inclut, anonymisé. Utile sous Docker, LXC et fnOS, où la sortie d’erreur standard disparaît après un redémarrage. Voir [Paquet de diagnostic](/fr/docs/reference/diagnostics).

## Autres améliorations

- Les binaires macOS sont signés avec un certificat Developer ID et notariés par Apple : ils s’exécutent dès le téléchargement ; voir [Vérifier les artefacts publiés](/fr/docs/guide/verify).
- Le modèle de demande de fonctionnalité demande la version, le système et l’architecture.

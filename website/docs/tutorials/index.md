# 教程

这里的教程按难度排列，每篇都从一个具体目标出发，带着你在管理界面里一步步完成，并给出验证方法和常见问题。还没装好 Gately 的话，先看[安装](/docs/guide/install)；想先看看界面长什么样，可以打开[在线演示](https://demo.gately.cn)，点「演示账号一键进入」随便看（只读，每小时重置）。

教程里的截图都来自演示实例，域名、地址都是示例值（`example.com`、`192.0.2.x`、`203.0.113.x` 等），照着做时换成你自己的。

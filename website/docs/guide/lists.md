# 列表分组与排序

条目较多的列表都可以分组、手动排序和搜索，操作方式在各页面一致。顺序和分组只影响管理界面的显示，修改后不会重启运行中的实例，也不会断开连接。

## 支持的列表

| 页面 | 列表 |
| --- | --- |
| 动态域名 | 任务；任务内的解析记录 |
| STUN 穿透 | 规则 |
| 端口转发 | 规则 |
| SSL 证书 | 证书 |
| Web 服务 | 监听内的站点（监听本身可上移、下移） |
| WAF 防火墙 | 实例 |
| 入侵防护 | 日志规则 |
| frp | frpc 实例、frps 实例、代理 |
| Cloudflare 隧道 | 隧道 |
| File Browser | 实例 |
| 存储挂载 | 挂载 |
| 网络唤醒 | 设备 |
| 计划任务 | 任务 |
| 通知中心 | 渠道、规则 |
| Web 终端 | 保存的连接 |
| API 令牌 | 令牌 |

这些列表大多同时提供卡片视图与紧凑视图，在列表右上角切换；窄屏下固定为卡片视图。

## 分组

在编辑对话框中填写「分组」（最长 64 个字符，可从已有分组中选择），留空为未分组。只要有一个条目设置了分组，列表就按分组显示可折叠的区块：分组按首次出现的顺序排列，未分组的条目排在最后，各分组的折叠状态保存在浏览器中。搜索框可按名称、分组、备注等过滤条目，搜索时展开全部分组。

鼠标移到分组标题上，点铅笔按钮可以重命名分组：组内条目一起改为新名称，位置和顺序不变；改成已有分组的名称时，确认后两个分组合并。

## 排序模式

点击「排序」进入排序模式，此时显示全部条目，搜索与筛选暂不生效：

- 用箭头在分组内上移、下移条目，或在分组标题上整组移动；
- 桌面端可以直接拖动条目；拖到其他分组的条目或分组标题上即加入该分组；
- 勾选多个条目（分组标题的复选框可选中整组）后拖动其中任一项，所有选中项按当前顺序一起移动；
- 工具栏可以把选中的条目批量移到指定分组，留空则移出分组。

手机等窄屏设备不支持拖动，用箭头和工具栏完成同样的操作。

## 各页面的补充说明

- **动态域名**：任务卡片上的「记录排序」打开对话框，调整该任务内解析记录的顺序与分组，保存后立即生效，不会重新同步；编辑任务时也可在「解析记录」页签中打开同一对话框，随任务一起保存。记录设置了分组时，卡片中的记录按分组显示，每组可以单独收起。
- **frp**：代理列表可以按 frpc 实例筛选；排序模式下显示全部代理，调整的是完整顺序。
- **API 令牌**：未手动排序前按创建时间从新到旧显示；调整过顺序后按保存的顺序显示，新建的令牌排在最前。
- **认证用户**：「使用共享用户的站点」按监听显示，监听内的站点再按 Web 服务中的分组归类；监听和分组都可以单独收起，工具栏可一键全部收起或展开。

## 接口

通用列表接口都提供 `PUT <列表路径>-order`（请求体 `{"keys": [...]}`，须包含全部条目）调整顺序，`PUT <列表路径>-group`（请求体 `{"keys": [...], "group": "..."}`）批量设置分组，例如 `PUT /api/stun/rules-group`。DDNS 任务内的记录使用 `PUT /api/ddns/tasks/{key}/records-layout`，API 令牌使用 `PUT /api/tokens/order` 与 `PUT /api/tokens/group`。详见[接口清单](/docs/reference/api-reference)。

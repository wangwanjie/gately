# 配置与运行参数

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| `-c` | 配置目录，也可以用环境变量 `GATELY_CONFIG_DIR` 指定 |
| `-listen` | 覆盖管理界面监听地址，例如 `:16680` |
| `-apply` | 声明式配置目录，也可以用环境变量 `GATELY_APPLY_DIR` 指定，见下文 |
| `-version` | 输出版本信息 |

| 环境变量 | 说明 |
| --- | --- |
| `GATELY_INITIAL_PASSWORD` | 首次启动时的管理员初始密码（至少 8 位），不设置时为默认密码 `gately.cn`；账号已存在时不起作用 |

## 配置目录

所有配置保存在配置目录中，每个模块一个 `<name>.json` 明文文件，原子写入，文件权限 0600。因此：

- 可以直接用文本编辑器查看；
- 可以把目录纳入 git，用 diff 审计每次变更并随时回滚；
- 备份只需复制目录。

::: warning 注意
`ssl.json` 中含有证书私钥，纳入版本库前请确认仓库为私有，或把该文件加入忽略列表。
:::

## 声明式配置

指定 `-apply <目录>` 后，每次启动会把该目录下的 `<名称>.json` 覆盖到配置目录，内容相同的文件不会重写。适合把配置放在 git 仓库、Kubernetes ConfigMap 或部署脚本中统一下发。

- 写入前校验是合法 JSON，任一文件无效则拒绝启动；
- `account.json` 与 `tokens.json` 不允许覆盖，账号与令牌只能在管理界面管理；
- 被覆盖的旧内容会保存在 [配置历史](/docs/guide/audit) 中，可随时回滚。

## 外部程序目录

Tailscale、frp、cloudflared 与 File Browser 托管官方的外部程序，按以下顺序查找可执行文件：

1. 模块设置中填写的路径；
2. 配置目录下的 `bin/` 子目录；
3. `PATH`。

各模块页面可以在线安装、更新与回滚，程序装在 `bin/` 下，旧版本保存在 `bin/.versions/`，详见 [在线安装、更新与回滚](/docs/modules/tunnels#install)。也可以自行把二进制放进配置目录，Docker 部署时例如 `./gately-data/bin/frpc`；Tailscale 需要同时提供 `tailscale` 与 `tailscaled`。

## 运行日志

系统日志与各模块的运行日志默认写入配置目录下的 `logs/`，重启或升级后仍可在「系统日志」和各模块页面查看：

- 每个来源一个 JSON Lines 文件：`logs/<模块 ID>.log`，系统日志为 `logs/gately.log`；启动时按「日志保留条数」从文件恢复最近的日志；
- 有新日志时最多延迟 1 秒批量写入；单个文件超过上限（默认 2 MB）后轮转为 `.1`，只保留这一份历史，每个来源最多占用两倍上限；
- Web 服务的访问日志量大、需要回看，单独按天归档：当前文件跨天（或超过总大小的四分之一，最大 16 MB）时改名为 `logs/webservice.<开始时间>.log` 并在后台压缩为 `.log.gz`，按「访问日志保留天数」（默认 7 天）与「访问日志总大小」（当前文件与全部压缩归档合计，默认 32 MB，且不超过日志所在分区容量的 5%）删除最旧的归档；
- 每个模块记录出现过的日志来源（`logs/<模块 ID>.sources`），重启后保留；
- 「设置 → 网络与运行 → 运行参数」中可以关闭「日志落盘」，调整「日志文件上限」「访问日志保留天数」「访问日志总大小」，或把「日志目录」改到其他绝对路径（例如外接硬盘上的目录，不存在时自动创建为仅本用户可访问），立即生效；修改日志目录后新日志写到新目录，原目录中的文件保留不动；关闭落盘后日志只保存在内存，重启后清空；
- 在页面上清空某个模块的日志会同时删除对应的文件、历史文件、压缩归档与来源记录；
- 配置备份不包含 `logs/` 与操作审计日志 `audit.log`。

### 查看与筛选 {#log-filter}

「系统日志」页和各模块页面底部的日志卡片使用同一个日志查看器，可以组合以下条件筛选，修改后立即生效，新日志也只追加符合条件的部分：

- 级别、来源（下拉列出模块配置中的全部来源与日志中出现过的来源，例如 Web 服务的全部监听器，包括还没有访问记录或日志只在文件里的；也可以直接输入）；
- 关键词：空格分隔表示同时包含，双引号包住短语，词前加 `-` 表示排除，例如 `GET "timeout" -debug`，命中的部分会高亮；界面为其他语言时，按界面上看到的译文搜索即可；
- 「不包含」：包含其中任意一个词的日志不显示，与关键词同时生效；写法同关键词（空格分隔、双引号包住短语），例如 `debug "health check"`。要排除本身以 `-` 开头的词，用双引号包住，如 `"-v"`；
- 「更多筛选」中的 IP：可填完整地址、网段（如 `10.0.0.0/8`）或地址的一部分，多个以逗号分隔；日志没有单独记录 IP 时会从日志内容中识别地址，登录失败、入侵防护等日志同样适用；前加 `!` 或 `-` 表示排除，如 `!1.2.3.4, !10.0.0.0/8` 不显示这些来源，也可以与包含项组合（`10.0.0.0/8, !10.0.0.5`）；
- 「更多筛选」中的时间范围：最近 15 分钟到 7 天，或自定义起止时间；
- Web 服务的工具栏还有两个显示开关，只影响页面显示，日志照常保存，选择记在浏览器里：「隐藏被封禁来源」不显示来源已被封禁而被拒绝的请求（站点在 CDN 后面时，内核封禁对回源连接不起作用，被封的访客仍会在 Web 层被拒绝并留下 403 / 444 记录），同时隐藏当前仍在封禁中的来源的全部请求（包括封禁前触发封禁的那些请求，解封或到期后重新显示）；「隐藏后台自身请求」不显示带本实例管理后台登录态的请求，例如经 Web 服务站点访问后台时日志页的轮询，默认开启。这两类日志行尾分别带「拦截原因=已封禁」「后台用户=…」标签，对应接口参数 `hideBanned=1`、`hideAdmin=1`（只认管理员会话，只读账号不算；被拦截的请求不带后台用户标记）；
- Web 服务还可按站点名称或域名、状态码（`404`、`4xx`、`500-599`，多个以逗号分隔）筛选；WAF 防火墙可按域名筛选，命中日志会记录域名与规则 ID。

点击日志中的来源，或行尾的「站点=…」「域名=…」等标签，可直接按该值筛选；Web 服务日志中点「站点=…」按站点名称完整匹配，工具栏显示可移除的「站点：…」标签（接口参数 `site`），不会混入名称相近的站点。接口还接受 `listener` 参数，按监听器键精确匹配；两个监听器同名时，日志来源名称附上监听地址以便区分，例如 `HTTPS (0.0.0.0:443)` 与 `HTTPS ([::]:443)`，名称唯一的监听器保持原名。「加载更早的日志」在内存中的日志不够时，会继续查找日志文件中保留的历史（包括 Web 服务的压缩归档，按时间范围筛选时跳过范围外的归档），因此开启落盘后能筛选的范围不受「日志保留条数」限制。接口 `GET /api/logs` 与 `GET /api/<模块>/logs` 支持相同的筛选参数，见 [API 参考](/docs/reference/api-reference)。

日志区高度可以调整：拖动日志区下方的横条（触屏可直接按住拖动），双击横条恢复默认高度，横条获得焦点后也可用方向键调整；页面里的日志卡片与站点日志弹窗分别记住各自的高度，保存在当前浏览器。工具栏右侧的全屏按钮让日志占满整个窗口，再点一次或按 Esc 退出。向上翻看历史时，新日志照常追加，当前位置保持不动，日志区右下角显示「回到最新」，期间到达的新日志条数也显示在按钮上；滚回底部或点击按钮后恢复自动滚动。

### 导出 {#log-export}

日志工具栏的「导出」按当前筛选条件导出全部日志，包括日志文件与压缩归档中保留的历史，按时间从旧到新排列，由浏览器直接下载保存：

- CSV（表格软件）：UTF-8 带 BOM，Excel 可直接打开；列为时间、级别、来源、消息与 IP、域名、站点、状态码等字段；以 `=`、`+`、`-`、`@` 开头的单元格前加单引号，防止表格软件把访客提交的路径当作公式执行；
- JSON Lines：每行一条日志，字段与日志接口相同；
- 消息按界面语言导出；只读账号与只有读权限的 API 令牌也可以导出，内容与查看时一样隐藏地址中的密码与令牌；
- 接口为 `GET /api/logs/export` 与 `GET /api/<模块>/logs/export`，`format` 取 `csv` 或 `jsonl`，其余筛选参数与查看日志相同；来源列表接口为 `GET /api/logs/sources` 与 `GET /api/<模块>/logs/sources`。

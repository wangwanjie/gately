# 安全模型与隐私承诺

Gately 运行在网络边界，经手 DNS 服务商密钥、证书私钥与各类凭据，因此安全与透明是首要设计目标。

## 隐私承诺

- **不连接项目方服务器**：不上报设备信息，不下发远程配置。默认每 12 小时匿名读取 GitHub 上的发布列表与安全公告，只用于提示新版本与安全更新，可以关闭，详见[自动检查更新](/docs/guide/install#update-check)。
- **对外地址可见可改**：公网 IP 查询、STUN 服务器等地址都在界面中展示，可修改或关闭。
- **第三方登录自主**：GitHub、Google、QQ、OIDC 登录使用你自己申请的 OAuth 应用，不经过任何中转。
- **自主升级**：程序不会在后台下载或替换自身；Linux 二进制部署的在线升级只在管理员点击后执行，先验证发布签名再核对 SHA-256，并保留旧版本，升级时机由你决定。

## 数据保护

- 配置为明文 JSON，文件权限 0600，可审计、可回滚。
- 敏感字段在 API 输出中脱敏；界面上的眼睛按钮按需取回已保存的明文，需要写权限。以 bcrypt 哈希保存的网页用户密码、OIDC 客户端密钥和私钥不会返回；开启两步验证的共享用户可以重新查看二维码。Docker 容器的环境变量、启动命令与进程命令行同样处理：没有 Docker 写权限时显示为 `********`。
- cloudflared 的令牌通过环境变量传递，不会出现在进程列表中；frp、Tailscale 的令牌与密钥以 0600 权限保存。

## 认证与访问控制

- bcrypt 密码哈希，HMAC 签名会话令牌；
- 会话吊销：退出登录会在服务端吊销当前会话令牌，泄露的令牌立即失效；「设置 → 账号与安全 → 登录会话」的「退出所有设备」让全部管理界面会话失效（API 令牌不受影响）；修改密码、启停两步验证与重置密码同样使全部会话失效。吊销记录保存在账号文件中，重启后仍然有效，随令牌过期清理，数量有上限；
- 出站请求限制：「设置 → 网络与运行」的「出站请求限制」默认关闭，开启后 Webhook、通知、IP 列表订阅、DDNS 回调与 IP 查询地址、更新检查与程序下载、第三方登录等管理员配置的出站请求在连接时拒绝回环、私网、链路本地（含云厂商元数据地址 169.254.169.254）与 ULA 地址，对域名解析结果和重定向同样生效；反向代理上游、网络唤醒、存储挂载等面向内网的功能不受影响；
- 慢速请求防护：管理端口对带请求体的请求限制读取速度，普通接口的请求体需在 60 秒内读完；备份恢复、升级包与文件上传等大文件接口不限总时长，但要求持续发送并保持最低平均速率（每秒 4 KiB），慢速占用连接的客户端会被断开；
- 密码规则：管理员密码长度 10～72 字节，拒绝常见弱口令（含首尾加数字或符号、`p@ssw0rd` 式字符替换等变形）、包含 gately 或用户名、连续字符（如 `123456`、`qwerty`）、重复字符或片段，以及只含一种字符的密码（16 位以上的口令短语放宽字符种类要求）；输入时实时显示强度；
- 强制改密：默认密码 `gately.cn` 是公开的。管理员仍在使用默认密码或强度不足的密码时，登录后弹出无法关闭的改密对话框，改完才能继续使用；在此之前，登录会话除修改密码、切换界面语言与退出所有设备外的写操作一律被服务端拒绝，API 令牌仍可调用，但不能修改账号、两步验证、通行密钥、附加账号、API 令牌、系统设置与 Web 终端安全设置（也不能从备份恢复或回滚系统设置与 Web 终端的历史版本）；新密码不能是默认密码，改过之后也不能改回；
- 重置：忘记密码或丢失两步验证器时只能在服务器上用 `gately reset-password` / `gately reset-totp` 重置（需要读写配置目录并输入 `yes` 确认），重置后所有会话失效并记入审计日志，详见 [重置密码与两步验证](/docs/guide/install#reset)；
- Passkey（WebAuthn）登录：只保存公钥，强制用户验证（指纹、面容或 PIN），签名计数防克隆；需要通过域名与 HTTPS（或 localhost）访问；
- 两步验证（TOTP，通过 RFC 6238 测试向量验证）；
- 只读账号：可查看状态与配置，不能修改、下载备份、读取密钥或打开终端；重置密码或删除后会话立即失效；只读账号与只有读权限的 API 令牌读取配置时，站点共享用户密码、分享链接令牌、请求头与响应头的值、各类密钥以及地址中的密码和查询参数一律显示为 `********`；「审计日志」「配置历史」「API 令牌」「设置」只对管理员开放，只读账号的界面中不显示对应入口，直接打开链接时回到总览；
- 只读账号与只有读权限的 API 令牌同样看不到命令与脚本、托管程序的附加启动参数与环境变量、Webhook 等 HTTP 请求的请求体，以及 DNS 服务商凭据里除接入点、请求方法这类设置以外的附加字段（如自定义回调的请求头与请求体）；
- 登录失败限流与递增锁定：同一来源连续失败达到上限后被锁定，反复被锁定时每次锁定时长翻倍，最长 24 小时；
- 陌生来源失败预算：10 分钟内，所有从未成功登录过的地址累计登录失败达到预算（「设置 → 账号与安全」中的「陌生地址失败预算」，配置项 `loginGlobalLimit`，默认 20，-1 关闭）后，陌生地址的密码登录暂时返回 429，并发出「认证：疑似分布式爆破」通知事件；曾成功登录过的地址不受影响，用来抵御分散在大量地址上的爆破。Passkey 登录使用独立的按来源限流，不受密码失败与陌生来源预算影响；
- 关闭密码登录：注册了 Passkey 后，可在「设置 → 账号与安全」的 Passkey 卡片中关闭密码登录，之后管理员账号只能用 Passkey 或第三方登录，密码无法再被爆破（只读账号不受影响）；关闭状态下不能删除最后一个 Passkey，丢失全部 Passkey 时在服务器上运行 `gately reset-password` 会重新开启密码登录；
- 安全评分：「设置 → 账号与安全」顶部的安全评分（`GET /api/system/security`）按当前配置检查七项并给出 0～100 分：管理员密码（35 分）、二次验证（TOTP 或 Passkey，20 分）、安全入口（15 分）、登录失败锁定策略（10 分）、HTTPS（10 分）、陌生地址失败预算（5 分）、管理员用户名不是 admin 等常见名称（5 分）；管理端没有暴露到公网（仅内网访问或只监听回环地址）时，安全入口、HTTPS 与用户名三项视为满分。存在高风险或建议加固时管理界面顶部提示（建议加固的提示可暂缓 7 天），点「去加固」跳到对应设置；
- 本机反向代理：管理界面放在本机 nginx、haproxy 或 Gately Web 服务之后时，只信任本机地址传来的 `X-Real-IP` / `X-Forwarded-For`，仅内网访问、登录限流与审计日志据此取得真实来源，可在「设置 → 访问限制」关闭或添加额外可信代理；两个请求头不一致时以代理追加的 `X-Forwarded-For` 为准，其中一个是内网地址、另一个是公网地址时取公网地址，伪造内网地址无法绕过仅内网访问；建议代理同时写入两个请求头（nginx：`proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;`）；
- 安全入口、仅内网访问、管理界面 HTTPS；模块免登录接口（`/api/<模块>/public`，如[网络唤醒客户端](/docs/modules/tools#agent)）凭有效的设备凭据可以越过安全入口，封禁与仅内网访问的限制仍然生效；
- 未授权访问响应：被封禁、仅内网时的外网访问与未经过安全入口的请求，可以改为普通 404、空白页、断开连接、不响应直到超时或自定义页面，隐藏管理端口的特征，详见 [安全加固清单](/docs/guide/hardening)；
- 飞牛统一网关：飞牛安装包经飞牛统一网关访问时，由飞牛负责访问控制，只有飞牛管理员能打开；「飞牛登录态自动登录」默认关闭，开启后已登录的飞牛管理员以 Gately 管理员身份直接登录（跳过两步验证），普通飞牛用户仍需登录，详见 [飞牛 fnOS 原生应用](/docs/guide/install#fnos)；
- 经飞牛统一网关访问时，修改状态的请求与 WebSocket 连接只接受管理界面自身页面发出的请求：浏览器标明同源（`Sec-Fetch-Site: same-origin`），或者页面来源此前已由管理员会话或管理员的密码、Passkey 登录确认过；同一台 NAS 其他端口上的页面不能借用管理员的登录状态。经 HTTP 地址（如飞牛的 5000 端口、飞牛 App 关闭 HTTPS 时）访问时浏览器不发送 `Sec-Fetch-Site`，管理界面的请求会带上专用请求头 `X-Gately-Page` 表明来源，其他页面无法带上它（需先通过跨域预检，而管理接口不放行）。经网关的登录限流按飞牛用户计算；
- 内容安全策略：管理界面的页面只加载自身的脚本，不能被其他站点嵌入，接口响应不加载任何资源；登录 Cookie 带 `HttpOnly` 与 `SameSite=Strict`，经 HTTPS 访问（包括可信代理或飞牛统一网关转发的 HTTPS）时带 `Secure`；
- 功能模块开关：在「设置 → 功能模块」关闭不用的模块后，该模块不启动服务、不提供管理接口，可缩小暴露面；[定制构建](/docs/modules/#custom-build)可以在编译时直接去掉不用的模块；
- 多令牌 API：每个令牌只拥有创建时勾选的模块读写权限，可设置过期时间，并记录最近使用的来源 IP；账号、两步验证、令牌管理以及备份、恢复、重启、系统设置接口只接受登录会话，详见 [API 令牌与 OpenAPI](/docs/reference/api)；
- 站点访问控制：认证失败自动封禁、GeoIP 国家过滤、路径规则，详见 [Web 服务](/docs/modules/web)；
- 配置备份支持加密（scrypt + AES-GCM），详见 [配置备份](/docs/modules/backup)。

## 审计与可追溯

操作审计日志记录登录、配置变更与敏感访问，配置历史保留每个配置文件被覆盖前的版本并支持一键回滚，详见 [审计与配置历史](/docs/guide/audit)。发布产物附带 cosign 签名、构建来源证明与 SBOM，校验方法见 [校验发布产物](/docs/guide/verify)。

## 高风险功能的默认值

本机 Shell 终端默认关闭。SSH 终端采用「首次信任」策略记录主机密钥指纹。

# Web 终端

在浏览器中连接 SSH、Telnet 服务器或本机 Shell，会话在服务端持久保存，可断线重连。入口为侧边栏「Web 终端」。

## 连接类型

| 类型 | 说明 |
| --- | --- |
| SSH | 支持密码与私钥认证（可粘贴私钥或指定服务器本机的 `keyFile` 路径，支持私钥口令），可设置登录后进入的 `workDir`、`keepAlive`、连接超时（1~120 秒，默认 15）与代理 |
| Telnet | 默认端口 23，检测到 `login:`、`username:`、`password:` 等提示时各自动填充一次，可设置代理 |
| 本机 Shell | 在运行 Gately 的设备上直接打开 Shell，可指定 Shell 路径、工作目录与附加环境变量 |

每个连接可填写备注。连接列表支持拖动排序和「测试连接」：SSH 返回服务端版本与延迟，Telnet 仅验证 TCP（含代理）可达，本机 Shell 不支持测试。编辑连接时，密码、私钥、私钥口令与代理密码以脱敏形式显示，保持不变时沿用原值。

在「设置」中可维护「SSH 认证预设」（密码或私钥，可附默认用户名）。新增或编辑 SSH 连接时选择「认证预设」即可复用，同一份凭据被多个连接引用，修改预设后这些连接下次连接时自动生效；仍被连接引用的预设无法删除。

### 代理

SSH 与 Telnet 连接可单独配置出口代理，类型为 `socks5` 或 `http`，可填写代理用户名和密码。

### 主机密钥首次信任

SSH 连接首次建立时记录服务器主机指纹并信任，之后每次连接核对指纹。服务器重装或更换密钥后，在连接上执行「重置主机指纹」即可重新信任。

## 会话

- 会话持久保存在服务端，浏览器刷新或断开后可从会话列表重新附着，附着时先回放输出缓冲再实时转发；
- 同一会话允许多个客户端同时附着，输入共享、输出广播；
- 会话可添加备注，会话列表显示创建时间、最后活动时间、窗口大小与收发字节数；
- 页面刷新后，仍存活的会话自动恢复为标签页，分屏布局一并恢复；
- 终端内置搜索（输入关键字，回车查找下一个，Shift+回车查找上一个）、复制、粘贴、清屏、字号调整、全屏与多套终端配色（默认跟随界面主题，也可固定为某套配色）。

### 设置项

在页面右上角「设置」中调整：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `allowLocalShell` | 关闭 | 是否允许打开本机 Shell |
| `maxSessions` | 20 | 最大并发会话数，上限 1000，超出时新建会话返回 HTTP 429 |
| `idleTimeout` | 0 | 会话无输入输出超过该分钟数自动结束，0 表示不限 |
| `bufferSize` | 256 | 每个会话保留的回放缓冲（KB），上限 16384 |
| `heartbeatInterval` | 30 | WebSocket 心跳间隔（秒），上限 600 |
| `sessionKeepAlive` | 0 | 浏览器断开后会话继续保留的分钟数，0 表示断开即结束，上限 10080 |

::: tip
需要断线重连能力时，把 `sessionKeepAlive` 设为大于 0 的值。设为 0 时浏览器断开会立即结束会话。
:::

## SFTP 文件管理

终端工具栏的文件夹图标打开文件管理面板。SSH 连接通过 SFTP 操作远端文件，本机 Shell 连接直接操作 Gately 所在设备的文件系统；Telnet 连接不提供文件管理。本机文件管理要求已开启「允许本机 Shell」。

| 能力 | 说明 |
| --- | --- |
| 浏览 | 面包屑与上级目录导航，目录在前、按名称排序，可切换排序方式；显示权限、大小、修改时间与属主 |
| 新建 | 新建文件夹、新建空文件 |
| 上传 | 多文件上传，桌面端支持上传整个文件夹（保留子目录结构），同名文件覆盖，面板显示上传进度 |
| 下载 | 流式下载，支持断点续传（`Range`） |
| 在线编辑 | 文本文件预览与保存，文件超过 1MB 或为二进制时不可预览 |
| 重命名、复制、粘贴 | 复制到同目录时自动改名为 `name 副本.ext`、`name 副本 2.ext` |
| 删除 | 支持多选批量删除，目录递归删除，根目录受保护 |
| 压缩与解压 | 压缩为 `zip` 或 `tar.gz`；解压支持 `zip`、`tar`、`tar.gz`、`tgz`；可在解压前预览压缩包内容（最多 10000 条）；压缩解压由 Gately 自身完成，远端无需安装命令 |
| 修改权限 | 八进制权限（0 到 7777），目录可选递归 |
| 快速访问 | 为每个连接保存常用目录，一键跳转 |

解压时含 `..` 的条目整体拒绝以防目录穿越，符号链接与硬链接条目被跳过，文件权限只保留 rwx 位。移动端面板提供多选模式与操作面板。

## 快捷命令

「快捷命令」下拉菜单列出全局快捷命令，点击后发送到当前终端。每条快捷命令包含 `name`、`command` 与 `sendEnter`（发送后是否自动回车）。在下拉菜单底部的「管理快捷命令」中增删改。

## 分屏

工具栏「分屏」菜单提供左右分屏、上下分屏与网格分屏，最多同时显示 4 个窗格。进入分屏后，再打开连接会自动加入分屏，也可点击其他标签加入，窗格标题栏可将会话移出分屏。分屏布局保存在服务端，刷新页面后恢复。窄屏下自动取消分屏，已保存的布局不会删除。

## 移动端适配

- 窄屏下连接列表与终端分为两个视图，终端视图左上角返回按钮回到列表；
- 终端区域跟随可视视口，软键盘弹出时自动缩小；
- 虚拟按键栏是单行、可左右滑动，提供 `Esc`、`Tab`、`Ctrl`、`Alt`（可粘滞）、方向键（长按重复）、常用符号、快捷命令入口，右侧固定一个键盘按钮（呼出或收起键盘）。按键栏默认跟随软键盘出现和隐藏；键盘收起时右下角留一个悬浮按钮，点击即可呼出键盘。需要在不弹键盘时使用方向键、翻页等按键，可在「更多」菜单打开「始终显示按键栏」。

## 安全

终端等同于在目标主机上执行任意命令，Gately 默认采取以下限制：

- **本机 Shell 默认关闭**，需要在设置中显式开启；
- **协议确认**：首次开启本机 Shell、新建会话、附着会话或使用文件管理时，弹出用户协议，勾选同意后继续；
- **二次验证（2FA）**：在安全设置中扫码绑定 TOTP 验证器后，上述操作要求输入 6 位验证码。验证通过后当前登录令牌 30 分钟内无需重复验证；连续输错 5 次，该登录令牌锁定 1 分钟；
- 连接密码、私钥与代理密码在接口输出中脱敏。

::: warning
开启本机 Shell 前，先为管理界面启用两步验证，并搭配「仅内网访问」或 VPN 使用。
:::

# 动态域名（DDNS）

家庭宽带的公网 IP 会变化，DDNS 在 IP 变化后自动更新 DNS 解析，让域名始终指向当前地址。

## 支持的服务商

阿里云、Cloudflare、腾讯云、DNSPod、华为云、GoDaddy、Porkbun、dynv6、DuckDNS、Amazon Route 53、OVHcloud、Gandi、NS1、Bunny DNS、Namecheap、DynDNS2，以及自定义回调（用于未内置的服务商或自建接口）。

| 服务商 | 凭据 | 可用于证书 DNS 验证 |
| --- | --- | --- |
| Amazon Route 53 | Access Key ID / Secret Access Key，可选托管区域 ID | 是 |
| OVHcloud | Application Key / Secret 与 Consumer Key，接入点 ovh-eu / ovh-ca / ovh-us | 是 |
| Gandi | Personal Access Token | 是 |
| NS1 | API Key | 是 |
| Bunny DNS | Account API Key | 是 |
| Namecheap | 域名的 Dynamic DNS 密码（仅 A 记录） | 否 |
| DynDNS2 | 用户名、密码与更新地址，适用于 No-IP、Dynu 等兼容 dyndns2 协议的服务 | 否 |

## 获取 IP 的方式

- **URL**：请求公网 IP 查询地址（可自行替换为任意服务，或自建）；
- **网卡**：直接读取指定网卡的地址，适合拥有公网 IP 的设备；
- **命令**：执行命令并取其输出，适合特殊网络环境。

支持 IPv4 与 IPv6。

## 记录值变量 {#record-vars}

记录值可以使用以下变量，每轮同步时替换为当前值：

- `{ipv4Addr}`、`{ipv6Addr}`：本任务获取到的 IPv4、IPv6 地址（A、AAAA 记录留空时默认使用）；
- `{STUN_规则名_PORT}`、`{STUN_规则名_IP}`、`{STUN_规则名_ADDR}`：STUN 穿透规则当前的公网端口、IP、IP:端口，规则名中可以含下划线。例如 TXT 记录写 `port={STUN_ssh_PORT}`，A 记录写 `{STUN_ssh_IP}`。

STUN 规则的公网地址变化后，引用它的任务会立即同步，不必等到下个检查周期；规则未启用或还没有穿透成功时，该记录本轮跳过，记录状态中会显示原因。STUN 变量同样可以在本任务的 Webhook 中使用。只在 Webhook 中引用时，地址变化后也会调用一次 Webhook。规则名也可以换成规则的 key。

## 批量添加记录 {#batch}

编辑任务的「解析记录」页点「批量添加」，在文本框中每行输入一个域名：

- 可以写完整域名，也可以只写主机记录（如 `emby`），只写主机记录时挂在「默认主域名」下；
- 完整域名优先按默认主域名和已有记录的主域名拆分，其余按公共后缀推断（如 `example.com.cn`），预览中可以核对拆分结果；
- 域名后可以跟类型与记录值；不写类型时按勾选的类型（A、AAAA）各添加一条，记录值默认 `{ipv4Addr}`、`{ipv6Addr}`；只写 IP 地址时按地址推断 A 或 AAAA；
- TTL、线路与备注对本次添加的记录统一生效；空行与 `#` 开头的行忽略，误粘贴的 `https://`、端口与路径会自动去掉。

```text
www.example.com
nas.example.com
emby
v6.example.com AAAA
cdn.example.com CNAME target.example.net
_ssh.example.com TXT port={STUN_ssh_PORT}
fix.example.com 203.0.113.10
```

与已有记录重复的行会跳过；有无效行时按行号列出原因，修改后才能添加。添加的记录会出现在编辑表格中，保存任务后生效。

## 通知

IP 变化或同步失败时可调用 Webhook。回调地址直连不通时，可在 Webhook 的「代理」中选择全局更新代理或填写 `http://`、`https://`、`socks5://` 代理地址；STUN 穿透与计划任务的 HTTP 请求同样有这个选项。

## 备注 {#remark}

记录可以填写「备注」，同步时写到 DNS 服务商处，在服务商后台的解析列表中可以看到。记录备注留空时使用任务备注；两者都为空时不改动服务商处已有的备注。只修改备注也会触发一次同步。超过 100 个字符的部分不会写入（Cloudflare 免费套餐的上限）；阿里云的备注最多 50 个字符，只能含中文、英文字母、数字与 `_ - , . ，。`，空格和其他符号会换成下划线。

支持写入备注的服务商：阿里云、Cloudflare、腾讯云、DNSPod（国内站与国际站）、华为云。其他服务商的备注只保存在 Gately 中。

## 删除记录与任务 {#delete}

删除记录（列表中记录右侧的删除图标，或在编辑页移除已保存的记录后保存）和删除任务时，会弹出确认框，可以勾选「同时从 DNS 服务商删除解析」：

- 勾选后先删除服务商处的解析，全部成功才删除 Gately 中的配置；任一条失败时显示失败原因，Gately 中的配置保持不变，可以重试或取消勾选；
- 只删除由 Gately 同步的那条：同名、同类型（同线路）且值与 Gately 最近一次同步结果相同的解析；
- 以下情况不删除，并提示原因：Gately 还没有同步过这条记录（值未知）；服务商处的值与最近同步的值不一致（例如在控制台改过）；按记录集管理的服务商（华为云、Route 53、Gandi、NS1、GoDaddy）记录集里还有其他值。可以先同步一次，或到服务商控制台处理；
- 服务商处已经没有这条解析时视为成功；
- 编辑任务时删掉记录并勾选该项，保存时先校验待保存的配置，校验不通过时不删除服务商处的解析；
- DuckDNS、Namecheap、DynDNS2 与自定义回调不提供删除接口，确认框中不显示该选项，服务商处的记录需要手动删除。

勾选框的默认状态在「全局设置」中设置。

## 全局设置 {#settings}

页头的「全局设置」包含：

- **启用模块**：停用期间不检查 IP，也不更新任何解析记录；
- **删除时同时删除服务商记录**：删除记录或任务时「同时从 DNS 服务商删除解析」勾选框的默认状态，默认不勾选，每次删除时仍可修改。

## 使用建议

- 为 DNS 服务商创建仅具备解析编辑权限的子账号密钥，不要使用主账号密钥；
- 新建任务后点击「强制同步」确认记录已更新；
- 不再需要的记录可以点击列表中该记录右侧的删除图标直接移除，无需进入编辑页；任务至少保留一条记录，是否同时删除服务商处的解析见[删除记录与任务](#delete)；
- 公网 IP 查询地址不再依赖任何项目方服务，可以在任务中随时更换。

## 分组与排序

任务可以填写「分组」（最长 64 个字符）。列表按分组显示可折叠的区块：分组按首次出现的顺序排列，未分组的任务排在最后，折叠状态保存在浏览器中；页头的搜索框按任务与记录过滤：任务的名称、分组、备注或服务商匹配时显示该任务的全部记录，否则只列出域名、类型、分组、备注或当前值匹配的记录；搜索期间折叠的任务卡片与记录分组会自动展开。

点击「排序」进入排序模式：用箭头上移、下移任务或整组移动；勾选多个任务后拖动其中任一项会一起移动，拖到其他分组的任务或分组标题上即加入该分组；工具栏可以把选中的任务批量移到指定分组，留空则移出分组。顺序和分组只影响列表显示，修改后不会重启任务。

鼠标移到分组标题上，点铅笔按钮可以重命名分组：组内条目一起改为新名称，位置和顺序不变；改成已有分组的名称时，确认后两个分组合并。

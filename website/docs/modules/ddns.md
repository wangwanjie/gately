# 动态域名（DDNS）

家庭宽带的公网 IP 会变化，DDNS 在 IP 变化后自动更新 DNS 解析，让域名始终指向当前地址。

## 支持的服务商

阿里云、Cloudflare、腾讯云、DNSPod、华为云、GoDaddy、Porkbun、dynv6、DuckDNS、Amazon Route 53、OVHcloud、Gandi、NS1、Bunny DNS、Namecheap、DynDNS2，以及自定义回调（用于未内置的服务商或自建接口）。

| 服务商 | 凭据 | 可用于证书 DNS 验证 |
| --- | --- | --- |
| Amazon Route 53 | Access Key ID / Secret Access Key，可选托管区域 ID | 是 |
| OVHcloud | Application Key / Secret 与 Consumer Key，接入点 ovh-eu / ovh-ca / ovh-us | 是 |
| Gandi | Personal Access Token | 是 |
| NS1 | API Key | 是 |
| Bunny DNS | Account API Key | 是 |
| Namecheap | 域名的 Dynamic DNS 密码（仅 A 记录） | 否 |
| DynDNS2 | 用户名、密码与更新地址，适用于 No-IP、Dynu 等兼容 dyndns2 协议的服务 | 否 |

## 获取 IP 的方式

- **URL**：请求公网 IP 查询地址（可自行替换为任意服务，或自建）；
- **网卡**：直接读取指定网卡的地址，适合拥有公网 IP 的设备；
- **命令**：执行命令并取其输出，适合特殊网络环境。

支持 IPv4 与 IPv6。

## 记录值变量 {#record-vars}

记录值可以使用以下变量，每轮同步时替换为当前值：

- `{ipv4Addr}`、`{ipv6Addr}`：本任务获取到的 IPv4、IPv6 地址（A、AAAA 记录留空时默认使用）；
- `{STUN_规则名_PORT}`、`{STUN_规则名_IP}`、`{STUN_规则名_ADDR}`：STUN 穿透规则当前的公网端口、IP、IP:端口，规则名中可以含下划线。例如 TXT 记录写 `port={STUN_ssh_PORT}`，A 记录写 `{STUN_ssh_IP}`。

STUN 规则的公网地址变化后，引用它的任务会立即同步，不必等到下个检查周期；规则未启用或还没有穿透成功时，该记录本轮跳过，记录状态中会显示原因。STUN 变量同样可以在本任务的 Webhook 中使用。只在 Webhook 中引用时，地址变化后也会调用一次 Webhook。规则名也可以换成规则的 key。

## 通知

IP 变化或同步失败时可调用 Webhook。

## 使用建议

- 为 DNS 服务商创建仅具备解析编辑权限的子账号密钥，不要使用主账号密钥；
- 新建任务后点击「强制同步」确认记录已更新；
- 不再需要的记录可以点击列表中该记录右侧的删除图标直接移除，无需进入编辑页；只会从任务中移除，服务商处已有的解析保留，任务至少保留一条记录；
- 公网 IP 查询地址不再依赖任何项目方服务，可以在任务中随时更换。

## 分组与排序

任务可以填写「分组」（最长 64 个字符）。列表按分组显示可折叠的区块：分组按首次出现的顺序排列，未分组的任务排在最后，折叠状态保存在浏览器中；页头的搜索框可按名称、分组、域名或服务商过滤。

点击「排序」进入排序模式：用箭头上移、下移任务或整组移动；勾选多个任务后拖动其中任一项会一起移动，拖到其他分组的任务或分组标题上即加入该分组；工具栏可以把选中的任务批量移到指定分组，留空则移出分组。顺序和分组只影响列表显示，修改后不会重启任务。

鼠标移到分组标题上，点铅笔按钮可以重命名分组：组内条目一起改为新名称，位置和顺序不变；改成已有分组的名称时，确认后两个分组合并。

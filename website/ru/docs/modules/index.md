# Обзор модулей

Каждая возможность Gately — отдельный модуль: его можно запускать, останавливать и настраивать независимо, а конфигурация хранится в собственном JSON-файле.

Модуль целиком можно отключить в разделе «Настройки → Модули». Отключённый модуль по-прежнему загружает свою конфигурацию, но не запускает служб, не обслуживает API управления (его конечные точки возвращают 403) и скрыт в интерфейсе; конфигурация сохраняется и снова начинает действовать после повторного включения. Модули, от которых зависят другие, отключить нельзя; изменения вступают в силу после перезапуска.

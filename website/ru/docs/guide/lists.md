# Группы, порядок, пакетные операции и дублирование в списках

Списки с большим числом элементов можно группировать, вручную упорядочивать, искать по ним и изменять пакетно; управление одинаково на всех страницах. Порядок и группы влияют только на отображение в интерфейсе управления; их изменение не перезапускает работающие экземпляры и не разрывает соединения.

Большинство этих списков поддерживают виды «Карточки» и «Компактный вид», которые переключаются в правом верхнем углу списка; на узких экранах всегда используются карточки.

## Группы

Заполните поле «Группа» в диалоге редактирования (до 64 символов; можно выбрать существующую группу). Пустое поле означает отсутствие группы. Как только у одного элемента появляется группа, список отображается сворачиваемыми блоками по группам: группы идут в порядке первого появления, элементы без группы располагаются в конце, а состояние свёрнутости каждой группы сохраняется в браузере. Поле поиска фильтрует элементы по имени, группе, примечанию и похожим полям и во время поиска разворачивает все группы.

Наведите указатель на заголовок группы и нажмите кнопку с карандашом, чтобы переименовать группу: все её элементы получают новое имя и сохраняют своё положение и порядок. Если указать имя существующей группы, после подтверждения две группы объединятся.

## Режим сортировки

Нажмите «Сортировка и пакет», чтобы перейти в режим сортировки. В нём показываются все элементы, а поиск и фильтры временно отключены:

- стрелками перемещайте элементы вверх и вниз внутри группы, а стрелками на заголовке группы — всю группу;
- на компьютере элементы можно перетаскивать; если отпустить элемент на элемент или заголовок другой группы, он попадёт в эту группу;
- отметьте несколько элементов (флажок на заголовке группы выбирает всю группу) и перетащите любой из них — все выбранные элементы переместятся вместе в текущем порядке;
- кнопка «Переместить в группу» на панели инструментов переносит выбранные элементы в указанную группу за один шаг; пустое значение убирает их из группы.

На телефонах и других узких экранах перетаскивание недоступно; те же действия выполняются стрелками и панелью инструментов.

## Пакетные операции

Если отметить элементы в режиме сортировки, панель инструментов позволяет также:

- **Включить / Отключить**: сохраняет все отмеченные элементы за один раз; элементы, уже находящиеся в нужном состоянии, не перезапускаются;
- **Удалить**: диалог подтверждения перечисляет удаляемые элементы, удаление необратимо. Если хотя бы один элемент удалить нельзя (например, сертификат ещё используется сайтом), не удаляется ни один, и показывается причина.

Пакетная операция обрабатывает до 500 элементов. Изменения сохраняются, только если все элементы прошли проверку; если хотя бы один не прошёл, ничего не меняется. У устройств Wake-on-LAN нет переключателя включения, для них доступно только пакетное удаление; для API-токенов пакетное включение, отключение и удаление пока недоступны. В веб-службах есть также пакетное изменение доменов и опций, см. [Веб-службы](/ru/docs/modules/web#пакетные-операции). Сайты также можно переносить в другой слушатель, см. [Перенос сайтов](/ru/docs/modules/web#move-sites).

## Дублирование элементов

Все элементы из таблицы выше, кроме токенов API, можно дублировать; так же дублируются подписные списки IP, места хранения резервных копий, шаблоны учётных данных веб-терминала, записи внутри задачи DDNS и сайты внутри слушателя веб-сервиса. Нажмите «Дублировать» у элемента — откроется диалог добавления с этим элементом в качестве шаблона, к имени добавится «(копия)». Измените настройки, которые должны отличаться, и сохраните — будет добавлен новый элемент. Исходный элемент не меняется, копия располагается сразу после него.

- **Секреты берутся из исходного элемента**: сохранённые пароли, токены и закрытые ключи в диалоге остаются скрытыми. Если их не менять, копия использует значения исходного элемента, и открытый текст не проходит через браузер. Кнопка с глазом показывает открытый текст исходного элемента. Для подключений и шаблонов учётных данных веб-терминала перед повторным использованием секретов нужно принять пользовательское соглашение и пройти двухфакторную проверку.
- **Содержимое, которое ведёт система, не копируется**: сертификаты, полученные через ACME или прочитанные из файлов, выпускаются или читаются заново по настройкам копии; загруженный сертификат копируется вместе с закрытым ключом. Журналы развёртывания сертификатов очищаются, подписные списки IP скачиваются заново, а ссылки для общего доступа сайтов не копируются, так как их токены обходят аутентификацию.
- **Цели развёртывания сертификата** в копии отключены, чтобы она не записывала в те же файлы, что и исходный сертификат. Включите их, убедившись, что имена файлов не совпадают.
- **Веб-сервис**: при дублировании сайта его можно поместить под другой слушатель (например, из HTTP-слушателя в HTTPS-слушатель). При дублировании слушателя можно выбрать, копировать ли его сайты.
- Копия сохраняет состояние включения исходного элемента. Перед сохранением измените порты, домены, записи и другие настройки, которые должны отличаться, чтобы копия не конфликтовала с исходным элементом.

## Особенности отдельных страниц

- **Динамический DNS**: «Порядок записей» на карточке задачи открывает диалог, где настраиваются порядок и группы DNS-записей этой задачи. Сохранение применяется сразу и не запускает повторную синхронизацию. При редактировании задачи тот же диалог доступен на вкладке «DNS-записи» и сохраняется вместе с задачей. Если у записей есть группы, на карточке они показываются по группам, и каждую группу можно свернуть отдельно.
- **frp**: список прокси можно фильтровать по экземпляру frpc; в режиме сортировки показываются все прокси и настраивается полный порядок.
- **API-токены**: пока порядок не изменён вручную, токены показываются по времени создания, от новых к старым. После изменения порядка они показываются в сохранённом порядке, а новые токены добавляются в начало.
- **Пользователи входа**: «Сайты с общими пользователями» показываются по слушателям, а сайты внутри слушателя дополнительно сгруппированы по группам из веб-служб. Слушатели и группы сворачиваются по отдельности, а панель инструментов позволяет свернуть или развернуть всё одним нажатием.

## API

Все общие эндпоинты списков предоставляют `PUT <путь списка>-order` (тело `{"keys": [...]}`, должно содержать все элементы) для изменения порядка и `PUT <путь списка>-group` (тело `{"keys": [...], "group": "..."}`) для массовой установки группы, `PUT <путь списка>-enable` (тело `{"keys": [...], "enable": true}`) для пакетного включения и отключения и `POST <путь списка>-delete` (тело `{"keys": [...]}`) для пакетного удаления, например `PUT /api/stun/rules-group` и `POST /api/portforward/rules-delete`. Записи внутри задачи DDNS используют `PUT /api/ddns/tasks/{key}/records-layout`, API-токены — `PUT /api/tokens/order` и `PUT /api/tokens/group`. Подробнее см. [Справочник API](/ru/docs/reference/api-reference).

Для дублирования используется `POST <путь списка>/{key}/copy`. Тело запроса — новый элемент; секреты, оставшиеся заполнителем `********`, берут значения элемента `{key}`, например `POST /api/frp/clients/{key}/copy`.

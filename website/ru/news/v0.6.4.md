# Вышел Gately v0.6.4

3 ноября 2026 г.

[Скачать v0.6.4](/ru/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.4) · [Пользовательская сборка онлайн](https://build.gately.cn)

## Пользовательская сборка

Кроме трёх основных модулей (Проброс портов, Веб-службы и SSL-сертификаты), остальные 22 модуля можно исключить при компиляции, а языки интерфейса — ограничить упрощённым китайским или упрощённым китайским, традиционным китайским и английским:

- Откройте [build.gately.cn](https://build.gately.cn) и отметьте модули и языки (или начните с предустановок «Core only», «Router» или «NAS»); страница сразу оценивает размер и онлайн собирает двоичные файлы для Linux / Windows / macOS / FreeBSD, пакеты для OpenWrt и fnOS или мультиархитектурный Docker-образ для amd64, arm64 и arm/v7; результаты с теми же параметрами используются повторно без новой сборки;
- Например, для linux/arm64: полная версия занимает 33,6 МБ, только ядро — около 19,9 МБ, предустановка Router с упрощённым китайским — около 21,2 МБ; Docker-образ предустановки Router с упрощённым китайским скачивается примерно на 18,7 МБ (полный образ — 51,9 МБ), а образ без управления Docker не содержит docker-cli и compose, а образ без защиты от вторжений и STUN — nftables;
- Для модулей, не включённых в сборку, файлы конфигурации остаются нетронутыми, их переключатели в настройках и права API-токенов продолжают действовать, их API отвечают 404 с пояснением, что модуль не входит в эту сборку, а интерфейс скрывает их страницы и параметры; при возврате к полной версии всё восстанавливается;
- Страница «О программе» показывает модули, исключённые из этой сборки, и ссылку, открывающую сборщик с теми же параметрами. В пользовательских сборках нет онлайн-обновления (оно скачивает полную версию); после выхода новой версии соберите её заново с теми же параметрами и воспользуйтесь «Загрузить пакет обновления»;
- При самостоятельной компиляции используйте build tag `no_<модуль>` и `lang_zh` / `lang_cjken`, `GATELY_LOCALES` для фронтенда или аргументы сборки Dockerfile, например `GATELY_TAGS`; `tools/custombuild` переводит выбор в эти параметры.

Подробнее: [Обзор модулей · Пользовательская сборка](/ru/docs/modules/#custom-build) и [Сборка из исходного кода](/ru/download#custom-build).

## Скрытие порта администрирования

В «Настройки → Контроль доступа» появился «Ответ на неавторизованный доступ». Он действует для заблокированных источников, для доступа из интернета при включённом доступе только из локальной сети и для запросов, не прошедших через защищённый путь входа:

- Можно выбрать страницу-подсказку по умолчанию, обычную страницу 404, пустую страницу, закрытие соединения, отсутствие ответа до тайм-аута или свою HTML-страницу (с заданным кодом состояния);
- Закрытие соединения и отсутствие ответа определяются по источнику при установке соединения, поэтому HTTPS не отправляет сертификат; запросы, пересланные доверенным прокси, автоматически получают обычную страницу 404, чтобы фронтальный прокси не показывал свою страницу ошибки; удерживаемые соединения ограничены по времени и количеству;
- В режимах скрытия ответы больше не содержат заголовков безопасности, характерных для консоли администрирования, а свои страницы отображаются в песочнице, запрещающей скрипты и внешние ресурсы.

Сам порт по-прежнему обнаруживается сканированием; для полного скрытия нужен межсетевой экран. Подробнее: [Рекомендации по защите](/ru/docs/guide/hardening).

## Страницы ошибок сайтов

- На вкладке «Страницы ошибок» сайта Веб-служб для страниц 404 и 5xx, которые генерирует Gately, можно выбрать стиль по умолчанию, один из 10 встроенных стилей (Минимализм, Терминал, Неон, Звёздное небо, Газета, Брутализм, Аврора, Пиксели, Чертёж, Цепочка статуса) или свою страницу из библиотеки страниц; у каждого стиля есть миниатюра и предпросмотр для компьютера и телефона;
- В библиотеку страниц можно загрузить или вставить HTML либо сослаться на файл `.html` на сервере; при сохранении скрипты, атрибуты событий, формы и подобное содержимое проверяются и удаляются, поддерживаются подстановки `{code}`, `{title}`, `{host}`, `{path}` и другие, а страницы отдаются с CSP, запрещающей скрипты и внешние ресурсы;
- Сайты обратного прокси могут перехватывать заданные коды состояния бэкенда (например, `404, 500-599`) и заменять только запросы браузеров, открывающих страницу, оставляя API-запросы без изменений;
- Настройки сайта по умолчанию применяются и к запросам, не совпавшим ни с одним сайтом, а в «Сортировка и пакет» можно задать стиль страниц ошибок сразу для многих сайтов.

Подробнее: [Веб-службы · Страницы ошибок](/ru/docs/modules/web#error-pages).

## Другие улучшения

- Поиск в Динамическом DNS фильтрует по записям: если совпадают имя, группа, примечание или провайдер задачи, показываются все её записи, иначе — только совпавшие, а свёрнутые задачи и группы на время поиска разворачиваются; поиск в Веб-службах автоматически разворачивает свёрнутые слушатели;
- Длинные подписи на странице настроек переносятся автоматически и больше не наезжают на поля ввода в немецком, русском и других языках;
- Если запрос консоли получает ответ не в формате JSON (например, после истечения сессии его заблокировал защищённый путь входа), консоль предлагает обновить страницу или заново открыть защищённый путь входа;
- «Обновить» на странице ошибки по умолчанию теперь обычная ссылка и работает и при CSP, запрещающей скрипты;
- Диагностические пакеты, `GET /api/status` и `GET /api/system/info` содержат сведения о сборке (пользовательская ли она, какие модули и языки включены);
- CI проверяет комбинации build tag для предустановок.

## Об обновлении

- Docker: скачайте новый образ и пересоздайте контейнер; если смонтирован сокет Docker, Gately может обновить и сам себя на странице Docker. OpenWrt: установите новый `.apk` / `.ipk` поверх старого. fnOS: вручную установите новый `.fpk` в Центре приложений. Остальные варианты развёртывания можно обновить онлайн на странице «О программе».
- Пользователям полной версии ничего делать не нужно; формат конфигурации не изменился.

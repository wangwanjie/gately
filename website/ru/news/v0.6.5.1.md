# Вышел Gately v0.6.5.1

7 ноября 2026 г.

[Скачать v0.6.5.1](/ru/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.1)

## Автозапуск: gately service

При установке из бинарного файла Gately можно сразу зарегистрировать как системную службу: `sudo ./gately service install` (в Windows — `.\gately.exe service install` в терминале администратора). В Linux регистрируется юнит systemd, в macOS — демон launchd (`-user` регистрирует объект входа без sudo), в Windows — системная служба; Gately сразу запускается и перезапускается после сбоя. Далее управляйте ею командами `gately service uninstall|start|stop|restart|status`; при удалении каталог конфигурации сохраняется.

- В Windows каталог конфигурации по умолчанию `%ProgramData%\Gately` доступен только SYSTEM и администраторам;
- при установке выводится предупреждение, если бинарный файл или каталог конфигурации может изменить пользователь, отличный от root, например файл всё ещё лежит в «Загрузках».

См. [Автозапуск](/ru/docs/guide/install#service).

## Постраничные длинные списки

Список блокировок защиты от вторжений, блокировки панели в глобальных настройках веб-сервисов, списки файлов точек монтирования хранилища и контейнеров Docker и файловый менеджер SFTP веб-терминала теперь показываются постранично: 20 / 50 / 100 / 200 строк на странице, отдельно для каждого списка. Страница с 4000 блокировок отрисовывается за 0,23 с вместо примерно 2,6 с; поиск фильтрует до разбиения на страницы, а периодическое обновление и разблокировка сохраняют текущую страницу. Флажок в заголовке SFTP действует только на текущую страницу, чтобы случайно не удалить невидимые файлы.

## Пакетное добавление записей DDNS

На вкладке «Записи» редактора задачи появилось **Пакетное добавление**: по одному домену в строке, полностью или только хост, при желании с типом и значением (например, `cdn.example.com CNAME target.example.net`). Перед добавлением показываются добавляемые записи, пропущенные дубликаты и неверные строки, которые нужно сначала исправить; интернационализированные доменные имена преобразуются в punycode. См. [Пакетное добавление записей](/ru/docs/modules/ddns#batch).

## crash.log

Gately записывает сбои среды выполнения Go (panic, fatal error) со стеками в `crash.log` в каталоге конфигурации, а при принудительном завершении процесса (например, OOM killer) — время, когда процесс последний раз был жив. При следующем запуске об этом сообщается в системном журнале, а диагностический пакет включает файл в обезличенном виде. Это помогает в Docker, LXC и fnOS, где стандартный вывод ошибок после перезапуска пропадает. См. [Диагностический пакет](/ru/docs/reference/diagnostics).

## Прочие улучшения

- Бинарные файлы для macOS подписаны сертификатом Developer ID и заверены Apple, поэтому запускаются сразу после загрузки; см. [Проверка артефактов выпуска](/ru/docs/guide/verify).
- Шаблон запроса функции требует указать версию, систему и архитектуру.

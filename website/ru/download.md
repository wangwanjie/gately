# Скачать Gately

## Образ Docker (рекомендуется)

Образ опубликован для amd64, arm64 и arm/v7:

```bash
docker pull ghcr.io/wangwanjie/gately:latest
```

Тот же образ (с теми же тегами) есть и в Docker Hub:

```bash
docker pull vanjayak/gately:latest
```

Все варианты развёртывания описаны в разделе [Установка](/ru/docs/guide/install).

## Бинарные файлы

Скачайте архив для своей платформы, распакуйте его и запустите `./gately -c /etc/gately`. Поддерживаемые платформы: Linux (amd64 / arm64 / arm / mips / mipsle / riscv64), macOS, Windows и FreeBSD.

## Нативное приложение для fnOS {#fnos}

Пользователи fnOS могут сразу установить нативное приложение: скачайте `.fpk` из группы fnOS в списке выше (`x86` для Intel / AMD, `arm` для устройств ARM) и выберите его в fnOS в разделе «Центр приложений → Ручная установка».

- Работает с единым шлюзом fnOS: открывается значком на рабочем столе, в том числе через удалённый домен fnOS, без открытия дополнительных портов;
- Вход администраторов fnOS по их сеансу fnOS: после включения администраторы, уже вошедшие в fnOS, не вводят пароль Gately и код двухэтапной проверки.

Подробнее — [Установка · Нативное приложение для fnOS](/ru/docs/guide/install#fnos).

## Пакеты для OpenWrt {#openwrt}

Пользователи OpenWrt могут скачать пакет из группы OpenWrt в списке выше: для OpenWrt 24.10 и более ранних версий (включая iStoreOS) выберите `.ipk` и установите его командой `opkg install`, для OpenWrt 25.12 и новее — `.apk` и установите его командой `apk add --allow-untrusted`. Архитектуру выбирайте по `DISTRIB_ARCH` в `/etc/openwrt_release`. Служба запускается сразу после установки и хранит конфигурацию в `/etc/gately`.

`luci-app-gately_<версия>_openwrt_all` в той же группе — приложение LuCI. Оно не зависит от архитектуры; установите его после Gately, чтобы управлять службой в LuCI на странице **Службы → Gately**.

Подробнее — [Установка · OpenWrt](/ru/docs/guide/install#openwrt).

## Сборка из исходного кода

Требуются Go 1.26+, Node.js 24+ и pnpm:

```bash
git clone https://github.com/wangwanjie/gately.git
cd gately
make web      # сборка фронтенда
make build    # результат: bin/gately
```

### Пользовательская сборка {#custom-build}

Необязательные модули и языки интерфейса можно исключить при компиляции (подробности — [Обзор модулей · Пользовательская сборка](/ru/docs/modules/#custom-build)). Проще всего отметить нужное на [build.gately.cn](https://build.gately.cn) и собрать онлайн. При самостоятельной сборке:

- в Go модули и языки исключаются build-тегами: каждому необязательному модулю соответствует `no_<модуль>` (например, `no_waf`, `no_smb`), уровни языков — `lang_zh` (только упрощённый китайский) или `lang_cjken` (упрощённый и традиционный китайский, английский); без тегов собирается полная версия;
- фронтенд с переменной окружения `GATELY_LOCALES` включает только выбранные языки (например, `zh-CN,zh-TW,en`), пустое значение — все;
- `modules.json` в корне репозитория перечисляет все необязательные модули, зависимости и оценку размера; `go run ./tools/custombuild resolve` переводит выбор в теги, языки и аргументы сборки Docker, а подкоманда `build` сразу создаёт tar.gz или пакет fnOS.

```bash
# Оставить только DDNS и frp, интерфейс только на упрощённом китайском
go run ./tools/custombuild resolve -modules ddns,frp -lang zh
go run ./tools/custombuild build -version v0.6.4 -modules ddns,frp -lang zh -targets linux-arm64 -out dist
```

Образ Docker собирается тем же Dockerfile: аргументы сборки `GATELY_TAGS` и `GATELY_LOCALES` соответствуют тегам и языкам выше, `WITH_DOCKER_CLI=0` не устанавливает docker-cli и compose (если модуль Docker не включён), `WITH_NFTABLES=0` не устанавливает nftables (если не включены защита от вторжений и STUN); `resolve -targets docker` выводит соответствующие аргументы.

## Проверка

Каждый релиз содержит файл с контрольными суммами. После загрузки и перед запуском проверьте SHA-256.

Начиная с v0.5.0 файл контрольных сумм и образы Docker подписаны cosign без ключей, к архивам прилагается аттестация происхождения сборки и публикуется SBOM. Подробнее — [Проверка релизов](/ru/docs/guide/verify) (на английском).

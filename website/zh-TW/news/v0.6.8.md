# Gately v0.6.8 發佈

2026 年 11 月 17 日

[下載 v0.6.8](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8)

## 安全修復

本版本修復了以下影響 v0.6.6.6 及更早版本的安全問題，建議盡快升級。

- **寫入權杖可讀取設定目錄（高）**：`storage:write`、`webservice:write` 等權杖可把設定目錄掛為儲存或靜態站點後讀取 `account.json` 並偽造管理員工作階段。現在儲存掛載、靜態站點與 WebDAV/FTP/SMB 拒絕設定目錄及其子目錄；包含設定目錄的目錄照常分享，但設定目錄會被隱藏。EasyTier/Tailscale/NetBird 程式路徑與備份口令改為僅登入工作階段可修改，權杖編輯器會標出可讀寫伺服器檔案的模組。
- **站點第三方登入回跳位址可被 Host 操縱（高）**：萬用字元或預設站點的第三方登入可把登入票據送到攻擊者網域。現在只從指向本實例的位址發起。
- **SMB 認證前解析在 32 位元建置上可單封包崩潰（高）**：偏移與長度改為 64 位元判斷，單一連線 panic 只中斷該連線；未登入連線增加逾時、請求大小與連線數上限。
- **其他（中/低）**：飛牛閘道模式下同主機其他連接埠頁面可借管理員 Cookie 發送請求；管理端 Cookie 會轉發給同主機名站點；唯讀帳號可見部分憑證；WebDAV/FTP 跟隨指向分享範圍外的符號連結；誘餌連接埠/掃描偵測依可偽造的單一 SYN 封鎖；Webhook/PushPlus 拼入未跳脫的訪客文字；站點使用者密碼以明文儲存（改為 bcrypt）；管理介面加入 CSP，HTTPS 下 Cookie 帶 Secure；跨來源只接受站點自身網域；Passkey 登入挑戰依來源限制；診斷包去識別化補全。
- **發佈簽章**：`checksums.txt` 起以 minisign 簽章（`checksums.txt.minisig`），線上升級先驗簽再核對 SHA-256；v0.6.8 及之後缺少簽章檔的版本拒絕線上升級。

## 管理介面

- **導覽精簡**：相關頁面合併為帶分頁籤的頁面，側邊欄由 39 項減為 27 項，舊網址自動跳轉；手機抽屜分組可摺疊。
- **全域搜尋**：Ctrl/⌘+K 搜尋頁面、分頁籤、站點網域、連接埠轉發規則、DDNS 記錄與憑證。
- **首次使用**：全新安裝改密後選擇使用情境（發佈網站、連接埠轉發/打洞、動態網域、組網、檔案分享、VPS 入口或全部），依情境開啟模組；總覽頂部的「開始使用」清單依實際設定打勾。
- **快速建站精靈**：三步發佈一個站點：網域、後端位址（附連通性測試與 Home Assistant、Jellyfin、Emby、Vaultwarden、Nextcloud、Immich、Proxmox VE、群暉、飛牛等範本）、HTTP 或 HTTPS（就地申請憑證）。
- **空列表範本**：連接埠轉發與 DDNS 的空列表提供常見情境範本。
- **其他**：HTTPS 站點列顯示所符合憑證的剩餘天數；表單儲存前檢查必填項；列表載入失敗時顯示原因與重試；手機端按鈕與頂欄改進，頂欄顯示目前頁面名稱；頁面標題連結到官網文件；狀態色對比度與無障礙改進。

## 匯入

- **Nginx Proxy Manager**：nginx 匯入直接支援 NPM 設定，`set` 變數代入 `proxy_pass` 與跳轉目標，Force SSL、Cache Assets 等對應為 Gately 設定。
- **Sun-Panel**：導覽面板可匯入 Sun-Panel 1.x（.sun-panel.json）與 2.x（.zip）匯出檔，建立新面板或合併到既有面板。

## 導覽面板

- **版面**：每個面板可選卡片或桌面應用程式圖示兩種連結樣式，可調圖示大小、每行數量（寬螢幕與手機分別設定）、間距與內容寬度，訪客可切換樣式。
- **位址選擇器**：帶其他存取方式的連結點擊後彈出位址選擇（桌面為浮層、手機為底部彈層，支援鍵盤），不可用位址以刪除線顯示。
- **開關**：分組數量與多位址角標（預設關閉）；「登入以檢視更多連結」只在頁面原本為空時顯示。

## 入侵防護與存取控制

- 誘餌連接埠與掃描偵測只對完成 TCP 握手的來源計數封鎖，不再因偽造來源位址的 SYN 誤封。
- 管理員登入成功後的免封只涵蓋誘餌連接埠與連接埠掃描；日誌規則、路徑探測、TLS、敲門與檔案服務封鎖照常生效。
- WebDAV/FTP/SMB 登入失敗會發佈 `fileauth.failed` 事件，附規則範本。
- 封鎖表上限 32768 筆，滿時先淘汰過期與最早的臨時自動封鎖，永久與手動封鎖不淘汰。

## 連接埠轉發與協定分流

- 每個 TCP 連接埠限制單一來源（IPv4 或 IPv6 /64）的並行連線，預設為連接埠上限的一半，可依規則與全域設定調整；本機迴路與內網來源不受限。
- 雙方在首包逾時（預設 60 秒）內都不傳送資料的 TCP 連線會被關閉。
- 目標位址寫成 host:port 時介面即時提示。

## frp、DNS 與 WAF

- frps 可監聽 KCP 與 QUIC（UDP 連接埠），frpc/frps 可調 QUIC 參數，frps 可自動放行防火牆。
- 自訂 DNS：首選伺服器 1 秒內無結果或失敗時並行查詢下一台，取最先回傳的結果。
- 動態網域：主機記錄統一小寫，Porkbun 找不到記錄時回退為列出整個網域（#99）；A/AAAA 依位址比較，展開寫法的 IPv6 不再被視為變更。
- WAF：正規表示式預過濾預設開啟（可關閉）。

## 日誌與效能

- 新增日誌等級設定（預設 info，可用 `GATELY_LOG_LEVEL`），連接埠轉發與協定分流的逐連線記錄預設不再寫入。
- 日誌與翻譯、反向代理、封鎖表、DNS 查詢、連接埠轉發等熱路徑減少配置與鎖競爭；管理介面按需載入元件與語言包，首屏更小。

## 其他

- 示範模式：`-demo` / `GATELY_DEMO=1` 啟動唯讀公開實例，一鍵唯讀登入，資料每小時重置（`deploy/demo`）。
- 使用問題請先到 GitHub Discussions 的 Q&A，Telegram 群組用於即時交流。

## 升級提示

- Docker 拉取新映像後重建容器；OpenWrt 覆蓋安裝新的 `.apk` / `.ipk`；飛牛在應用中心手動安裝新版 `.fpk`；其他部署方式可在「系統設定」中線上升級。
- 站點使用者密碼改為 bcrypt 雜湊儲存，介面只回傳遮罩；舊版本儲存的明文照常可用，在所屬監聽下次儲存時轉換。
- 日誌等級預設為 info：需要連接埠轉發逐連線記錄時，在設定中改為 debug。
- 指向設定目錄本身或其子目錄的儲存掛載、靜態站點與檔案服務目錄升級後不再提供服務，日誌中會列出。

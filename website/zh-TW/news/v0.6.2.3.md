# Gately v0.6.2.3 發布

2026 年 11 月 2 日

這是 v0.6.2 系列的改進更新，設定格式沒有變動。

[下載 v0.6.2.3](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.3)

## 網路拓撲獨立頁面

拓撲從 Web 服務頁的「拓撲」分頁移到側邊欄「Web」下的「網路拓撲」頁面，Web 服務頁頂部的按鈕可直達；統計與連線視窗在拓撲頁直接開啟，「編輯」會跳到 Web 服務頁並開啟對應站點的編輯框。畫布跟隨目前外觀的淺色或深色。

## 七種版面

版面選單提供樹狀、直向、放射、桑基、旭日、矩形樹圖與氣泡圖，每項附圖示與一句說明，切換時漸變並記住選擇。每個監聽預設顯示前 8 個站點，每個站點顯示前 6 個後端，其餘合併為彙總節點，彙總其流量與處理中請求，點擊就地展開；在沒有摺疊按鈕的版面中可從詳情面板摺疊監聽。

## 縮放、全螢幕與畫布高度

畫布可拖曳平移；滾輪捲動頁面，按住 Ctrl / ⌘ 捲動、觸控板捏合或雙指捏合可在 15% 到 250% 之間縮放；右下角的控制項提供縮小、顯示比例（點擊回到 100%）、放大、適合畫布與視窗內全螢幕，全螢幕按 Esc 離開。畫布下方的拖曳列可調整高度並依裝置記住，雙擊或選擇自動高度即可還原。

## 依分類遮罩

遮罩可選擇類別：訪客 IP、後端位址、監聽位址與網域，前三項預設選取，截圖與直播時依需求遮擋。

## 截圖與示範影片

官網首頁與 10 種語言的 README 使用對應語言的介面截圖，新增拓撲動圖，README 頂部附帶 2 分鐘無聲功能巡覽影片。

## 其他

- 移除列表與拓撲檢視切換後殘留的無用註解。

## 升級提示

- Docker 拉取新映像後重建容器；OpenWrt 覆蓋安裝新的 `.apk` / `.ipk`；飛牛在應用中心手動安裝新版 `.fpk`；其他部署方式可在「系統設定」中線上升級。

# Gately v0.6.8.4 發佈

2026 年 11 月 19 日

[下載 v0.6.8.4](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.4)

## 安全修復

- **通知管道金鑰可能出現在投遞錯誤中（低）**：Telegram Bot Token、Bark 裝置 Key、Server酱 SendKey 等放在請求位址中，連線失敗時錯誤訊息會帶出完整位址，寫入通知模組日誌和「最近投遞」記錄，唯讀帳號與只有通知讀取權限的 API 權杖也能看到。現在錯誤訊息中的管道金鑰替換為 `***`。v0.6.8.2 及更早版本受影響；「最近投遞」只儲存在記憶體中，升級重啟後即清除；執行日誌中可能留有舊記錄，曾經推送失敗過的管道建議更換金鑰（GHSA-p368-wcp9-rv4q）。

## 修改設定不再把自己關在門外

- **儲存後確認，逾時自動回滾**：在管理後台儲存連接埠轉發、協定分流、Web 服務或全域設定後，頁面會用一條新連線確認後台仍能存取；確認不了（例如改錯了管理後台所經過的監聽連接埠），預設 90 秒後自動恢復修改前的設定。確認失敗時彈出倒數計時，可立即回滾；重啟 3 次都沒確認也會回滾。「系統設定 › 存取控制」可關閉此功能或調整等待秒數（30–600）。回滾會發出「設定變更」通知。
- **儲存前提醒存取路徑**：後台會追溯你目前這次存取經過了哪些連接埠轉發、協定分流和 Web 站台，儲存的修改會影響這條路徑時（改連接埠、停用、刪除、換到本機無法監聽的位址等）先說明原因並醒目標示受影響的一跳。「系統設定 › 存取控制」可查看目前存取路徑。
- **批次修改一起生效**：需要同時改好幾處才能通的情況（例如先改協定分流再改 Web 監聽），可以「暫存，稍後一起生效」，頂部橫幅列出暫存的規則與監聽，「全部生效」後整批確認、整批回滾，也可「放棄修改」。全部生效前會先列出無法啟動的監聽。
- **指令列回滾**：`gately rollback` 列出待確認的修改和最近 15 次設定儲存，可依編號撤銷，或用 `-last`、`-pending`、`-config` 搭配 `-version`。Gately 執行中會在 2 秒內恢復並重啟；未執行時直接改寫設定檔。
- 刪除設定檔前會先存一份到設定歷史，刪除也能從設定歷史中撤銷。

## 通知：失敗重試與補推

- 推送失敗後按 10、30、60 秒重試（預設 3 次，可設 0–10）；仍失敗的訊息進入補推佇列，管道恢復後按時間順序補發，重啟後繼續（預設保留 24 小時，可設 0–168，0 為關閉；每個管道最多 100 則）。
- 管道已有待補推的訊息時，新訊息只嘗試一次，失敗後排在積壓之後，不再逐則等待重試。
- 「最近投遞」顯示「待補推」「已補推」與嘗試次數，上方橫幅按管道統計待補推數量並可清空。

## 憑證：使用飛牛系統憑證（#105）

- 憑證來源新增「飛牛系統憑證」：從飛牛已管理的憑證中選一個網域，Gately 每 30 分鐘跟隨飛牛的續期讀取最新憑證（有完整憑證鏈時使用完整鏈），變化後自動載入並部署。
- 憑證在飛牛「設定 → 安全性 → 憑證」中管理。飛牛原生應用（fpk）可直接讀取；Docker 部署需把 `/usr/trim/etc/network_cert_all.conf` 與 `/usr/trim/var/trim_connect/ssls` 按原路徑唯讀掛載進容器，容器以 root 執行（官方映像預設如此）。詳見 [SSL 憑證](/zh-TW/docs/modules/ssl)。

## 儲存佔用

- 「系統設定 › 網路與執行」新增儲存佔用卡片：設定目錄所在分割區容量、設定目錄總大小，以及執行日誌、訪客稽核、設定歷史、備份、憑證、託管程式、通知補推佇列、File Browser 資料等各類用途的佔用和對應路徑。

## 修復

- **入侵防護**：管理後台連接埠在模組啟動前就登記為開放連接埠；此前誘餌連接埠範圍包含管理連接埠時，Gately 自己的誘餌監聽會先佔住它，導致管理後台監聽失敗、每次重啟都退出。啟動各模組期間不再設定誘餌連接埠；frps、EasyTier、FTP 被動連接埠等模組登記的連接埠即使暫未監聽也不作誘餌；誘餌連接埠隨連接埠變化重新計算；申請憑證時的臨時 HTTP-01 監聽不會被誘餌連接埠攔下。
- **Web 服務**：站台後端是本實例另一個 Web 監聽（如 443 站台 → 本機 444 監聽 → 管理後台）時，管理後台登入 Cookie 原樣轉發，不再登入後立即 401。

## 升級提示

- Docker 拉取新映像後重建容器；OpenWrt 覆蓋安裝新的 `.apk` / `.ipk`；飛牛在應用中心手動安裝新版 `.fpk`；其他部署方式可在「系統設定」中線上升級。
- 儲存後確認預設開啟。用腳本或 API 權杖儲存設定不受影響，只有管理後台工作階段帶確認請求標頭的儲存才需要確認。

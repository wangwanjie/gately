# Gately v0.6.4 發布

2026 年 11 月 3 日

[下載 v0.6.4](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.4) · [線上自訂建置](https://build.gately.cn)

## 自訂建置

除連接埠轉發、Web 服務與 SSL 憑證三個核心模組外，其餘 22 個模組都可以在編譯時去掉，介面語言也可以只保留簡體中文，或簡體中文、繁體中文與英語三種：

- 開啟 [build.gately.cn](https://build.gately.cn)，勾選模組與語言（也可以從「僅核心」「路由器」「NAS」預設開始），頁面即時估算大小，線上產生 Linux / Windows / macOS / FreeBSD 二進位檔、OpenWrt 與飛牛安裝包，或 amd64、arm64、arm/v7 多架構 Docker 映像；相同選項的產物會重複使用，不必重複建置；
- 以 linux/arm64 為例：完整版 33.6 MB，只留核心約 19.9 MB，路由器預設加簡體中文約 21.2 MB；路由器預設加簡體中文的 Docker 映像拉取約 18.7 MB（完整映像 51.9 MB），未包含 Docker 管理與入侵防護時映像也不再帶 docker-cli、compose 與 nftables；
- 沒有編譯進來的模組，設定檔原樣保留，設定中的開關與 API 權杖權限照常有效，API 回傳 404 並說明未包含在此建置中，介面隱藏對應頁面與選項，換回完整版後恢復；
- 「關於」頁列出本建置去掉的模組，並附上用相同選項開啟建置器的連結。自訂建置不提供線上升級（線上升級下載的是完整版本），新版本發布後用相同選項重新產生，再上傳升級包；
- 自行編譯時用 `no_<模組>` 與 `lang_zh` / `lang_cjken` build tag、前端的 `GATELY_LOCALES`，或 Dockerfile 的 `GATELY_TAGS` 等建置參數，`tools/custombuild` 可把選擇換算成這些參數。

詳見 [模組總覽 · 自訂建置](/zh-TW/docs/modules/#custom-build) 與 [從原始碼建置](/zh-TW/download#custom-build)。

## 隱藏管理連接埠

「設定 → 存取控制」新增「未授權存取回應」，作用於被封鎖的來源、開啟僅限內網存取時的外網存取，以及沒有經過安全入口的請求：

- 可選預設提示頁、一般 404、空白頁、中斷連線、不回應直到逾時，或自訂 HTML 頁面（可指定狀態碼）；
- 中斷與不回應在建立連線時按來源判定，HTTPS 不送出憑證，經可信代理轉送的請求自動改為一般 404，避免前置代理露出錯誤頁；掛起的連線有時長與數量上限；
- 隱藏方式下回應不再帶有管理介面特有的安全回應標頭，自訂頁面在禁止指令碼與外部資源的沙箱中顯示。

連接埠本身仍可被掃描發現，徹底隱藏需搭配防火牆。詳見 [強化建議](/zh-TW/docs/guide/hardening)。

## 站點錯誤頁

- Web 服務站點的「錯誤頁」分頁可以為 Gately 產生的 404 與 5xx 頁面選擇預設樣式、10 種內建風格（極簡、終端、霓虹、星空、報刊、粗獷、極光、像素、藍圖、狀態鏈路），或頁面庫中的自訂頁面，每種風格都有縮圖與桌面 / 手機預覽；
- 頁面庫可以上傳、貼上 HTML 或引用伺服器上的 `.html` 檔案，儲存時檢查並清理指令碼、事件屬性與表單等內容，支援 `{code}`、`{title}`、`{host}`、`{path}` 等預留位置，輸出時帶禁止指令碼與外部資源的 CSP；
- 反向代理站點可以攔截後端的指定狀態碼（如 `404, 500-599`），只替換瀏覽器開啟頁面的請求，API 請求保持原樣；
- 預設站點的設定同時用於未比對到任何站點的請求，「排序與批次」可以批次設定錯誤頁風格。

詳見 [Web 服務 · 錯誤頁](/zh-TW/docs/modules/web#error-pages)。

## 其他改進

- 動態網域搜尋按記錄篩選：任務的名稱、分組、備註或服務商相符時顯示全部記錄，否則只列出相符的記錄，搜尋期間自動展開收合的任務與分組；Web 服務搜尋時自動展開收合的監聽；
- 設定頁的長標籤自動換行，德語、俄語等語言下不再與輸入框重疊；
- 管理介面請求遇到非 JSON 回應（如工作階段過期後被安全入口攔截）時提示重新整理或重新開啟安全入口；
- 預設錯誤頁的「重新整理」改為一般連結，在禁止指令碼的 CSP 下同樣可用；
- 診斷包與 `GET /api/status`、`GET /api/system/info` 帶上建置資訊（是否自訂、包含的模組與語言）；
- CI 增加預設 build tag 組合的檢查。

## 升級提示

- Docker 拉取新映像後重建容器，已掛載 Docker 通訊端的也可以在 Gately 的 Docker 頁面直接升級 Gately 自身；OpenWrt 覆蓋安裝新的 `.apk` / `.ipk`；飛牛在應用中心手動安裝新版 `.fpk`；其他部署方式可在「關於」頁線上升級。
- 完整版使用者無需任何操作，設定格式沒有變化。

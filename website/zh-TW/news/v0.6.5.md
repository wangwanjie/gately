# Gately v0.6.5 發佈

2026 年 11 月 6 日

[下載 v0.6.5](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5)

## 後端逾時、訪客逾時與自動重試

- 反向代理站點的「流量」頁新增「後端逾時」：連線、TLS 交握、等待回應標頭三項，留空分別為 10 秒、10 秒與不限；等待回應標頭逾時回傳 504，不影響之後的下載與 WebSocket、SSE 等長連線。
- 連線後端失敗（拒絕連線、無法連線、連線逾時）時，同一個請求立即改用下一個後端，一個請求最多嘗試 3 個後端；這時請求還沒有送出，POST 等請求換後端同樣安全。
- 「訪客逾時」限制讀取請求本文與寫出回應時的閒置時間，預設 60 秒，用於斷開極慢傳送或讀取的訪客；讀取請求本文逾時回傳 408。
- 匯入 nginx 設定時，`proxy_connect_timeout` 與 `proxy_read_timeout` 轉換為站點的連線逾時與等待回應標頭逾時。

詳見 [後端逾時](/zh-TW/docs/modules/web#backend-timeouts) 與 [訪客逾時](/zh-TW/docs/modules/web#client-timeouts)。

## 向後端傳遞身分資訊

原來的「傳遞使用者名稱」與「傳遞電子郵件」合併為「傳遞身分資訊」清單，每列把登入使用者的一項資訊寫入一個請求標頭：使用者名稱、電子郵件、顯示名稱或群組，例如 Firefly III 這類以電子郵件作為帳號的應用可以直接讀取 `Remote-Email`。訪客自帶的同名請求標頭（包括以底線代替連字號的寫法）在認證前刪除，無法偽造；訪客也無法藉 `Connection` 標頭讓這些請求標頭被移除。舊設定升級後自動轉換。詳見 [傳遞身分資訊](/zh-TW/docs/modules/web#identity-headers)。

## 自動放行防火牆

Web 服務的監聽、連接埠轉發與協定分流的規則新增「自動放行防火牆」開關，只在本機防火牆（nftables、iptables 或 ip6tables）中放行實際監聽的連接埠，支援 IPv6 與連接埠區間，連續連接埠合併為一條規則；開啟 HTTP/3 的監聽同時放行同號 UDP 連接埠，只監聽迴環位址時無需放行。監聽停止或刪除時撤銷。詳見 [自動放行防火牆](/zh-TW/docs/modules/web#auto-firewall)。

## 執行日誌

- Web 服務的存取記錄按天切分並壓縮歸檔，可設定保留天數與總大小，過去的存取記錄可以繼續檢索；「載入更早的日誌」會查找歸檔。
- 日誌工具列新增「匯出」，依目前篩選條件匯出全部日誌（含檔案與歸檔中的歷史），格式為 CSV（UTF-8 帶 BOM，Excel 可直接開啟，已防公式注入）或 JSON Lines；唯讀帳號匯出的內容同樣隱藏位址中的密碼與權杖。
- 「設定 → 網路與執行」新增「日誌目錄」，可以把執行日誌放到外接硬碟等其他目錄。
- 「來源」篩選列出全部來源；同名的 IPv4 與 IPv6 監聽的日誌不再混在一起，站點的「記錄」視窗只顯示本監聽的訪客。
- 待寫入磁碟的日誌達到 256 KB 時立即寫入，高並行站點不再遺失存取記錄；手機上開啟日誌重新停在最新一筆。

詳見 [執行日誌](/zh-TW/docs/guide/configuration#log-export)。

## 入侵防護：IPv6 嚴格模式

連接埠掃描偵測新增「IPv6 嚴格模式」：IPv6 來源只能連線開放連接埠（正在監聽的連接埠加額外開放連接埠），第一次連線其他連接埠即按 /64 封鎖；IPv4 仍依門檻偵測。連接埠短暫停止監聽時 30 秒內仍視為開放，FTP 服務的被動連接埠範圍自動計入開放連接埠。詳見 [入侵防護](/zh-TW/docs/modules/guard)。

## 託管程序資源

概覽頁新增「託管程序」卡片，效能監控頁列出 Gately 管理的外部程式（frpc / frps、tailscaled、NetBird、cloudflared、File Browser）各自的 CPU 與記憶體，程序重啟後曲線保持連續。詳見 [效能監控](/zh-TW/docs/modules/perf)。

## 其他改進與修正

- 站點連結：監聽只對本機開放、經協定分流或連接埠轉發進入時，站點連結自動使用規則的入口連接埠，例如 4435 監聽由 4433 的 SNI 分流轉入時連結用 4433；手動填寫的存取連接埠仍優先。
- 網路拓撲新增「聚焦活動」，只顯示最近 60 秒有請求或有活動 IP 的站點與後端；活動中的節點不再被收進「其餘 N 個」。
- 網路自檢：本機 DNS 偶爾逾時不再把解析正確的 DDNS 記錄報為未解析，改用公共 DNS 複查。
- DDNS：任務停止或重新啟動時取消的同步不再記錄錯誤、不再把記錄標為失敗。
- 掃描器造成的 TLS 交握失敗改為除錯層級日誌，執行日誌不再被洗版；目標使用 `{host}` 等變數的重新導向站點，對沒有 Host 標頭的請求回傳 400。
- 入侵防護封鎖表改為緊湊格式寫入磁碟，單純到期的封鎖不再觸發重寫。
- 匯入的反向代理設定保留監聽的 HTTP/3 設定。
- 登入頁不再顯示預設帳號與重設密碼提示。
- Web 終端機：檔案管理器的編輯器用右上角 X 或 Esc 關閉後可以再次開啟；手機上選取模式向上拖過一屏後複製正常。
- 介面：站點列在平板與小螢幕筆電上不再把網域擠成一欄；IPv6 監聽位址顯示為 `http://[::1]:18951`。

# Gately v0.6.3.5 發布

2026 年 11 月 3 日

[下載 v0.6.3.5](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.3.5)

## 安全修正

- 唯讀帳號與唯讀 API 權杖此前能在 Tailscale 狀態介面與模組日誌裡看到等待登入時的登入連結，拿到連結即可把這台閘道登記到自己的 tailnet。現在登入連結只回傳給有 Tailscale 寫入權限的身分，日誌只保留連結的主機部分（新增的 NetBird 模組同樣處理登入連結與裝置碼）。
- Web 終端機「測試連線」在測試已儲存的連線、合併已儲存金鑰或引用認證預設時，同樣要先通過使用協議與兩步驟驗證門檻：這類請求會把已儲存的密碼送往請求指定的主機。

## NetBird 組網（#69）

新增 NetBird 模組，託管官方用戶端，用法與 Tailscale 模組一致：

- 由 Gately 託管 `netbird service run`（狀態儲存在設定目錄），也可以接管系統裡已安裝的 NetBird 服務；
- 支援設定金鑰或登入連結 / 裝置碼登入，自建管理伺服器位址、主機名稱、路由、DNS、拒絕入站、使用者態網路與「存取本機服務」、SOCKS5 代理；
- 託管時由 Gately 負責連線，守護程序重新啟動後自動重新連線，失敗時以 10 秒到 5 分鐘退避重試；
- 頁面的「線上安裝」可下載、更新、回滾與解除安裝 NetBird，「恢復預設設定」會登出並清空登入狀態。

詳見 [組網與穿透 · NetBird](/zh-TW/docs/modules/tunnels)。

## 自動檢查更新與安全提醒（#68）

- 預設每 12 小時匿名查詢一次 GitHub 上的發布列表與安全公告（經「更新代理」，只讀取不上報），可在「關於」頁或「設定」中關閉；
- 有新版本時管理介面頂部提示，可檢視更新內容或忽略此版本；目前版本受已公開的安全問題影響時顯示紅色提示，列出公告編號、嚴重程度與修正版本；
- 發現新版本或安全問題時發布 `system.update` / `system.security` 事件，通知中心新增「版本更新」規則範本；frp、cloudflared、Tailscale、NetBird、File Browser 的線上安裝卡片新增「檢查更新」，Docker 定時檢查發現新映像時也會傳送通知。

詳見 [安裝部署 · 自動檢查更新與安全提醒](/zh-TW/docs/guide/install#update-check)。

## 複製條目（#65）

所有列表都可以基於既有條目建立副本：編輯框以原條目為範本開啟，名稱自動加上「副本」，密碼與金鑰由伺服器端沿用原條目，明文不經過瀏覽器。憑證副本會重新簽發或讀取，部署目標預設停用，避免覆寫原憑證的檔案；Web 站點副本可放到其他監聽，監聽副本可選擇是否帶上站點。介面為通用的 `POST <路徑>/{key}/copy`。

## 移動 Web 站點（#63）

- 站點編輯框的「所屬監聽」在編輯時也能修改，儲存後站點移到新監聽；
- 「排序與批次」模式新增「移到監聽」，可跨監聽勾選，一次移動多個站點；
- 拖曳站點到其他監聽的站點或分組上即可移動。

目標監聽已有相同網域時拒絕移動；效能監控告警規則與分享連結的使用次數隨站點遷移，登入狀態依監聽與站點區分，移動後訪客需要重新登入。從 HTTPS 移到明文 HTTP 且站點需要登入時會提示風險。

## 通知與代理（#67）

- 通知中心新增「通知設定」，可設定全域通知代理（不使用 / 使用全域更新代理 / 自訂），每個管道也可以單獨選擇，支援 `http://`、`https://`、`socks5://`、`socks5h://`，郵件經代理時在通道內完成 STARTTLS / SSL；
- DDNS / STUN 的 Webhook、排程工作的 HTTP 請求、訂閱 IP 列表與 GeoIP 資料庫下載也可以設定代理；
- 卡片與錯誤訊息裡隱藏代理密碼。

## 其他改進

- 頁首與列表工具列在捲動時保持可見：模組頁首置頂，標題捲出後只露出操作列；卡片內的工具列固定在頁首下方；對話框的標題、分頁列與底部按鈕固定，表單在中間捲動（#64）；
- Docker 的拉取、推送、建置、檢查更新、Compose 與批次升級等背景工作可以中斷，Compose 先送出中斷訊號讓它自行收尾（#67）；
- 網路拓撲的站點、後端與活動 IP 可以直接檢視存取日誌，站點、後端與監聽可以在拓撲頁原地編輯；Web 服務站點列新增「記錄」按鈕（#67）；
- 映像同時發布到 Docker Hub 的 `vanjayak/gately`，與 GHCR 是同一份多架構映像，同樣有 cosign 簽章（#67）；
- 新建 API 權杖的彈窗新增 `/api/openapi.json` 呼叫範例（#67）；
- Web 服務手動封鎖與「中斷並封鎖」新增「永久」選項；
- 「隱藏被封鎖來源」同時隱藏仍在封鎖中的來源此前觸發封鎖的那些請求；
- 唯讀帳號的側欄不再顯示操作稽核、設定歷史、API 權杖與設定，直接開啟這些頁面會回到概覽，介面不再請求管理員介面。

## 修正與強化

- 批次新增條目改為持鎖校驗，修正新增 Web 服務監聽與 IP 列表之間的資料競爭；
- 連續移動站點時依序執行，效能監控告警規則不會停在已不存在的站點上；
- 手動封鎖拒絕迴環位址、未指定位址與可信代理位址（入侵防護的手動封鎖拒絕迴環與未指定位址），超大的封鎖秒數不再溢位成永久封鎖；
- Docker 定時檢查在檢查失敗或容器停止期間保留通知記錄，同一個新映像不會重複通知；
- NetBird 與 Tailscale 託管守護程序時不再修改既有自訂狀態目錄的權限；NetBird 0.75 以下的使用者態 SOCKS5 恆監聽 0.0.0.0 時給出警告，SOCKS5 監聽在本機以外的位址時介面提醒；
- 拓撲頁檢視命名預設站點的存取日誌時依該站點篩選；未命名的預設站點不再提供會混入全部站點日誌的入口；
- 執行日誌來源篩選的清除按鈕恢復正常；唯讀帳號重新整理管理員頁面時不再出現 403 請求；
- 代理密碼中含未編碼的 `@`、`/`、`:` 時也能完整隱藏。

## 升級提示

- Docker 拉取新映像後重建容器，已掛載 Docker 通訊端的也可以在 Gately 的 Docker 頁面直接升級 Gately 自身；OpenWrt 覆蓋安裝新的 `.apk` / `.ipk`；飛牛在應用中心手動安裝新版 `.fpk`；其他部署方式可在「系統設定」中線上升級。
- 升級後自動檢查更新預設開啟，不需要時可在「關於」頁關閉。

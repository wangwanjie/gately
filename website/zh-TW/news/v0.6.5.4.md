# Gately v0.6.5.4 發佈

2026 年 11 月 11 日

[下載 v0.6.5.4](/zh-TW/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.4)

## 網路喚醒：遠端關機

為裝置選擇一個 Web 終端中的 SSH 連線並填寫關機命令後，裝置卡片上出現「關機」按鈕（介面 `POST /api/wol/devices/{key}/shutdown`）。

- 介面提供 Linux（`shutdown -h now`）、Windows（`shutdown /s /t 0`，需開啟 OpenSSH 伺服器）與 macOS（`sudo -n shutdown -h now`）的常用命令；
- 該連線必須已在 Web 終端中連線過一次、記錄了主機金鑰，無人值守時不信任未知主機；
- 每次關機新建一條 SSH 連線，執行完即關閉，裝置重新開機後不會用到已失效的舊連線；命令最長執行 30 秒，同一裝置同時只執行一次；連線在返回結束碼之前中斷視為已開始關機；
- API 權杖新增、修改、複製裝置或觸發關機時，除 `wol:write` 外還需要 `webterminal:write`，列出可選的 SSH 連線需要 `webterminal:read`。

## 網路喚醒：巴法雲語音控制

接入[巴法雲](https://cloud.bemfa.com)後可以用小愛同學、小度、Google Assistant 等語音助理開關裝置：在巴法雲控制台新增以 `001`（插座）或 `006`（開關）結尾的主題，裝置中填寫同名主題，在「網路喚醒 → 巴法雲」中填寫使用者私鑰並啟用，再在米家、小度等 App 中綁定巴法雲帳號。

說「打開」喚醒裝置，說「關閉」遠端關機，成功後把開關狀態寫回巴法雲；從介面或 API 喚醒、關機同樣寫回。Gately 以 MQTT 3.1.1 經 TLS 連線 `bemfa.com:9503` 並驗證憑證，私鑰在介面中遮蔽顯示；訂閱時伺服器補發的上一次狀態不會執行，10 秒內重複的同一指令只執行一次。同一私鑰同時只能有一個用戶端在線。

## Web 服務：監聽附加 HTTP 埠

監聽可以再填一個明文 HTTP 埠（例如 HTTPS 監聽 443 時再開 80），與主埠共用全部站點與設定，不必為 HTTP 另建監聽、重複填寫站點。開啟 HTTPS 時可選「跳轉到 HTTPS」（預設，保留網域、路徑與查詢字串，埠換成存取位址中的埠，GET/HEAD 用 301、其他方法用 308）或「直接服務」。

- ACME HTTP-01 驗證、PROXY 協定與自動放行防火牆同樣作用於這個埠；埠被佔用時主埠照常運行，監聽狀態中顯示原因；
- 沒有對應站點的網域不跳轉，按未知網域回傳 404 或交給預設站點（預設站點為「斷開連線」時直接斷開），與 HTTPS 上的處理一致，同埠 HTTP 的跳轉也改為如此；
- 儲存時檢查 HTTP 埠與其他監聽的埠是否衝突；監聽經協定分流或連接埠轉發存取而未填寫存取埠時，編輯框會提醒填寫入口埠。

## 導覽面板：換膚

導覽面板使用與管理介面相同的主題配色（Gately 原創與經典配色），編輯面板時可以選擇預設外觀。訪客點頁面右上角的調色盤按鈕即可換膚，互動與管理介面一致：亮色、暗色或跟隨系統，懸停預覽色系、點擊後從點擊處展開新配色，自訂主色與圓角；手機上從底部彈出。選擇保存在訪客的瀏覽器中，面板與管理介面在同一網域下時兩邊的選擇互通。詳見 [Web 服務 · 導覽面板](/zh-TW/docs/modules/web#nav-panel)。

# 設定與執行參數

## 命令列參數

| 參數 | 說明 |
| --- | --- |
| `-c` | 設定目錄，也可以用環境變數 `GATELY_CONFIG_DIR` 指定 |
| `-listen` | 覆寫管理介面監聽位址，例如 `:16680` |
| `-apply` | 宣告式設定目錄，也可以用環境變數 `GATELY_APPLY_DIR` 指定，見下文 |
| `-version` | 輸出版本資訊 |

| 環境變數 | 說明 |
| --- | --- |
| `GATELY_INITIAL_PASSWORD` | 首次啟動時的管理員初始密碼（至少 8 位），未設定時為預設密碼 `gately.cn`；帳號已存在時不起作用 |

## 設定目錄

所有設定都儲存在設定目錄中，每個模組一個 `<name>.json` 純文字檔案，原子寫入，檔案權限 0600。因此：

- 可以直接用文字編輯器檢視；
- 可以把目錄納入 git，用 diff 稽核每次變更並隨時回復；
- 備份只需複製目錄。

::: warning 注意
`ssl.json` 中含有憑證私鑰，納入版本庫前請確認儲存庫為私有，或把該檔案加入忽略清單。
:::

## 宣告式設定

指定 `-apply <目錄>` 後，每次啟動會把該目錄下的 `<名稱>.json` 覆寫到設定目錄，內容相同的檔案不會重寫。適合把設定放在 git 儲存庫、Kubernetes ConfigMap 或部署指令碼中統一下發。

- 寫入前驗證是否為合法 JSON，任一檔案無效則拒絕啟動；
- `account.json` 與 `tokens.json` 不允許覆寫，帳號與權杖只能在管理介面管理；
- 被覆寫的舊內容會保存在 [設定歷史](/zh-TW/docs/guide/audit) 中，可隨時還原。

## 外部程式目錄

Tailscale、frp、cloudflared 與 File Browser 託管官方的外部程式，依以下順序尋找可執行檔：

1. 模組設定中填寫的路徑；
2. 設定目錄下的 `bin/` 子目錄；
3. `PATH`。

各模組頁面可以線上安裝、更新與回滾，程式裝在 `bin/` 下，舊版本儲存在 `bin/.versions/`，詳見 [線上安裝、更新與回滾](/zh-TW/docs/modules/tunnels#install)。也可以自行把執行檔放進設定目錄，Docker 部署時例如 `./gately-data/bin/frpc`；Tailscale 需要同時提供 `tailscale` 與 `tailscaled`。

## 執行日誌

系統日誌與各模組的執行日誌預設寫入設定目錄下的 `logs/`，重新啟動或升級後仍可在「系統日誌」與各模組頁面查看：

- 每個來源一個 JSON Lines 檔案：`logs/<模組 ID>.log`，系統日誌為 `logs/gately.log`；啟動時依「日誌保留筆數」從檔案還原最近的日誌；
- 有新日誌時最多延遲 1 秒批次寫入；單一檔案超過上限（預設 2 MB）後輪替為 `.1`，只保留這一份歷史，每個來源最多占用兩倍上限；
- 「設定 → 網路與執行 → 執行參數」中可以關閉「日誌落盤」或調整「日誌檔上限」，立即生效；關閉後日誌只保存在記憶體，重新啟動後清空；
- 在頁面上清空某個模組的日誌會同時刪除對應檔案；
- 設定備份不包含 `logs/` 與操作稽核日誌 `audit.log`。

### 檢視與篩選 {#log-filter}

「系統日誌」頁和各模組頁面底部的日誌卡片使用同一個日誌檢視器，可以組合以下條件篩選，修改後立即生效，新日誌也只追加符合條件的部分：

- 層級、來源（下拉選擇已出現的來源，也可以直接輸入）；
- 關鍵字：空格分隔表示同時包含，雙引號包住短語，詞前加 `-` 表示排除，例如 `GET "timeout" -debug`，命中的部分會醒目標示；介面為其他語言時，按介面上看到的譯文搜尋即可；
- 「不包含」：包含其中任意一個詞的日誌不顯示，與關鍵字同時生效；寫法同關鍵字（空格分隔、雙引號包住短語），例如 `debug "health check"`。要排除本身以 `-` 開頭的詞，用雙引號包住，如 `"-v"`；
- 「更多篩選」中的 IP：可填完整位址、網段（如 `10.0.0.0/8`）或位址的一部分，多個以逗號分隔；日誌沒有單獨記錄 IP 時會從日誌內容中辨識位址，登入失敗、入侵防護等日誌同樣適用；前加 `!` 或 `-` 表示排除，如 `!1.2.3.4, !10.0.0.0/8` 不顯示這些來源，也可以與包含項組合（`10.0.0.0/8, !10.0.0.5`）；
- 「更多篩選」中的時間範圍：最近 15 分鐘到 7 天，或自訂起訖時間；
- Web 服務的工具列還有兩個顯示開關，只影響頁面顯示，日誌照常保存，選擇記在瀏覽器裡：「隱藏被封鎖來源」不顯示來源已被封鎖而被拒絕的請求（站點在 CDN 後面時，核心封鎖對回源連線不起作用，被封的訪客仍會在 Web 層被拒絕並留下 403 / 444 記錄），之前觸發封鎖的那些請求仍然可見；「隱藏後台自身請求」不顯示帶本執行個體管理後台登入狀態的請求，例如經 Web 服務站點存取後台時日誌頁的輪詢，預設開啟。這兩類日誌行尾分別帶「攔截原因=已封鎖」「後台使用者=…」標籤，對應介面參數 `hideBanned=1`、`hideAdmin=1`（只認管理員工作階段，唯讀帳號不算；被攔截的請求不帶後台使用者標記）；
- Web 服務還可依站點名稱或網域、狀態碼（`404`、`4xx`、`500-599`，多個以逗號分隔）篩選；WAF 防火牆可依網域篩選，命中日誌會記錄網域與規則 ID。

點擊日誌中的來源，或行尾的「站點=…」「網域=…」等標籤，可直接依該值篩選。「載入更早的日誌」在記憶體中的日誌不夠時，會繼續查找日誌檔案中保留的歷史，因此開啟落盤後能篩選的範圍不受「日誌保留條數」限制。介面 `GET /api/logs` 與 `GET /api/<模組>/logs` 支援相同的篩選參數，見 [API 參考](/zh-TW/docs/reference/api-reference)。

# 安全模型與隱私承諾

Gately 執行在網路邊界，經手 DNS 服務商金鑰、憑證私鑰與各類憑據，因此安全與透明是首要設計目標。

## 隱私承諾

- **不連線專案方伺服器**：不回報裝置資訊，不下發遠端設定。預設每 12 小時匿名讀取 GitHub 上的發布列表與安全公告，只用於提示新版本與安全更新，可以關閉，詳見[自動檢查更新](/zh-TW/docs/guide/install#update-check)。
- **對外位址可見可改**：公網 IP 查詢、STUN 伺服器等位址都在介面中顯示，可修改或關閉。
- **第三方登入自主**：GitHub、Google、QQ、OIDC 登入使用你自己申請的 OAuth 應用程式，不經過任何中轉。
- **自主升級**：程式不會在背景下載或替換自身；Linux 執行檔部署的線上升級只在管理員點擊後執行，先驗證發布簽章再核對 SHA-256，並保留舊版本，升級時機由你決定。

## 資料保護

- 設定為純文字 JSON，檔案權限 0600，可稽核、可回復。
- 敏感欄位在 API 輸出中會遮蔽；介面上的眼睛按鈕可依需求取回已儲存的明文，需要寫入權限。以 bcrypt 雜湊儲存的網頁使用者密碼、OIDC 用戶端密鑰和私鑰不會回傳；開啟兩步驟驗證的共用使用者可以重新檢視 QR 碼。Docker 容器的環境變數、啟動指令與行程命令列同樣處理：沒有 Docker 寫入權限時顯示為 `********`。
- cloudflared 的權杖透過環境變數傳遞，不會出現在行程清單中；frp、Tailscale 的權杖與金鑰以 0600 權限儲存。

## 驗證與存取控制

- bcrypt 密碼雜湊，HMAC 簽章工作階段權杖；
- 工作階段撤銷：登出時會在伺服器端撤銷目前的工作階段權杖，外洩的權杖立即失效。「設定 → 帳號與安全 → 登入工作階段」中的「登出所有裝置」會讓所有管理介面工作階段失效（API 權杖不受影響）；修改密碼、啟用或關閉兩步驟驗證與重設密碼同樣會讓所有工作階段失效。撤銷紀錄保存在帳號檔中，重新啟動後仍然有效，隨權杖到期清理，數量有上限；
- 對外請求限制：「設定 → 網路與執行」的「對外請求限制」預設關閉，開啟後 Webhook、通知、IP 清單訂閱、DDNS 回呼與 IP 查詢位址、更新檢查與程式下載、第三方登入等由管理員設定的對外請求，會在連線時拒絕迴環、私有網路、連結本機（含雲端供應商中繼資料位址 169.254.169.254）與 ULA 位址，對網域解析結果和重新導向同樣有效；反向代理上游、網路喚醒、儲存掛載等面向內網的功能不受影響；
- 慢速請求防護：管理連接埠會限制請求本文的讀取速度，一般介面的請求本文需在 60 秒內讀完；備份還原、升級包與檔案上傳等大檔案介面不限總時長，但要求持續傳送並維持最低平均速率（每秒 4 KiB），以慢速佔用連線的用戶端會被中斷；
- 密碼規則：管理員密碼長度 10～72 位元組，拒絕常見弱密碼（含首尾加數字或符號、`p@ssw0rd` 式字元替換等變形）、包含 gately 或使用者名稱、連續字元（如 `123456`、`qwerty`）、重複字元或片段，以及只含一種字元的密碼（16 位以上的密碼短語放寬字元種類要求）；輸入時即時顯示強度；
- 強制修改密碼：預設密碼 `gately.cn` 是公開的。管理員仍在使用預設密碼或強度不足的密碼時，登入後跳出無法關閉的修改密碼對話框，改完才能繼續使用；在此之前，登入工作階段除修改密碼、切換介面語言與登出所有裝置外的寫入操作一律被伺服器端拒絕，API 權杖仍可呼叫，但不能修改帳號、兩步驟驗證、通行金鑰、附加帳號、API 權杖、系統設定與 Web 終端安全設定（也不能從備份還原或回滾系統設定與 Web 終端的歷史版本）；新密碼不能是預設密碼，改過之後也不能改回；
- 重設：忘記密碼或遺失兩步驟驗證器時只能在伺服器上用 `gately reset-password` / `gately reset-totp` 重設（需要讀寫設定目錄並輸入 `yes` 確認），重設後所有工作階段失效並記入稽核日誌，詳見 [重設密碼與兩步驟驗證](/zh-TW/docs/guide/install#reset)；
- Passkey（WebAuthn）登入：只保存公鑰，強制使用者驗證（指紋、臉部或 PIN），簽章計數防複製；需要透過網域名稱與 HTTPS（或 localhost）存取；
- 兩步驟驗證（TOTP，已通過 RFC 6238 測試向量驗證）；
- 唯讀帳號：可檢視狀態與設定，不能修改、下載備份、讀取金鑰或開啟終端機；重設密碼或刪除後工作階段立即失效；唯讀帳號與只有讀取權限的 API 令牌讀取設定時，站點共用使用者密碼、分享連結令牌、請求標頭與回應標頭的值、各類金鑰以及位址中的密碼和查詢參數一律顯示為 `********`；「操作稽核」「設定歷史」「API 權杖」「設定」只對管理員開放，唯讀帳號的介面中不顯示對應入口，直接開啟連結時回到總覽；
- 唯讀帳號與只有讀取權限的 API 權杖同樣看不到命令與指令碼、託管程式的附加啟動參數與環境變數、Webhook 等 HTTP 請求的請求主體，以及 DNS 服務商憑證裡除接入點、請求方法這類設定以外的附加欄位（如自訂回呼的請求標頭與請求主體）；
- 登入失敗限流與遞增鎖定：同一來源連續失敗達到上限後被鎖定，反覆被鎖定時每次鎖定時長加倍，最長 24 小時；
- 陌生位址失敗額度：10 分鐘內，所有從未成功登入過的位址累計登入失敗達到額度（「設定 → 帳號與安全」中的「陌生位址失敗額度」，設定項 `loginGlobalLimit`，預設 20，-1 關閉）後，陌生位址的密碼登入暫時回傳 429，並發出「認證：疑似分散式暴力破解」通知事件；曾成功登入過的位址不受影響，用來抵禦分散在大量位址上的暴力破解。Passkey 登入使用獨立的依來源限流，不受密碼失敗與陌生位址額度影響；
- 關閉密碼登入：註冊了 Passkey 後，可在「設定 → 帳號與安全」的 Passkey 卡片中關閉密碼登入，之後管理員帳號只能用 Passkey 或第三方登入，密碼無法再被暴力破解（唯讀帳號不受影響）；關閉狀態下不能刪除最後一個 Passkey，遺失全部 Passkey 時在伺服器上執行 `gately reset-password` 會重新開啟密碼登入；
- 安全評分：「設定 → 帳號與安全」頂端的安全評分（`GET /api/system/security`）依目前設定檢查七項並給出 0～100 分：管理員密碼（35 分）、二次驗證（TOTP 或 Passkey，20 分）、安全入口（15 分）、登入失敗鎖定策略（10 分）、HTTPS（10 分）、陌生位址失敗額度（5 分）、管理員使用者名稱避開 admin 等常見名稱（5 分）；管理端沒有暴露到公網（僅限內網存取或只監聽迴環位址）時，安全入口、HTTPS 與使用者名稱三項視為滿分。存在高風險或建議強化的項目時管理介面頂端會提示（建議強化的提示可暫緩 7 天），點「前往加強」跳到對應設定；
- 本機反向代理：管理介面放在本機 nginx、haproxy 或 Gately Web 服務之後時，只信任本機位址送來的 `X-Real-IP` / `X-Forwarded-For`，僅限內網存取、登入限流與稽核日誌據此取得真實來源，可在「設定 → 存取控制」關閉或新增額外的可信代理；兩個請求標頭不一致時以代理附加的 `X-Forwarded-For` 為準，其中一個是內網位址、另一個是公網位址時取公網位址，偽造內網位址無法繞過僅內網存取；建議代理同時寫入兩個請求標頭（nginx：`proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;`）；
- 安全入口、僅限內網存取、管理介面 HTTPS；模組免登入介面（`/api/<模組>/public`，如[網路喚醒用戶端](/zh-TW/docs/modules/tools#agent)）憑有效的裝置憑證可以越過安全入口，封鎖與僅限內網存取的限制仍然生效；
- 未授權存取回應：被封鎖、僅限內網時的外網存取與未經過安全入口的請求，可以改為一般 404、空白頁、中斷連線、不回應直到逾時或自訂頁面，隱藏管理連接埠的特徵，詳見 [強化建議](/zh-TW/docs/guide/hardening)；
- 飛牛統一閘道：飛牛安裝包經飛牛統一閘道存取時，由飛牛負責存取控制，只有飛牛管理員能開啟；「飛牛登入狀態自動登入」預設關閉，開啟後已登入的飛牛管理員以 Gately 管理員身分直接登入（略過兩步驟驗證），一般飛牛使用者仍需登入，詳見 [飛牛 fnOS 原生應用](/zh-TW/docs/guide/install#fnos)；
- 經飛牛統一閘道存取時，修改狀態的請求與 WebSocket 連線只接受管理介面自身頁面發出的請求：瀏覽器標明同源（`Sec-Fetch-Site: same-origin`），或者頁面來源此前已由管理員工作階段或管理員的密碼、Passkey 登入確認過；同一台 NAS 其他連接埠上的頁面不能借用管理員的登入狀態。很舊的瀏覽器不傳送 `Sec-Fetch-Site`，首次使用時用管理員密碼登入一次即可。經閘道的登入限流按飛牛使用者計算；
- 內容安全政策：管理介面的頁面只載入自身的指令碼，不能被其他站台嵌入，介面回應不載入任何資源；登入 Cookie 帶 `HttpOnly` 與 `SameSite=Strict`，經 HTTPS 存取（包括可信代理或飛牛統一閘道轉送的 HTTPS）時帶 `Secure`；
- 功能模組開關：在「設定 → 功能模組」關閉不用的模組後，該模組不啟動服務、不提供管理介面，可縮小暴露面；[自訂建置](/zh-TW/docs/modules/#custom-build)可以在編譯時直接去掉不用的模組；
- 多權杖 API：每個權杖只擁有建立時勾選的模組讀寫權限，可設定到期時間，並記錄最近使用的來源 IP；帳號、兩步驟驗證、權杖管理以及備份、還原、重新啟動、系統設定介面只接受登入工作階段，詳見 [API 權杖與 OpenAPI](/zh-TW/docs/reference/api)；
- 站台存取控制：驗證失敗自動封鎖、GeoIP 國家過濾、路徑規則，詳見 [Web 服務](/zh-TW/docs/modules/web)；
- 設定備份支援加密（scrypt + AES-GCM），詳見 [設定備份](/zh-TW/docs/modules/backup)。

## 稽核與可追溯

操作稽核日誌記錄登入、設定變更與敏感存取，設定歷史保留每個設定檔被覆寫前的版本並支援一鍵還原，詳見 [稽核與設定歷史](/zh-TW/docs/guide/audit)。發佈檔案附帶 cosign 簽章、建置來源證明與 SBOM，驗證方法見 [驗證發佈檔案](/zh-TW/docs/guide/verify)。

## 高風險功能的預設值

本機 Shell 終端機預設關閉。SSH 終端機採用「首次信任」策略記錄主機金鑰指紋。

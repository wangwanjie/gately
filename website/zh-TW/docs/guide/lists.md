# 列表分組、排序、批次操作與複製

條目較多的列表都可以分組、手動排序、搜尋和批次操作，操作方式在各頁面一致。順序和分組只影響管理介面的顯示，修改後不會重新啟動執行中的實例，也不會中斷連線。

## 分組

在編輯對話框中填寫「分組」（最長 64 個字元，可從既有分組中選擇），留空為未分組。只要有一個條目設定了分組，列表就按分組顯示可摺疊的區塊：分組按首次出現的順序排列，未分組的條目排在最後，各分組的摺疊狀態儲存在瀏覽器中。搜尋框可按名稱、分組、備註等篩選條目，搜尋時展開全部分組。

滑鼠移到分組標題上，點鉛筆按鈕可以重新命名分組：組內條目一起改為新名稱，位置和順序不變；改成既有分組的名稱時，確認後兩個分組合併。

## 排序模式

點擊「排序與批次」進入排序模式，此時顯示全部條目，搜尋與篩選暫不生效：

- 用箭頭在分組內上移、下移條目，或在分組標題上整組移動；
- 桌面端可以直接拖曳條目；拖到其他分組的條目或分組標題上即加入該分組；
- 勾選多個條目（分組標題的核取方塊可選取整組）後拖曳其中任一項，所有選取項按目前順序一起移動；
- 工具列可以把選取的條目批次「移到分組」，留空則移出分組。

手機等窄螢幕裝置不支援拖曳，用箭頭和工具列完成同樣的操作。

## 批次操作

在排序模式下勾選條目後，工具列還可以：

- **啟用 / 停用**：一次儲存全部選取的條目，已經是目標狀態的條目不會重新啟動；
- **刪除**：確認對話框會列出將刪除的條目，刪除後無法復原。任一條目不允許刪除（例如憑證仍被站台引用）時一個都不刪，並提示原因。

批次操作一次最多處理 500 個條目，全部驗證通過才儲存，任一條目失敗都不做修改。網路喚醒裝置沒有啟用開關，只提供批次刪除；API 權杖暫不提供批次啟停與刪除。Web 服務另有批次修改網域與選項，見 [Web 服務](/zh-TW/docs/modules/web#批次操作)。

## 複製項目

除 API 權杖外，上表中的項目都可以「複製」，另外訂閱 IP 清單、備份目的地、Web 終端的認證預設、動態網域任務內的解析記錄與 Web 服務監聽內的站點也可以複製：點擊項目上的「複製」，以它為範本開啟新增對話框，名稱自動加上「副本」後綴，改好需要區分的設定後儲存即新增一筆，原項目不受影響，副本排在原項目之後。

- **金鑰沿用原項目**：密碼、權杖、私鑰等已儲存的金鑰在對話框中保持遮蔽，不修改就沿用原項目的值，明文不經過瀏覽器；點眼睛按鈕可以查看原項目的明文。Web 終端的連線與認證預設需要先通過使用者協議與二次驗證才能沿用金鑰。
- **系統維護的內容不複製**：ACME 申請和從檔案讀取的憑證會依副本的設定重新簽發或讀取，上傳的憑證連同私鑰一起複製；憑證的部署記錄清空；訂閱 IP 清單重新下載；站點的分享連結不複製，因為其權杖可以繞過認證。
- **憑證的部署目標**：副本中的部署目標先停用，避免寫到與原憑證相同的檔案，確認檔名不衝突後再啟用。
- **Web 服務**：複製站點時可以選擇放到其他監聽下（例如從 HTTP 監聽複製到 HTTPS 監聽）；複製監聽時可以選擇是否同時複製其中的站點。
- 副本保持原項目的啟用狀態，儲存前記得修改連接埠、網域、記錄等需要區分的設定，避免與原項目衝突。

## 各頁面的補充說明

- **動態網域**：任務卡片上的「記錄排序」開啟對話框，調整該任務內解析記錄的順序與分組，儲存後立即生效，不會重新同步；編輯任務時也可在「解析記錄」頁籤中開啟同一對話框，隨任務一起儲存。記錄設定了分組時，卡片中的記錄按分組顯示，每組可以單獨收合。
- **frp**：代理列表可以按 frpc 實例篩選；排序模式下顯示全部代理，調整的是完整順序。
- **API 權杖**：未手動排序前按建立時間從新到舊顯示；調整過順序後按儲存的順序顯示，新建的權杖排在最前。
- **認證使用者**：「使用共用使用者的站點」按監聽顯示，監聽內的站點再按 Web 服務中的分組歸類；監聽和分組都可以單獨收合，工具列可一鍵全部收合或展開。

## 介面

通用列表介面都提供 `PUT <列表路徑>-order`（請求主體 `{"keys": [...]}`，須包含全部條目）調整順序，`PUT <列表路徑>-group`（請求主體 `{"keys": [...], "group": "..."}`）批次設定分組，`PUT <列表路徑>-enable`（請求主體 `{"keys": [...], "enable": true}`）批次啟停，`POST <列表路徑>-delete`（請求主體 `{"keys": [...]}`）批次刪除，例如 `PUT /api/stun/rules-group`、`POST /api/portforward/rules-delete`。DDNS 任務內的記錄使用 `PUT /api/ddns/tasks/{key}/records-layout`，API 權杖使用 `PUT /api/tokens/order` 與 `PUT /api/tokens/group`。詳見[介面清單](/zh-TW/docs/reference/api-reference)。

複製項目使用 `POST <列表路徑>/{key}/copy`，請求主體為新項目，仍為占位符 `********` 的金鑰沿用 `{key}` 項目的值，例如 `POST /api/frp/clients/{key}/copy`。

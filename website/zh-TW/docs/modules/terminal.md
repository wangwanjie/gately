# Web 終端機

在瀏覽器中連線 SSH、Telnet 伺服器或本機 Shell，工作階段在伺服器端持久保存，可斷線重連。入口為側邊欄「Web 終端機」。

## 連線類型

| 類型 | 說明 |
| --- | --- |
| SSH | 支援密碼與私鑰驗證（可貼上私鑰或指定伺服器本機的 `keyFile` 路徑，支援私鑰密碼），可設定登入後進入的 `workDir`、`keepAlive`、連線逾時（1~120 秒，預設 15）與代理 |
| Telnet | 預設連接埠 23，偵測到 `login:`、`username:`、`password:` 等提示時各自動填入一次，可設定代理 |
| 本機 Shell | 在執行 Gately 的裝置上直接開啟 Shell，可指定 Shell 路徑、工作目錄與附加環境變數 |

每個連線可填寫備註。連線清單支援拖曳排序和「測試連線」：SSH 回傳伺服器端版本與延遲，Telnet 僅驗證 TCP（含代理）可達，本機 Shell 不支援測試。編輯連線時，密碼、私鑰、私鑰密碼與代理密碼以遮蔽形式顯示，維持不變時沿用原值。

在「設定」中可維護「SSH 認證預設」（密碼或私鑰，可附預設使用者名稱）。新增或編輯 SSH 連線時選擇「認證預設」即可重複使用，同一份憑證可被多個連線引用，修改預設後這些連線下次連線時自動生效；仍被連線引用的預設無法刪除。

### 代理

SSH 與 Telnet 連線可單獨設定出口代理，類型為 `socks5` 或 `http`，可填寫代理使用者名稱和密碼。

### 主機金鑰首次信任

SSH 連線首次建立時記錄伺服器主機指紋並信任，之後每次連線核對指紋。伺服器重灌或更換金鑰後，在連線上執行「重設主機指紋」即可重新信任。

## 工作階段

- 工作階段持久保存在伺服器端，瀏覽器重新整理或中斷後可從工作階段清單重新附著，附著時先重播輸出緩衝再即時轉發；
- 同一工作階段允許多個用戶端同時附著，輸入共用、輸出廣播；
- 工作階段可新增備註，清單顯示建立時間、最後活動時間、視窗大小與收發位元組數；
- 頁面重新整理後，仍存活的工作階段自動恢復為分頁，分割畫面佈局一併恢復；
- 終端機內建搜尋（輸入關鍵字，Enter 尋找下一個，Shift+Enter 尋找上一個）、複製、貼上、清除畫面、字型大小調整、全螢幕與多套終端機配色（預設跟隨介面主題，也可固定為某套配色）。

### 設定項

在頁面右上角「設定」中調整：

| 欄位 | 預設值 | 說明 |
| --- | --- | --- |
| `allowLocalShell` | 關閉 | 是否允許開啟本機 Shell |
| `maxSessions` | 20 | 最大並行工作階段數，上限 1000，超出時新增工作階段會回傳 HTTP 429 |
| `idleTimeout` | 0 | 工作階段無輸入輸出超過該分鐘數自動結束，0 表示不限 |
| `bufferSize` | 256 | 每個工作階段保留的重播緩衝（KB），上限 16384 |
| `heartbeatInterval` | 30 | WebSocket 心跳間隔（秒），上限 600 |
| `sessionKeepAlive` | 0 | 瀏覽器中斷後工作階段繼續保留的分鐘數，0 表示中斷即結束，上限 10080 |

::: tip
需要斷線重連能力時，把 `sessionKeepAlive` 設為大於 0 的值。設為 0 時瀏覽器中斷會立即結束工作階段。
:::

## SFTP 檔案管理

終端機工具列的資料夾圖示會開啟檔案管理面板。SSH 連線透過 SFTP 操作遠端檔案，本機 Shell 連線直接操作 Gately 所在裝置的檔案系統；Telnet 連線不提供檔案管理。本機檔案管理要求已開啟「允許本機 Shell」。

| 能力 | 說明 |
| --- | --- |
| 瀏覽 | 麵包屑與上層目錄導覽，目錄在前、依名稱排序，可切換排序方式；顯示權限、大小、修改時間與擁有者 |
| 新增 | 新增資料夾、新增空檔案 |
| 上傳 | 多檔案上傳，桌面版支援上傳整個資料夾（保留子目錄結構），同名檔案覆寫，面板顯示上傳進度 |
| 下載 | 串流下載，支援斷點續傳（`Range`） |
| 線上編輯 | 文字檔預覽與儲存，檔案超過 1MB 或為二進位時無法預覽 |
| 重新命名、複製、貼上 | 複製到同目錄時自動改名為 `name 副本.ext`、`name 副本 2.ext` |
| 刪除 | 支援多選批次刪除，目錄遞迴刪除，根目錄受保護 |
| 壓縮與解壓縮 | 壓縮為 `zip` 或 `tar.gz`；解壓縮支援 `zip`、`tar`、`tar.gz`、`tgz`；可在解壓縮前預覽壓縮檔內容（最多 10000 筆）；壓縮解壓縮由 Gately 自身完成，遠端無需安裝命令 |
| 修改權限 | 八進位權限（0 到 7777），目錄可選遞迴 |
| 快速存取 | 為每個連線儲存常用目錄，一鍵跳轉 |

解壓縮時含 `..` 的項目整體拒絕以防目錄穿越，符號連結與硬連結項目會被略過，檔案權限只保留 rwx 位。行動裝置版面板提供多選模式與操作面板。

## 快捷命令

「快捷命令」下拉選單列出全域快捷命令，點擊後送出到目前終端機。每條快捷命令包含 `name`、`command` 與 `sendEnter`（送出後是否自動按 Enter）。在下拉選單底部的「管理快捷命令」中新增、修改、刪除。

## 分割畫面

工具列「分割畫面」選單提供左右分割、上下分割與網格分割，最多同時顯示 4 個窗格。進入分割畫面後，再開啟連線會自動加入分割，也可點擊其他分頁加入，窗格標題列可將工作階段移出分割。分割佈局儲存在伺服器端，重新整理頁面後恢復。窄螢幕下自動取消分割，已儲存的佈局不會刪除。

## 行動裝置適配

- 窄螢幕下連線清單與終端機分為兩個檢視，終端機檢視左上角的返回按鈕可回到清單；
- 終端機區域跟隨可視視窗，軟鍵盤彈出時自動縮小；
- 虛擬按鍵列為單列、可左右滑動，提供 `Esc`、`Tab`、`Ctrl`、`Alt`（可黏滯）、方向鍵（長按重複）、常用符號、快捷命令入口，右側固定一個鍵盤按鈕（叫出或收起鍵盤）。按鍵列預設跟隨軟體鍵盤出現與隱藏；鍵盤收起時右下角保留一個懸浮按鈕，點擊即可叫出鍵盤。需要在不彈出鍵盤時使用方向鍵、翻頁等按鍵，可在「更多」選單開啟「始終顯示按鍵列」。

## 安全

終端機等同於在目標主機上執行任意命令，Gately 預設採取以下限制：

- **本機 Shell 預設關閉**，需要在設定中明確開啟；
- **協議確認**：首次開啟本機 Shell、新增工作階段、附著工作階段或使用檔案管理時，會彈出使用者協議，勾選同意後繼續；
- **二次驗證（2FA）**：在安全設定中掃描 QR code 綁定 TOTP 驗證器後，上述操作要求輸入 6 位數驗證碼。驗證通過後目前登入權杖 30 分鐘內無需重複驗證；連續輸錯 5 次，該登入權杖鎖定 1 分鐘；
- 連線密碼、私鑰與代理密碼在介面輸出中遮蔽。

::: warning
開啟本機 Shell 前，先為管理介面啟用兩步驟驗證，並搭配「僅限內網存取」或 VPN 使用。
:::

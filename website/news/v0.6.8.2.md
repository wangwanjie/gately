# Gately v0.6.8.2 发布

2026 年 11 月 18 日

[下载 v0.6.8.2](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.2)

## 端口敲门：每人一份密钥

- **身份**：规则可添加身份，每个身份（人或设备）有自己的加密密钥与 HMAC 密钥，可单独停用、重新生成；每条规则最多 64 个身份。日志、通知与放行记录会写明是哪个身份敲的门，停用或换掉某人的密钥只撤销这个人的放行。
- **停用共享密钥**：全部改用身份后，可关闭规则原来的共享密钥。
- **一次只放行一个地址**：同一身份从新地址敲门时撤销它在旧地址上的放行，适合手机在不同网络间切换。
- 校验伪造报文时复用 HMAC 计算对象，64 个身份时每个报文的开销约减半；来源表满时淘汰最久未用的网段，合法的首次敲门不再和攻击流量共用一个溢出桶。

## 端口转发 / 协议分流

- **不受单来源上限的来源**：全局设置新增 IP / CIDR 列表。前面有公网中转或前置代理、所有访客都显示为同一个来源时，把它填进去，就不会被「单来源最大连接数」卡住；其他来源照旧按上限限制。
- 触发单来源上限的日志会写明被计数的来源（IPv6 为 /64）和上限，并提示调高规则的单来源上限或添加豁免来源。
- 修复：填写目标地址后失去焦点，仍提示「targetAddresses 为必填」。

## Web 服务

- **反代到另一台 Gately**：v0.6.8 起，反向代理到非本机管理后台的站点会剥掉所有 `gately_token`、`gately_entry`、`gately_login_nonce`，后端是另一台 Gately 时会出现登录后立即 401、设置了安全入口的后台一直 404、经外层站点第三方登录提示「浏览器不一致」。现在只剥掉本实例签发且仍有效的 Cookie，后端 Gately 自己的同名 Cookie 照常转发。
- **双层 Gately 的后台登录免认证**：开启「转发 Gately 登录 Cookie」的站点会转发本实例校验不过的 `gately_admin`，内层 Gately 的「后台登录免认证」可以生效；本实例签发的仍不转发。
- **修复 421**：v0.6.8.1 起，前面有反向代理（另一台 Gately、Caddy、Traefik）以 HTTP/2 连接、SNI 为后端主机名而 Host 为访客域名时，落到默认站点的请求会收到 421，页面打不开。现在只有 SNI 是本监听上某个站点的域名时才返回 421，浏览器复用连接的场景照旧处理。
- **同一地址并发登录**：同一 IP 同时发起多个正确的登录不再被当成失败过多而拒绝。只有真正的失败计入上限，进行中的校验排队等待，最多仍只能试 10 次错误密码；排队超过 5 秒或队列已满返回 429。
- **后台登录免认证**：去掉 v0.6.8.1 的跨父域握手（「后台入口地址」），这个选项重新只在单点登录域内生效。

## 导航面板（#104）

- **拖动排序**：面板编辑中按住链接的拖动柄拖到其他链接前后或分组标题上，鼠标与触摸都可以；靠近边缘自动滚动，Esc 取消。「选择」模式下可一次移动多个链接。
- **面板列表分组**：面板可设分组，列表支持分组折叠、按名称 / 标题 / 分组 / 备注搜索、紧凑视图，以及「排序与批量」（批量删除时仍被站点使用的面板不会删除）。

## 性能

- 同一监听下指向同一后端、连接设置相同的站点共用后端连接池，反向代理不再为每个请求复制一份请求。
- 站点 24 小时分钟统计按小时块按需分配：1000 个站点的峰值内存从 463 MiB 降到 225 MiB，吞吐 37,423 req/s。
- GC 百分比设为 0 时，可用内存不少于 1 GiB 默认用 200（反向代理压测吞吐约提高 10%），否则仍为 100；设置了环境变量 `GOGC` 时沿用环境变量。
- 入侵防护跟随日志改为文件写入即读取（Linux 用 inotify，其他系统仍为轮询），封禁写入防火墙每 250 ms 合并一次，单次封禁仍立即生效。

## 其他

- 手动编辑或脚本生成的配置文件缺字段时，Web 服务、DDNS、STUN、SSL、WAF、入侵防护、网络唤醒、通知、File Browser、Web 终端、性能监控在加载时补上与保存时相同的默认值（此前空的监听网络会导致监听无法启动、健康检查零间隔会空转等）。
- 通知 Webhook 渠道的变量列表补上 `{server}`。
- 官网新增[教程](/docs/tutorials/)与[性能对比](/docs/guide/benchmarks)页面。

## 升级提示

- Docker 拉取新镜像后重建容器；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「系统设置」中在线升级。
- 用过 v0.6.8.1「后台入口地址」让单点登录域以外的站点免认证的，升级后这些站点恢复为正常的站点认证。
- 反代到另一台 Gately 的 Cookie 问题只需升级外层（做反向代理的那台）。

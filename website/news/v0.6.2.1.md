# Gately v0.6.2.1 发布

2026 年 11 月 1 日

[下载 v0.6.2.1](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.1)

## 可信代理下的访客真实 IP（#50）

Web 服务「全局设置」新增「访客真实 IP」：填写 CDN、WAF 等可信代理的回源地址或网段，并按顺序选择真实 IP 请求头（`CF-Connecting-IP`、`X-Forwarded-For`、`X-Real-IP`、`True-Client-IP` 或自定义）。只有直接对端属于可信代理时才读取这些头，访客直接访问时自带的头一律忽略；`X-Forwarded-For` 自右向左跳过可信代理。取到的地址用于访问日志、IP 名单、仅内网访问、国家过滤、封禁、统计与转发给后端的头。使用 Cloudflare 时建议选 `CF-Connecting-IP`。详见 [Web 服务](/docs/modules/web)。

## 站点实时连接（#51）

站点列表的每个域名行显示进行中的请求数，「连接」窗口每 2 秒刷新：

- 实时列表显示来源地址、协议（h1 / h2 / h3，WebSocket 单独标记）、方法与路径（不含查询串）、已持续时间与上下行流量，可按 IP 搜索；
- 历史记录保留每个站点最近 200 条持续 1 秒以上或被手动断开的请求，只在内存中；
- 可以断开单个请求（HTTP/2、HTTP/3 只重置这个请求流），或断开并封禁来源地址，同时断开它在全部站点上的请求。不能封禁自己当前使用的地址、回环地址与可信代理。

## 来源 IP 访问控制（#49）

端口转发、协议分流、STUN 内置转发与 frps 实例都可以设置白名单或黑名单，名单由手填的 IP / 网段和 Web 服务中的订阅 IP 列表组成，订阅列表刷新后立即生效，不重启规则：

- 入侵防护的封禁最先检查，然后才是名单；
- 规则卡片显示访问模式与拒绝次数，IP 列表页显示哪些规则引用了它，被引用的列表不能删除；
- frps 的名单在 frpc 登录时检查，保护绑定端口；
- 从 Lucky 导入端口转发与 STUN 规则时，安全模式一并转换为来源 IP 访问控制（需同时上传 `lucky_ipfilter.lkcf`）。

详见 [端口转发](/docs/modules/portforward) 与 [内网穿透](/docs/modules/tunnels)。

## 站点链接（#52）

站点列表中的每个具体域名都可以点击打开，旁边可复制带协议与端口的完整地址；经协议分流、端口映射、frp 或 CDN 访问时，可以在监听里填写对外的访问地址。frpc 的 http / https 代理、File Browser 访问地址、Cloudflare 临时隧道与 Tailscale 登录链接也可以点击和复制。域名保存时统一为浏览器发送的形式（小写，中文域名转为 punycode），带端口、路径等永远匹配不上的写法会被拒绝。

## 动态域名

- 记录备注（留空用任务备注）写入阿里云、Cloudflare、腾讯云、DNSPod 与华为云的控制台；
- 删除记录或任务时可勾选「同时从 DNS 服务商删除」，14 个服务商支持。只删除值与 Gately 最近一次同步结果相同的那条解析，值未知、在控制台改过或记录集中还有其他值时都不删除并说明原因；
- 模块开关移入「全局设置」，可设置删除勾选框的默认值。

## 其他改进

- Docker 页面可以直接升级 Gately 自身所在的容器：先拉取新镜像，有新版本时由临时辅助容器完成重建，失败时恢复旧容器；Web 终端的本机 Shell 运行在 Gately 容器内时会提示改用这里升级；
- 手机上的 Web 终端长按约半秒进入选择模式，可用系统的选择手柄与复制菜单，换行被拆开的长行复制时会还原；按键栏新增粘贴键，HTTP 访问时打开粘贴面板，可重发本标签页最近复制或输入的 10 条文本；粘贴多行且远端程序没有开启括号粘贴时先确认；
- 认证用户页可以直接取消只靠共享用户认证的站点，保存前确认会关闭这些站点的认证；
- 协议分流修改规则时，协议、域名与 ALPN 不变的路由保留命中次数；
- 网络诊断测速默认节点改用 50 MB 请求，修复 Cloudflare 返回 403，新增 Vultr、Hetzner、OVH 测速节点，任务标题只显示当前工具的目标；
- 默认站点按名单断开访问时，拒绝按 444 计入 Web 路径探测（#53）；
- 安全入口开启时 iOS 添加到主屏幕的图标不再显示为字母占位。

## 修复与加固

- Web 终端粘贴时去掉控制字符，内嵌的括号粘贴结束序列无法绕过多行确认；从系统剪贴板直接读到的内容不写入剪贴板记录，退出登录或会话失效时清空记录；
- 断开请求与请求自然结束同时发生时，不再影响同一连接上的下一个请求；
- 同时发起两次升级 Gately 自身时拒绝第二次；升级辅助容器连同匿名卷一起删除，同一 Docker 上的多个 Gately 只处理自己的辅助容器；
- 编辑动态域名任务时删除记录并勾选同时从服务商删除，先校验待保存的配置，校验失败时不删除服务商处的解析；腾讯云同步时按主机记录精确匹配；
- 离开页面后连接与统计窗口停止轮询；封禁失败时保留封禁窗口；frp 子域名拒绝 IPv6 地址；从 Lucky 导入黑名单模式的规则缺少名单时给出提示。

## 升级提示

- Docker 拉取新镜像后重建容器，已挂载 Docker 套接字的也可以在 Gately 的 Docker 页面直接升级 Gately 自身；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「系统设置」中在线升级。

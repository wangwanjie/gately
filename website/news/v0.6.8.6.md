# Gately v0.6.8.6 发布

2026 年 11 月 23 日

[下载 v0.6.8.6](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.6)

## 网络拓扑上行速率与统计时间段（#113）

- 站点、后端和监听级动作在下行之外新增上行速率：站点统计访客发来的字节（请求体，以及 WebSocket 等升级后访客发送的数据），后端统计转发给它的请求体字节。
- 详情面板的「60 秒均值」换成「上行」，与「下行」并列；顶部新增「统计时间段」下拉，QPS、上行、下行可在最近 1、5、10、30、60 秒之间切换（默认 10 秒，按设备记住）。回放时固定使用录制时的 10 秒。
- 工具栏同时显示上下行，窄屏下自动换行；每秒流量曲线分上行、下行两条线。
- 接口 `GET /api/webservice/topology` 新增 `window=1..60` 参数，各节点速率新增 `upBps`，`qps60` 继续保留。

## SMTP 跳过证书校验（#115）

- 通知渠道的 SMTP 在 STARTTLS 和 SSL/TLS 加密下新增「跳过证书校验」开关，用于证书为自签名或与服务器地址不符的自建邮件服务（例如只对 localhost 有效的默认证书），默认关闭。

## Windows 概览资源信息

- Windows 上的概览页显示 CPU 型号与使用率、内存与页面文件、磁盘、运行时长、Windows 版本与内部版本号、网络流量与速率，以及 Gately 和托管程序的内存、CPU 与线程数。Windows 没有系统负载，该项留空。

## 修复

- **概览**：健康检查失败但仍在运行的容器计入「运行中」，并在 Docker 一行单独显示「健康检查失败」数量；「异常」只统计重启中、已停止运行（dead）和非 0 退出的容器（#114）。
- **Docker**：健康检查失败的容器在卡片、详情头部和概览标签页显示「健康检查失败」警告徽标，容器列表新增「异常」筛选（#114）。
- **网络拓扑**：监听卡片的折叠按钮指向点击后子节点的去向，树形布局为左/右，纵向布局为上/下，径向布局为减号/加号（#113）。

## 升级提示

- Docker 拉取新镜像后重建容器；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「系统设置」中在线升级。

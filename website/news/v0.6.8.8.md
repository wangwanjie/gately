# Gately v0.6.8.8 发布

2026 年 11 月 25 日

[下载 v0.6.8.8](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.8.8)

## 站点域名任意一段通配（#118）

- 站点域名的 `*` 不再限于第一段：`audiobook.*.example.com` 中间整段 `*` 匹配一段，`audiobook.*` 末尾整段 `*` 匹配一段或多段（`audiobook.example.com`、`audiobook.home.lan`），`a.api-*.example.com` 段内 `*` 只在该段内匹配。
- 每个域名仍只能有一个 `*`，重定向里的 `{1}` 取到匹配的部分；固定部分构成 IP 的写法（如 `192.168.1.*`、`10.*`）会被拒绝。
- `audiobook.*` 这类末尾通配也会匹配别人注册的域名（如 `audiobook.attacker.com`），因此第三方登录回跳、带凭据跨域和敲门探测都不把它当作本站点域名；需要这些功能时请填写后缀固定的域名。
- `*` 不在首段的站点按实际访问域名各自匹配证书，不再误报缺少证书。
- 路由优先级不变：精确域名优先，其次匹配最长的通配，最后是 `*`。网络拓扑的打码与别名同样覆盖这类域名。

## 导航面板

- **分组登录后可见**：链接列表的分组标题新增锁形按钮，开启后整组链接只对已登录访客显示，之后加入该组的链接也自动生效，不用再逐个勾选。
- **分组改名（#122）**：分组标题新增改名按钮，组内链接一起改名并保持顺序；改成已有分组的名字时确认后合并；登录后可见设置跟随新名字，合并到公开分组时组内链接会逐个勾选「登录后可见」，不会因改名对未登录访客暴露。手机上分组标题不再被挤成一字一行。
- **图标网站与去除留白（#120）**：链接图标栏新增「图标网站」菜单（Dashboard Icons、selfh.st/icons、Seeklogo、Iconify）和「去除留白」按钮：自动裁掉透明或纯色边距，让图标居中铺满；SVG 只调整 viewBox 保持矢量，位图转为方形 PNG，图片地址会先下载再内嵌保存。

## 概览获取公网 IP

- 没有 DDNS 任务、或 DDNS 只覆盖一种地址族时，管理员可在概览网络卡片点「获取公网 IP」查一次公网 IPv4 / IPv6；DDNS 已提供的地址族沿用 DDNS 的值，查不到的显示「未获取到」并可悬停看原因。结果只保存在内存，刷新页面后仍在；网络自检找到的地址也会记录在这里。只读账号不显示该按钮。
- 新增接口 `POST /api/system/public-ip`（仅登录会话）与 `GET /api/system/public-ip`（`status:read`，不发外部请求）。

## 上下行方向统一（#117）

- 全站统一按 Gately 自身视角计算：上行是 Gately 发出的数据，下行是收到的数据，与概览网络速率一致。网络拓扑中 Gately、监听和站点节点把发给访客的响应计为上行、访客上传计为下行，后端节点相反；工具栏、详情面板、流量曲线、实时连接、端口转发、协议分流和 STUN 规则卡片同样调整。
- 接口字段（`bps`、`upBps`、`bytes`、`up`、`bytesIn`、`bytesOut`）不变，API 文档改为写明方向。

## 修复

- **反向代理**：访客的查询串原样转发给后端。之前含分号或非法百分号转义的参数会被丢掉、其余参数被重新排序（如 `?filters=and;(user_id;eq;123)`），路径规则去前缀和失败重试同样覆盖（#116）。
- **反向代理**：访客使用 HTTPS 时，后端返回指向同主机同端口的 `http://` 绝对跳转会改写为 `https://`，修复 oci-start 等忽略 `X-Forwarded-Proto` 的应用登录后跳回 http 的问题；其他主机、端口和相对跳转不变。
- **概览**：去掉 CPU、内存、磁盘圆环的发光和主机图标投影，部分浏览器下圆环两端不再出现方块污迹（#121）。

## 升级提示

- Docker 拉取新镜像后重建容器；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「系统设置」中在线升级。

# Gately v0.6.2.3 发布

2026 年 11 月 2 日

这是 v0.6.2 系列的改进更新，没有配置格式变化。

[下载 v0.6.2.3](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.2.3)

## 网络拓扑独立页面

拓扑从 Web 服务页的「拓扑」标签移到侧边栏「Web」下的「网络拓扑」页面，Web 服务页顶部的按钮可直达；统计与连接窗口在拓扑页直接打开，「编辑」跳到 Web 服务页并打开对应站点的编辑框。画布跟随当前皮肤的浅色或深色。

## 七种布局

布局菜单提供树状、竖向、放射、桑基、旭日、矩形树图和气泡图，每项带图标与一句话说明，切换时渐变并记住选择。每个监听默认显示前 8 个站点，每个站点显示前 6 个后端，其余合并为汇总节点，汇总其流量与处理中请求，点击就地展开；在没有折叠按钮的布局中可以从详情面板折叠监听。

## 缩放、全屏与画布高度

画布可拖动平移；滚轮滚动页面，按住 Ctrl / ⌘ 滚动、触控板捏合或双指捏合在 15% 到 250% 之间缩放；右下角的控件提供缩小、显示比例（点击回到 100%）、放大、适应画布和窗口内全屏，全屏按 Esc 退出。画布下方的拖动条可调整高度并按设备记住，双击或选择自动高度恢复。

## 按分类打码

打码可选择类别：访客 IP、后端地址、监听地址和域名，前三项默认选中，截图和直播时按需遮挡。

## 截图与演示视频

官网首页与 10 种语言的 README 使用对应语言的界面截图，新增拓扑动图，README 顶部附带 2 分钟无声功能巡览视频。

## 升级提示

- Docker 拉取新镜像后重建容器；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「系统设置」中在线升级。

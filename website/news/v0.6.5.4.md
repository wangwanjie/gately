# Gately v0.6.5.4 发布

[下载 v0.6.5.4](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5.4)

## 网络唤醒：远程关机

为设备选择一个 Web 终端中的 SSH 连接并填写关机命令后，设备卡片上出现「关机」按钮（接口 `POST /api/wol/devices/{key}/shutdown`）。

- 界面提供 Linux（`shutdown -h now`）、Windows（`shutdown /s /t 0`，需开启 OpenSSH 服务器）与 macOS（`sudo -n shutdown -h now`）的常用命令；
- 该连接必须已在 Web 终端中连接过一次、记录了主机密钥，无人值守时不信任未知主机；
- 每次关机新建一条 SSH 连接，执行完即关闭，设备重启后不会用到已失效的旧连接；命令最长执行 30 秒，同一设备同时只执行一次；连接在返回退出码之前断开视为已开始关机；
- API 令牌新增、修改、复制设备或触发关机时，除 `wol:write` 外还需要 `webterminal:write`，列出可选的 SSH 连接需要 `webterminal:read`。

## 网络唤醒：巴法云语音控制

接入[巴法云](https://cloud.bemfa.com)后可以用小爱同学、小度、Google Assistant 等语音助手开关设备：在巴法云控制台新建以 `001`（插座）或 `006`（开关）结尾的主题，设备中填写同名主题，在「网络唤醒 → 巴法云」中填写用户私钥并启用，再在米家、小度等 App 中绑定巴法云账号。

说「打开」唤醒设备，说「关闭」远程关机，成功后把开关状态写回巴法云；从界面或接口唤醒、关机同样写回。Gately 以 MQTT 3.1.1 经 TLS 连接 `bemfa.com:9503` 并校验证书，私钥在接口中脱敏显示；订阅时服务器补发的上一次状态不会执行，10 秒内重复的同一指令只执行一次。同一私钥同时只能有一个客户端在线。

## Web 服务：监听附加 HTTP 端口

监听可以再填一个明文 HTTP 端口（例如 HTTPS 监听 443 时再开 80），与主端口共用全部站点与设置，不必为 HTTP 另建监听、重复填写站点。开启 HTTPS 时可选「跳转到 HTTPS」（默认，保留域名、路径与查询串，端口换成访问地址中的端口，GET/HEAD 用 301、其他方法用 308）或「直接服务」。

- ACME HTTP-01 验证、PROXY 协议与自动放行防火墙同样作用于这个端口；端口被占用时主端口照常运行，监听状态中显示原因；
- 没有对应站点的域名不跳转，按未知域名返回 404 或交给默认站点（默认站点为「断开连接」时直接断开），与 HTTPS 上的处理一致，同端口 HTTP 的跳转也改为如此；
- 保存时检查 HTTP 端口与其他监听的端口是否冲突；监听经协议分流或端口转发访问而未填写访问端口时，编辑框会提醒填写入口端口。

## 导航面板：换肤

导航面板使用与管理界面相同的主题配色（Gately 原创与经典配色），编辑面板时可以选择默认皮肤。访客点页面右上角的调色板按钮即可换肤，交互与管理界面一致：亮色、暗色或跟随系统，悬停预览色系、点击后从点击处展开新配色，自定义主色与圆角；手机上从底部弹出。选择保存在访客的浏览器中，面板与管理界面在同一域名下时两边的选择互通。详见 [Web 服务 · 导航面板](/docs/modules/web#nav-panel)。

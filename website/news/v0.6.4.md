# Gately v0.6.4 发布

2026 年 11 月 3 日

[下载 v0.6.4](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.4) · [在线定制构建](https://build.gately.cn)

## 定制构建

除端口转发、Web 服务与 SSL 证书三个核心模块外，其余 22 个模块都可以在编译时去掉，界面语言也可以只保留简体中文，或简体中文、繁体中文与英语三种：

- 打开 [build.gately.cn](https://build.gately.cn)，勾选模块与语言（也可以从「仅核心」「路由器」「NAS」预设开始），页面实时估算体积，在线生成 Linux / Windows / macOS / FreeBSD 二进制、OpenWrt 与飞牛安装包，或 amd64、arm64、arm/v7 多架构 Docker 镜像；相同选项的产物会复用，不必重复构建；
- 以 linux/arm64 为例：完整版 33.6 MB，只留核心约 19.9 MB，路由器预设加简体中文约 21.2 MB；路由器预设加简体中文的 Docker 镜像拉取约 18.7 MB（完整镜像 51.9 MB），未包含 Docker 管理时镜像不带 docker-cli 与 compose，未包含入侵防护与 STUN 时不带 nftables；
- 没有编译进来的模块，配置文件原样保留，设置中的开关与 API 令牌权限照常有效，接口返回 404 并说明未包含在此构建中，界面隐藏对应页面与选项，换回完整版后恢复；
- 「关于」页列出本构建去掉的模块，并附带用相同选项打开构建器的链接。定制构建不提供在线升级（在线升级下载的是完整版本），新版本发布后用相同选项重新生成，再上传升级包；
- 自行编译时用 `no_<模块>` 与 `lang_zh` / `lang_cjken` build tag、前端的 `GATELY_LOCALES`，或 Dockerfile 的 `GATELY_TAGS` 等构建参数，`tools/custombuild` 可把选择换算成这些参数。

详见 [模块总览 · 定制构建](/docs/modules/#custom-build) 与 [从源码构建](/download#custom-build)。

## 隐藏管理端口

「设置 → 访问控制」新增「未授权访问响应」，作用于被封禁的来源、开启仅内网访问时的外网访问，以及没有经过安全入口的请求：

- 可选默认提示页、普通 404、空白页、断开连接、不响应直到超时，或自定义 HTML 页面（可指定状态码）；
- 断开与不响应在建立连接时按来源判定，HTTPS 不发送证书，经可信代理转发的请求自动改为普通 404，避免前置代理露出错误页；挂起的连接有时长与数量上限；
- 隐藏方式下响应不再带有管理界面特有的安全响应头，自定义页面在禁止脚本与外部资源的沙箱中显示。

端口本身仍可被扫描发现，彻底隐藏需配合防火墙。详见 [安全加固清单](/docs/guide/hardening)。

## 站点错误页

- Web 服务站点的「错误页」标签可以为 Gately 生成的 404 与 5xx 页面选择默认样式、10 种内置风格（极简、终端、霓虹、星空、报刊、粗野、极光、像素、蓝图、状态链路），或页面库中的自定义页面，每种风格都有缩略图与桌面 / 手机预览；
- 页面库可以上传、粘贴 HTML 或引用服务器上的 `.html` 文件，保存时检查并清理脚本、事件属性与表单等内容，支持 `{code}`、`{title}`、`{host}`、`{path}` 等占位符，输出时带禁止脚本与外部资源的 CSP；
- 反向代理站点可以拦截后端的指定状态码（如 `404, 500-599`），只替换浏览器打开页面的请求，接口请求保持原样；
- 默认站点的设置同时用于未匹配任何站点的请求，「排序与批量」可以批量设置错误页风格。

详见 [Web 服务 · 错误页](/docs/modules/web#error-pages)。

## 其他改进

- DDNS 搜索按记录过滤：任务的名称、分组、备注或服务商匹配时显示全部记录，否则只列出匹配的记录，搜索期间自动展开折叠的任务与分组；Web 服务搜索时自动展开折叠的监听；
- 设置页的长标签自动换行，德语、俄语等语言下不再与输入框重叠；
- 管理界面请求遇到非 JSON 响应（如会话过期后被安全入口拦截）时提示刷新或重新打开安全入口；
- 默认错误页的「刷新」改为普通链接，在禁止脚本的 CSP 下同样可用；
- 诊断包与 `GET /api/status`、`GET /api/system/info` 带上构建信息（是否定制、包含的模块与语言）；
- CI 增加预设 build tag 组合的检查。

## 升级提示

- Docker 拉取新镜像后重建容器，已挂载 Docker 套接字的也可以在 Gately 的 Docker 页面直接升级 Gately 自身；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「关于」页在线升级。
- 完整版用户无需任何操作，配置格式没有变化。

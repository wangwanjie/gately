# Gately v0.6.6.2 发布

2026 年 11 月 14 日

[下载 v0.6.6.2](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.6.2)

## EasyTier 组网

「组网与穿透」新增 EasyTier：托管 `easytier-core` 进程，把本机加入 EasyTier 组网，优先 P2P 打洞直连，打不通时经公共节点或自建节点中继。

- 支持多个实例，每个实例是独立的进程，可以把同一台机器分别加入不同的组网；
- 在线安装、更新与回滚，Windows 安装包自带 wintun.dll 等依赖；
- 网络密钥经环境变量传给进程，不出现在命令行，日志中打码；共享本地网段或允许作为出口节点时必须设置密钥；
- 实例卡片显示虚拟 IP、监听地址与节点列表（直连 / 中继、延迟、连接协议）；TUN 网卡无法创建或进程启动即退出时显示原因；
- 同时启用的实例监听同一端口、端口转发绑定同一本机端口或网卡名相同时拒绝保存。

详见 [组网与穿透](/docs/modules/tunnels)。

## 入侵防护

- **TLS 握手失败规则（#90）**：日志规则新增来源「TLS 握手失败」，统计 Web 服务 HTTPS 监听上的握手失败，按失败类型、监听与次数封禁。可分别勾选握手中途断开（EOF）、连接被重置、握手超时、非 TLS 或协议错误、无法协商参数、未知域名、客户端中止等类型。内置「TLS 异常握手」（1 分钟 5 次封 1 天）与「TLS 握手中断」（1 分钟 20 次）两个模板，编辑规则时可以粘贴失败原因测试归类。来源是 Web 服务「可信代理」中的地址（CDN 回源节点）时不计数。
- **端口扫描检测识别模块端口**：Gately 各模块监听成功后立即把端口登记为开放，300 毫秒内生效。frps 的绑定、vhost、对外 dashboard 与 allowPorts 范围，frpc 登录后申请的远程端口，EasyTier 的监听与端口转发，Tailscale、NetBird 对外的 SOCKS5 端口都会登记；端口停止监听后 10 分钟内仍视为开放，frpc 掉线重连、程序重启期间的正常访客不会被当成端口扫描封禁。

详见 [入侵防护](/docs/modules/guard)。

## 通知：新地址登录提醒（#92）

新增通知事件「管理后台：新地址登录」（`login.newip`，警告级别）：管理后台登录成功且来源地址此前从未登录成功过时发布，「安全与登录」模板已包含。密码、Passkey、第三方登录与飞牛统一网关登录都会检查；第一次登录只建立基线；IPv6 按 /64 网段归并；最多记录 200 个来源。详见 [通知中心](/docs/modules/notify)。

## 其他改进

- 只读账号与只读 API 令牌查看托管程序配置时，环境变量只显示变量名，额外参数整体隐藏。
- 登录页用户名或密码为空时直接提示，不再发出请求。
- 列表卡片的操作按钮固定在卡片底部，不同高度的卡片按钮对齐；窄卡片字段两列显示。

## 升级提示

- Docker 拉取新镜像后重建容器；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「系统设置」中在线升级。
- 已有的入侵防护规则与通知规则不受影响。需要新地址登录提醒时，在通知中心为 `login.newip` 添加规则，或重新应用「安全与登录」模板。

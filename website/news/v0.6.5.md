# Gately v0.6.5 发布

2026 年 11 月 6 日

[下载 v0.6.5](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.5)

## 后端超时、访客超时与自动重试

- 反向代理站点的「流量」页新增「后端超时」：连接、TLS 握手、等待响应头三项，留空分别为 10 秒、10 秒与不限；等待响应头超时返回 504，不影响之后的下载与 WebSocket、SSE 等长连接。
- 连接后端失败（拒绝连接、不可达、连接超时）时，同一个请求立即改用下一个后端，最多重试 3 次；请求体已经开始发送的请求不会重试。
- 「访客超时」限制读取请求体与写出响应时的空闲时间，默认 60 秒，用于断开极慢发送或读取的访客；读取请求体超时返回 408。
- 导入 nginx 配置时，`proxy_connect_timeout` 与 `proxy_read_timeout` 转换为站点的连接超时与等待响应头超时。

详见 [后端超时](/docs/modules/web#backend-timeouts) 与 [访客超时](/docs/modules/web#client-timeouts)。

## 向后端传递身份信息

原来的「传递用户名」与「传递邮箱」合并为「传递身份信息」列表，每行把登录用户的一项信息写入一个请求头：用户名、邮箱、显示名或分组，例如 Firefly III 这类用邮箱作为账号的应用可以直接读取 `Remote-Email`。访客自带的同名请求头（包括用下划线代替连字符的写法）在认证前删除，无法伪造；访客也无法借 `Connection` 头让这些请求头被去掉。旧配置升级后自动转换。详见 [传递身份信息](/docs/modules/web#identity-headers)。

## 自动放行防火墙

Web 服务的监听、端口转发与协议分流的规则新增「自动放行防火墙」开关，只在本机防火墙（nftables、iptables 或 ip6tables）中放行实际监听的端口，支持 IPv6 与端口区间，连续端口合并为一条规则；开启 HTTP/3 的监听同时放行同号 UDP 端口，只监听回环地址时无需放行。监听停止或删除时撤销。详见 [自动放行防火墙](/docs/modules/web#auto-firewall)。

## 运行日志

- Web 服务的访问日志按天切分并压缩归档，可设置保留天数与总大小，过去的访问记录可以继续检索；「加载更早的日志」会查找归档。
- 日志工具栏新增「导出」，按当前筛选条件导出全部日志（含文件与归档中的历史），格式为 CSV（UTF-8 带 BOM，Excel 可直接打开，已防公式注入）或 JSON Lines；只读账号导出的内容同样隐藏地址中的密码与令牌。
- 「设置 → 运行」新增「日志目录」，可以把运行日志放到外接硬盘等其他目录。
- 来源筛选列出全部来源；同名的 IPv4 与 IPv6 监听的日志不再混在一起，站点的「日志」窗口只显示本监听的访客。
- 待写盘的日志达到 256 KB 时立即写盘，高并发站点不再丢访问日志；手机上打开日志重新停在最新一条。

详见 [运行日志](/docs/guide/configuration#log-export)。

## 入侵防护：IPv6 严格模式

端口扫描检测新增「IPv6 严格模式」：IPv6 来源只能连接开放端口（正在监听的端口加额外开放端口），第一次连接其他端口即按 /64 封禁；IPv4 仍按阈值检测。端口短暂停止监听时 30 秒内仍视为开放，FTP 服务的被动端口范围自动计入开放端口。详见 [入侵防护](/docs/modules/guard)。

## 托管进程资源

概览页新增「托管进程」卡片，性能页列出 Gately 管理的外部程序（frpc / frps、tailscaled、NetBird、cloudflared、File Browser）各自的 CPU 与内存，进程重启后曲线保持连续。详见 [性能监控](/docs/modules/perf)。

## 其他改进与修复

- 站点链接：监听只对本机开放、经协议分流或端口转发进入时，站点链接自动使用规则的入口端口，例如 4435 监听由 4433 的 SNI 分流转入时链接用 4433；手动填写的访问端口仍优先。
- 网络拓扑新增「聚焦活动」，只显示最近 60 秒有请求或有活动 IP 的站点与后端；活动中的节点不再被收进「其余 N 个」。
- 网络自检：本机 DNS 偶尔超时不再把解析正确的 DDNS 记录报为未解析，改用公共 DNS 复查。
- DDNS：任务停止或重启时取消的同步不再记录错误、不再把记录标为失败。
- 扫描器造成的 TLS 握手失败改为调试级别日志，运行日志不再被刷屏；目标使用 `{host}` 等变量的重定向站点，对没有 Host 头的请求返回 400。
- 入侵防护封禁表改为紧凑格式写盘，只是到期的封禁不再触发重写。
- 导入的反向代理配置保留监听的 HTTP/3 设置。
- 登录页不再显示默认账号与重置密码提示。
- Web 终端：文件管理器的编辑器用右上角 X 或 Esc 关闭后可以再次打开；手机上选择模式向上拖过一屏后复制正常。
- 界面：站点行在平板与小屏笔记本上不再把域名挤成一列；IPv6 监听地址显示为 `http://[::1]:18951`。

# Gately v0.6.3.5 发布

2026 年 11 月 3 日

[下载 v0.6.3.5](/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.3.5)

## 安全修复

- 只读账号与只读 API 令牌此前能在 Tailscale 状态接口与模块日志里看到等待登录时的登录链接，拿到链接即可把这台网关登记到自己的 tailnet。现在登录链接只返回给有 Tailscale 写权限的身份，日志只保留链接的主机部分（新增的 NetBird 模块同样处理登录链接与设备码）。
- Web 终端「测试连接」在测试已保存的连接、合并已保存密钥或引用认证预设时，同样要先通过使用协议与两步验证门禁：这类请求会把已保存的密码发往请求指定的主机。

## NetBird 组网（#69）

新增 NetBird 模块，托管官方客户端，用法与 Tailscale 模块一致：

- 由 Gately 托管 `netbird service run`（状态保存在配置目录），也可以接管系统里已安装的 NetBird 服务；
- 支持设置密钥或登录链接 / 设备码登录，自建管理服务器地址、主机名、路由、DNS、拒绝入站、用户态网络与「访问本机服务」、SOCKS5 代理；
- 托管时由 Gately 负责连接，守护进程重启后自动重新连接，失败按 10 秒到 5 分钟退避重试；
- 页面的「在线安装」可下载、更新、回滚与卸载 NetBird，「恢复默认配置」会退出登录并清空登录状态。

详见 [隧道与组网 · NetBird](/docs/modules/tunnels)。

## 自动检查更新与安全提醒（#68）

- 默认每 12 小时匿名查询一次 GitHub 上的发布列表与安全公告（经「更新代理」，只读取不上报），可在「关于」页或「设置」中关闭；
- 有新版本时管理界面顶部提示，可查看更新内容或忽略该版本；当前版本受已公开的安全问题影响时显示红色提示，列出公告编号、严重程度与修复版本；
- 发现新版本或安全问题时发布 `system.update` / `system.security` 事件，通知中心新增「版本更新」规则模板；frp、cloudflared、Tailscale、NetBird、File Browser 的在线安装卡片新增「检查更新」，Docker 定时检查发现新镜像时也会发送通知。

详见 [安装 · 自动检查更新与安全提醒](/docs/guide/install#update-check)。

## 复制条目（#65）

所有列表都可以基于已有条目创建副本：编辑框以原条目为模板打开，名称自动加上「副本」，密码与密钥由服务端沿用原条目，明文不经过浏览器。证书副本会重新签发或读取，部署目标默认停用，避免覆盖原证书的文件；Web 站点副本可放到其他监听，监听副本可选择是否带上站点。接口为通用的 `POST <路径>/{key}/copy`。

## 移动 Web 站点（#63）

- 站点编辑框的「所属监听」在编辑时也能修改，保存后站点移到新监听；
- 「排序与批量」模式新增「移到监听」，可跨监听勾选，一次移动多个站点；
- 拖动站点到其他监听的站点或分组上即可移动。

目标监听已有相同域名时拒绝移动；性能监控告警规则与分享链接的使用次数随站点迁移，登录状态按监听与站点区分，移动后访客需要重新登录。从 HTTPS 移到明文 HTTP 且站点需要登录时会提示风险。

## 通知与代理（#67）

- 通知中心新增「通知设置」，可设置全局通知代理（不使用 / 使用全局更新代理 / 自定义），每个渠道也可以单独选择，支持 `http://`、`https://`、`socks5://`、`socks5h://`，邮件经代理时在隧道内完成 STARTTLS / SSL；
- DDNS / STUN 的 Webhook、计划任务的 HTTP 请求、订阅 IP 列表与 GeoIP 数据库下载也可以设置代理；
- 卡片与错误信息里隐藏代理密码。

## 其他改进

- 页头与列表工具栏在滚动时保持可见：模块页头吸顶，标题滚出后只露出操作栏；卡片内的工具栏吸在页头下方；对话框的标题、标签栏与底部按钮固定，表单在中间滚动（#64）；
- Docker 的拉取、推送、构建、检查更新、Compose 与批量升级等后台任务可以中断，Compose 先发中断信号让它自行收尾（#67）；
- 网络拓扑的站点、后端与活动 IP 可以直接查看访问日志，站点、后端与监听可以在拓扑页原地编辑；Web 服务站点行新增「日志」按钮（#67）；
- 镜像同时发布到 Docker Hub 的 `vanjayak/gately`，与 GHCR 是同一份多架构镜像，同样有 cosign 签名（#67）；
- 新建 API 令牌的弹窗新增 `/api/openapi.json` 调用示例（#67）；
- Web 服务手动封禁与「断开并封禁」新增「永久」选项；
- 「隐藏被封禁来源」同时隐藏仍在封禁中的来源此前触发封禁的那些请求；
- 只读账号的侧栏不再显示操作审计、配置历史、API 令牌与设置，直接打开这些页面会回到总览，界面不再请求管理员接口。

## 修复与加固

- 批量新增条目改为持锁校验，修复新增 Web 服务监听与 IP 列表之间的数据竞争；
- 连续移动站点时按顺序执行，性能监控告警规则不会停在已不存在的站点上；
- 手动封禁拒绝回环地址、未指定地址与可信代理地址（入侵防护的手动封禁拒绝回环与未指定地址），超大的封禁秒数不再溢出成永久封禁；
- Docker 定时检查在检查失败或容器停止期间保留通知记录，同一个新镜像不会重复通知；
- NetBird 与 Tailscale 托管守护进程时不再修改已有自定义状态目录的权限；NetBird 0.75 以下的用户态 SOCKS5 恒监听 0.0.0.0 时给出警告，SOCKS5 监听在本机以外的地址时界面提醒；
- 拓扑页查看命名默认站点的访问日志时按该站点过滤；未命名的默认站点不再提供会混入全部站点日志的入口；
- 运行日志来源筛选的清除按钮恢复正常；只读账号刷新管理员页面时不再出现 403 请求；
- 代理密码中含未编码的 `@`、`/`、`:` 时也能完整隐藏。

## 升级提示

- Docker 拉取新镜像后重建容器，已挂载 Docker 套接字的也可以在 Gately 的 Docker 页面直接升级 Gately 自身；OpenWrt 覆盖安装新的 `.apk` / `.ipk`；飞牛在应用中心手动安装新版 `.fpk`；其他部署方式可在「系统设置」中在线升级。
- 升级后自动检查更新默认开启，不需要时可在「关于」页关闭。
